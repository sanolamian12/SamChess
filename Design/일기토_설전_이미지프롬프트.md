# 일기토 · 설전 — 이미지 생성 의뢰서

삼국지 소재 전술 대전 게임에 새로 들어가는 **일기토**(장수 둘의 가위바위보 승부)와 **설전**(말싸움 — 상대가 고른 숫자 1 · 2 · 3 맞히기)에 필요한 그림 **19장**의 의뢰서다.
배경 · 규격 · 고정 접두 · 프롬프트 · 검수 기준을 이 파일 하나에 담았다. 규칙은 [GDD §3.11](GDD.md), 화면 설계는 [`일기토_설전_설계.md`](일기토_설전_설계.md) §4 · §5.

> **2026-11-05 규칙 개정으로 바뀐 것** (GDD · 설계서에는 아직 안 옮겼다): 설전이 좌우 맞히기에서 **숫자 1~3 맞히기**로, 술래가 **공격권**으로, 게이지가 **전의 · 정신력 둘**로, 이긴 쪽에 **SP MAX 버프**(통상공격 AT +1)가 생겼고 퇴각은 없어졌다.
> 그래서 **뺀 것 2장**(`ic_debate_guess` 술래의 눈 · `ic_debate_point` 좌우 부채) · **더한 것 6장**(산가지 1 · 2 · 3, 정신력, 공격권, SP MAX 버프) — 15 − 2 + 6 = 19장. 이미 뽑은 그림은 그대로 쓴다.

## 1. 라벨 2장 ★★★

고유기술 라벨 40장과 **한 벌**로 보여야 한다 — 회색 수묵, 가로로 긴 띠, **왼쪽에 장면 · 오른쪽에 큰 한자 제목 + 한국어 한 줄 + 붉은 낙관.**

| | |
|---|---|
| 최종 크기 | **1626 × 336** (고유기술 라벨 813 × 168의 두 배) — 게임이 줄인다 |
| 생성 | 도구가 그 비율을 못 내면 가장 넓은 비율(21:9 · 3:1)로 만들고 **가운데 띠를 잘라 낸다** — 그래서 장면을 세로 가운데에 모은다 |
| 구도 | 장면은 **왼쪽 55~60%**, 오른쪽 40%는 **비워 둔 종이**(제목이 들어갈 자리) |
| 글자 | **생성 도구에는 글자를 시키지 않는다**(한자를 틀리게 쓴다). 받은 그림에 제목 · 한 줄 · 낙관을 얹는다 — 기존 라벨을 만드신 방식 그대로, 또는 받은 그림을 주시면 도구로 얹는다 |
| 파일 이름 · 놓는 곳 | `일기토.jpg` · `설전.jpg` → **`assets/duel/label/`** (고유기술 폴더 `skills/label/`에 넣지 않는다 — 그 폴더는 「장수이름 기술이름」 규칙을 추출기가 대조해서, 다른 이름이 들어오면 빌드가 멈춘다) |

### 3-2. 설전 패 — 산가지 1 · 2 · 3 ★★★

설전은 **상대가 고른 숫자(1 · 2 · 3)를 맞히는** 놀이다. 숫자를 글자로 쓰지 않고 옛 셈 막대 **산가지(算籌)**의 개수로 보인다 — 생성 도구에 글자를 안 시키는 원칙과도 맞고, 세계관에도 맞는다.

| | |
|---|---|
| 규격 · 놓는 곳 | 접두 A와 같다 (512², 검정 바탕) · `assets/icons/ui/control/` |
| 한 벌 | **1개짜리를 먼저 뽑고 참조 이미지로 넣어** 2 · 3을 뽑는다 — 막대의 굵기 · 색 · 띠가 같아야 한다 |
| 개수가 틀리면 | 생성 도구는 개수를 자주 틀린다. 두세 번 해도 안 맞으면 **1개짜리만** 주시면 게임이 2 · 3개로 나란히 세운다 |

접두 A 끝의 `Subject:` 대신 아래 **공통 문장 + 개수 한 줄**을 붙인다:

```
… (접두 A 그대로) … Subject: ivory-white counting rods of ancient China, slim round sticks each with a thin red lacquered band near both ends, standing vertically side by side and evenly spaced, centered, bold clear silhouette, exactly
```

## 4. 대결 배경 2장 ★★

일기토 · 설전 화면 **전체**에 깔린다. 그 위에 위쪽 양옆으로 두 장수 초상 · 전의 막대, 가운데 큰 카운트 숫자, 아래쪽에 패 단추가 놓인다.

| | |
|---|---|
| 비율 | **세로 1 : 2** (게임 화면이 세로로 긴 1:2다) — 도구가 못 내면 9:16으로 만들어 위아래를 조금 자른다 |
| 크기 | **1400 × 2800 이상** (화면 폭 최대 700px의 두 배). 작게 받으면 늘려서 깨진다 |
| 구도 | **가운데 띠(세로 40~60%)는 조용하게** — 큰 숫자가 그 위에 선다. **아래 4분의 1은 어둡게**(단추 자리). 위쪽 양옆은 초상이 덮으니 덜 중요하다 |
| 화풍 | 기존 화면 배경(결과 화면 · 도시)과 같은 **반실사 회화풍**, 채도는 약간 낮게 — 그림이 아니라 그 위의 손 · 숫자가 주인공이다 |

## 7. 검수

- **라벨**: 기존 고유기술 라벨 옆에 나란히 놓았을 때 한 벌인가(먹색 · 종이색 · 낙관 위치) · 오른쪽 40%가 비어 제목이 들어가는가
- **아이콘**: 기존 `ic_cmd_unique` · `ic_cmd_ready` 옆에서 테두리 빛 · 채도가 같은가 · 48px에서 읽히는가 · 검정 바탕이 순수 검정인가(회색 바닥 · 그림자 없음)
- **손**: 손가락 개수 · 세 장의 소매가 같은가 · 셋이 실루엣만으로 갈리는가
- **배경**: 1400 × 2800 이상인가 · 가운데가 조용하고 아래가 어두운가 · 사람 · 글자가 없는가
- **연출**: 바탕이 순수 검정인가 · 가장자리에 닿지 않는가
- 생성 도구의 **✦ 워터마크**가 남았으면 지운다(기존 고유기술 장면에 남아 있던 적이 있다)
