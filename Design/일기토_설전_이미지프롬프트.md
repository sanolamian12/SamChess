# 일기토 · 설전 — 이미지 생성 의뢰서

삼국지 소재 전술 대전 게임에 새로 들어가는 **일기토**(장수 둘의 가위바위보 승부)와 **설전**(말싸움 — 상대가 고른 쪽 맞히기)에 필요한 그림 **15장**의 의뢰서다.
배경 · 규격 · 고정 접두 · 프롬프트 · 검수 기준을 이 파일 하나에 담았다. 규칙은 [GDD §3.11](GDD.md), 화면 설계는 [`일기토_설전_설계.md`](일기토_설전_설계.md) §4 · §5.

## 1. 라벨 2장 ★★★

고유기술 라벨 40장과 **한 벌**로 보여야 한다 — 회색 수묵, 가로로 긴 띠, **왼쪽에 장면 · 오른쪽에 큰 한자 제목 + 한국어 한 줄 + 붉은 낙관.**

| | |
|---|---|
| 최종 크기 | **1626 × 336** (고유기술 라벨 813 × 168의 두 배) — 게임이 줄인다 |
| 생성 | 도구가 그 비율을 못 내면 가장 넓은 비율(21:9 · 3:1)로 만들고 **가운데 띠를 잘라 낸다** — 그래서 장면을 세로 가운데에 모은다 |
| 구도 | 장면은 **왼쪽 55~60%**, 오른쪽 40%는 **비워 둔 종이**(제목이 들어갈 자리) |
| 글자 | **생성 도구에는 글자를 시키지 않는다**(한자를 틀리게 쓴다). 받은 그림에 제목 · 한 줄 · 낙관을 얹는다 — 기존 라벨을 만드신 방식 그대로, 또는 받은 그림을 주시면 도구로 얹는다 |
| 파일 이름 · 놓는 곳 | `일기토.jpg` · `설전.jpg` → **`assets/duel/label/`** (고유기술 폴더 `skills/label/`에 넣지 않는다 — 그 폴더는 「장수이름 기술이름」 규칙을 추출기가 대조해서, 다른 이름이 들어오면 빌드가 멈춘다) |

## 3. 가위 · 바위 · 보 손 3장 ★★★

기획자 확정: **손 모양 그대로.** 3초 안에 골라야 하므로 **실루엣만으로** 셋이 갈려야 한다. 세계관은 손의 차림(갑옷 소매)으로 맞춘다.

| | |
|---|---|
| 규격 | 접두 A와 같다 (512², 검정 바탕) |
| 방향 | **손끝이 위**, 손목이 아래 가장자리 쪽. 공개 연출에서는 게임이 돌려서 양쪽에서 맞부딪히게 한다 |
| 한 벌 | **세 장이 같은 팔 · 같은 소매 · 같은 각도 · 같은 빛**이어야 한다 — **첫 장(바위)을 뽑은 뒤 그 그림을 참조 이미지로 넣고** 나머지 둘을 뽑는다 |
| 놓는 곳 | `assets/icons/ui/control/` |

접두 A 끝의 `Subject:` 대신 아래 **공통 손 문장 + 손 모양 한 줄**을 붙인다:

```
… (접두 A 그대로) … Subject: a single strong right hand of an ancient Chinese general seen from the front, fingers pointing upward, wrist at the bottom wrapped in a dark lacquered leather bracer with bronze studs and a short red cloth cuff, the whole hand and bracer inside the frame, bold clear silhouette, the gesture is:
```

| ★ | 파일 | 손 모양 (공통 문장 뒤) |
|---|---|---|
| ★★★ | `ic_rps_rock.png` | `a tight closed fist, knuckles facing the viewer, no fingers extended.` |
| ★★★ | `ic_rps_scissors.png` | `index and middle fingers extended straight up and spread apart in a clear V shape, ring finger and little finger folded down, thumb holding them.` |
| ★★★ | `ic_rps_paper.png` | `an open flat palm facing the viewer, all five fingers extended upward and slightly spread.` |

검수: **48px로 줄여도** 셋이 바로 갈리는가 · 손가락 개수가 맞는가(생성 도구가 손가락을 6개로 그리기 쉽다) · 세 장의 소매가 같은가.

## 4. 대결 배경 2장 ★★

일기토 · 설전 화면 **전체**에 깔린다. 그 위에 위쪽 양옆으로 두 장수 초상 · 전의 막대, 가운데 큰 카운트 숫자, 아래쪽에 패 단추가 놓인다.

| | |
|---|---|
| 비율 | **세로 1 : 2** (게임 화면이 세로로 긴 1:2다) — 도구가 못 내면 9:16으로 만들어 위아래를 조금 자른다 |
| 크기 | **1400 × 2800 이상** (화면 폭 최대 700px의 두 배). 작게 받으면 늘려서 깨진다 |
| 구도 | **가운데 띠(세로 40~60%)는 조용하게** — 큰 숫자가 그 위에 선다. **아래 4분의 1은 어둡게**(단추 자리). 위쪽 양옆은 초상이 덮으니 덜 중요하다 |
| 화풍 | 기존 화면 배경(결과 화면 · 도시)과 같은 **반실사 회화풍**, 채도는 약간 낮게 — 그림이 아니라 그 위의 손 · 숫자가 주인공이다 |
| 놓는 곳 | `assets/duel/bg/` — `duel.jpg` · `debate.jpg` |

## 5. 공개 연출 2장 ★

패가 열리는 순간 가운데서 터지는 섬광. 게임이 **키우며 흐려지게** 움직이므로 **한 장**이면 된다(스프라이트 시트 아님).

| | |
|---|---|
| 규격 | 1024 × 1024, **완전한 검정 바탕**(밝은 부분만 남긴다), 가운데에서 바깥으로 퍼지는 모양, **가장자리까지 닿지 않게** |
| 놓는 곳 | `assets/duel/fx/` |

| 파일 | 프롬프트 |
|---|---|
| `clash.png` (일기토 — 이긴 패가 부딪힐 때) | `A bright impact flash of two blades colliding, white-hot core with golden and orange sparks and short streaks radiating outward in every direction, on a plain solid pure black background, centered, nothing touching the edges, no objects, no text.` |
| `ink.png` (설전 — 술래가 맞혔을 때) | `An explosive splash of glowing golden ink bursting outward from the center like a brush stroke flung hard, droplets and thin trailing strokes radiating in every direction, on a plain solid pure black background, centered, nothing touching the edges, no text, no calligraphy characters.` |

## 7. 검수

- **라벨**: 기존 고유기술 라벨 옆에 나란히 놓았을 때 한 벌인가(먹색 · 종이색 · 낙관 위치) · 오른쪽 40%가 비어 제목이 들어가는가
- **아이콘**: 기존 `ic_cmd_unique` · `ic_cmd_ready` 옆에서 테두리 빛 · 채도가 같은가 · 48px에서 읽히는가 · 검정 바탕이 순수 검정인가(회색 바닥 · 그림자 없음)
- **손**: 손가락 개수 · 세 장의 소매가 같은가 · 셋이 실루엣만으로 갈리는가
- **배경**: 1400 × 2800 이상인가 · 가운데가 조용하고 아래가 어두운가 · 사람 · 글자가 없는가
- **연출**: 바탕이 순수 검정인가 · 가장자리에 닿지 않는가
- 생성 도구의 **✦ 워터마크**가 남았으면 지운다(기존 고유기술 장면에 남아 있던 적이 있다)
