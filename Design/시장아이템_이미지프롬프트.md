# 시장 아이템 16종 — 이미지 생성 의뢰서

삼국지 소재 전술 대전 게임의 **상점(시장)에서 파는 아이템 16종**의 아이콘 그림을
만드는 의뢰서다. 이 파일 하나로 작업이 끝나도록 배경·규격·프롬프트·검수 기준을
모두 담았다. **다른 문서를 함께 볼 필요가 없다.**

---

## 1. 무엇을 만드는가

플레이어는 전투에 내보낼 장수에게 물건 하나를 들려 보낸다. 그 물건이 **시장에서
파는 소모성 아이템 16종**이고, 여기서 만들 것은 **그 16종의 아이콘 그림**이다.

- **아이콘은 목록에서 작게 뜬다.** 한 화면에 여러 개가 나란히 서므로 **작을 때
  서로 구별되는 것**이 가장 중요하다. 세밀함보다 **실루엣과 색의 차이**가 우선이다.
- 게임에는 이미 같은 방식으로 만든 **무기·방어구 아이콘 15종**이 있고, 이 16종은
  그 옆에 나란히 선다. 그래서 **화풍을 고정하는 접두 문장**(3절)을 반드시 쓴다.
- 시대 배경은 **중국 후한 말~삼국시대**(서기 2~3세기)다.

아이템은 네 부류이고, 상점 레벨이 오를수록 비싼 것이 열린다. 값이 셀수록 더 귀하고
장식이 화려해 보여야 한다.

## 2. 납품 규격

| | |
|---|---|
| 형식 | PNG |
| 크기 | **693 × 378 픽셀** (가로가 긴 직사각형) |
| 구도 | 물건 **하나**를 화면 가운데에. 사방에 약간의 여백 |
| 배경 | **단색 중립 배경** — 회색이나 옅은 베이지. 무늬·풍경·바닥·그림자 연출 없음 |
| 파일 이름 | `LV{상점레벨}_{부류}_{이름}.png` (예: `LV2_약_탕약.png`, `LV5_말_적토마.png`) |

부류는 **약 · 책 · 말 · 도구** 넷 중 하나다.

> 배경은 나중에 프로그램이 잘라 내고 액자에 앉힌다. 그래서 **배경이 단순할수록 좋다** —
> 물건 밑에 그림자를 깔거나 탁자·천을 깔면 잘라 낼 때 같이 딸려 온다.

## 3. 고정 접두 ★ 반드시 붙일 것

**아래 한 문장을 16장 전부의 프롬프트 맨 앞에 붙인다.** 기존 무기·방어구 15종이
이 문장으로 만들어졌고, **한 글자라도 달라지면 화풍이 갈린다.**

```
Single game item icon, isolated on a plain neutral background, three-quarter angled view, ancient Chinese Han dynasty and Three Kingdoms era craftsmanship, painterly semi-realistic game art, soft rim lighting, crisp high detail, no text, no watermark, no human figure.
```

말 넷에도 이 접두를 그대로 쓴다. 「item」이라는 낱말이 들어 있지만 목적은 **문체 고정**이고,
사람을 빼라는 지시(`no human figure`)가 **탈것에서 특히 중요하다** — 기수가 그려지면
아이콘이 아니라 삽화가 된다.

아래 4~7절의 프롬프트에는 **이 접두가 이미 붙어 있다.** 통째로 복사해 쓰면 된다.

## 8. 검수 기준

받은 그림을 **실제 크기의 4분의 1로 줄여 16장을 한 화면에 늘어놓고** 본다. 크게 보면
전부 멀쩡하지만 작게 뜨면 구별이 안 되는 것이 이 작업의 유일한 실패 방식이다.

| | 확인할 것 |
|---|---|
| ☐ | **사람이 없다.** 특히 말 넷에 기수가 없어야 한다 |
| ☐ | **글자가 없다.** 책 넷과 영기에 한자가 들어가기 쉽다 — 거의 언제나 깨진 글자가 된다. 태평요술의 **읽을 수 없는 붉은 부적 글씨만 예외**로 의도한 것이다 |
| ☐ | **배경이 단색이다.** 바닥·탁자·천·드리운 그림자가 없다 |
| ☐ | **물건이 하나다.** 곁들인 소품(약재·붓·부싯돌)은 괜찮지만 주인공이 둘이면 안 된다 |
| ☐ | **책 넷이 작게 봐도 갈린다** — 청낭서 **파란 주머니** · 태평요술 **누런 두루마리** · 육도삼략 **낡은 죽간 두 묶음** · 손자병법서 **남색 비단 위 옥 추**. 죽간 묶음 네 개로 나오면 다시 뽑는다 |
| ☐ | **말 넷이 작게 봐도 갈린다** — 대완마 **금빛** · 적로 **흰 이마** · 절영 **칠흑** · 적토마 **진홍**. 네 마리가 다 갈색 말로 나오면 다시 뽑는다 |
| ☐ | **레벨이 높을수록 귀해 보인다.** Lv2가 Lv5보다 화려하면 안 된다 |
| ☐ | 16장의 **붓질·조명·채도가 한 벌로 보인다.** 한 장만 사진처럼 사실적이거나 만화처럼 단순하면 다시 뽑는다 |

## 9. 알아 둘 것 둘

**폭약은 시대가 살짝 어긋난다.** 화약은 당대(唐, 7세기 이후) 물건이라 삼국시대에는
없었다. 그래서 프롬프트를 **한대(漢)의 화공 도구**, 즉 유황과 역청을 채우고 삼끈 심지를
낸 질항아리로 적었다 — 「폭약」이라는 이름으로 불러도 그림은 시대에 맞는다.

**척후기는 물건 하나가 아니라 장비 한 벌이다.** 斥候騎는 본래 「척후 기병」이라 사람과
말이 있어야 자연스러운데 둘 다 넣을 수 없다. 그래서 **척후병의 장비 꾸러미**(신호 깃발 ·
가죽 배낭 · 지도 · 죽간 · 청동 조준관)로 풀었다. 다른 열다섯 장과 결이 조금 다르므로,
어울리지 않으면 **망루 모형**이나 **깃발 하나**로 단순하게 바꿔도 좋다.
