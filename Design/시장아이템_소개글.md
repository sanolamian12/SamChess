# 시장 아이템 16종 — 소개글 (2026-09-23 확정)

GDD [§6.5](GDD.md)의 시장 아이템 16종에 붙는 **해설 한 줄**이다. 대장간 병기의
`lore`와 같은 성격이고 같은 문체다 — **물건이 무엇인가 + 사연 하나**, 1~2문장.

- **효과는 여기 적지 않는다.** 효과 문장(`결정타 +5%p` 같은)은 별도 칸이고, 시장
  아이템의 것은 GDD §6.5에 있다. 병기가 `lore`와 `text`를 가르는 것과 같다.
- **정본은 엑셀이다.** 품목 표가 생기면 `해설` 열로 옮기고 이 파일은 버린다.
- **아홉 언어 번역이 따로 필요하다.** 병기가 그렇듯 정본은 CSV가 아니라 **엑셀의
  `해설_{lang}` 열**이다 (번역은 별도 작업).

## 적으면서 지킨 것

- **출전을 정사와 전승으로 갈랐다.** 마비산·목우유마·대완마·절영·손자병법서는 정사에
  근거가 있고, 청낭서·태평요술·적로·적토마는 연의나 전승이다 — 뒤쪽은 「~라 전한다 /
  ~라 했으나 / ~라 한다」로 표시가 되게 적었다.
- **폭약만 실존하지 않는 물건이다.** 화약은 당대(唐) 물건이라 삼국시대에는 없었다.
  한대(漢)의 화공 도구인 **유황·역청 질항아리**로 적어 그림과 시대를 맞췄다.
- **짧게 적은 것은 번역과 화면 때문이기도 하다.** 해설은 아홉 언어로 불어나고,
  긴 번역(몽골어 등)이 팝업 칸을 넘치는 사고가 이미 여러 번 있었다.
