## 1. 납품 규격과 고정 접두

| | |
|---|---|
| 형식 | **PNG, 투명 배경** (투명이 안 되는 도구면 **완전한 흰 단색 배경**으로 받아 배경만 지운다) |
| 크기 | **512 × 512** — 게임은 128²로 굽는다(`tools/build_ui.py`). 물건이 칸의 **80~90%**를 채우고 가운데 |
| 파일 이름 | 각 표의 `파일` 열. 앞에 `ic_`를 붙인 밑줄 이름 (`ic_stat_hp.png`) |
| 놓는 곳 | `assets/icons/ui/` — 굽는 표(`build_ui.py`)에 줄을 더해 `public/icons/{id}.png`로 나간다 |

아이콘은 쓰임에 따라 **세 꼴**이다. 표마다 어느 접두를 쓰는지 적었다. 각 줄의 프롬프트는 **접두 바로 뒤에** 붙인다.

## 12. 일부러 안 만드는 것

- **판때기 · 액자 · 배경 · 초상** — 아이콘이 아니다.
- **시스템 로그의 줄 종류** — 이동 · 공격 · 책략 · 아이템 · 명상은 `ui/cmd/*`를 그대로 빌린다. 나머지는 색이 이미 가른다.
- **농지 파수꾼 단추의 아이콘** — 2026-09-22에 기획자가 일부러 걷었다(`FarmScreen` 주석).
- **대장간 제조 칸의 레벨 배지** — 같은 결로 걷었다.
- **컬렉션 등급 명패** — `컬렉션_UI_이미지프롬프트.md` ①에서 보류 중이다.
- **우편 안 읽음 점 · 입장 진행 점** — 작은 CSS 점이 더 읽힌다.
- **「→」 「×」** — 글자 안에서 숫자와 붙어 읽혀서 그림으로 바꾸면 오히려 끊긴다.

## 13. 검수

- 같은 묶음(§2 능력치, §3 전적, §4 결말 · 목표, §5 모드, §6 건물, §11 표식)을 **나란히 놓았을 때 한 벌**인가 — 시점 · 크기 · 밝기 ·
  테두리 굵기가 다르면 접두를 바꾸지 말고 다시 뽑는다
- **글자 · 숫자 · 한자가 하나도 없는가** (인장 · 두루마리 · 깃발에 잘 생긴다)
- **48px로 줄였을 때**(표식은 24px) 무엇인지 알아보이는가 — 정본은 700px 판, 실제로는 이 크기다
- 짙은 나무 판 위에서도 보이는가 — 흰 바탕에서만 보면 사라지는 색을 못 잡는다(CLAUDE.md 「흰 바탕의 목업에서 고른 색」)
- `ic_mode_3v3` / `5v5`, `ic_mk_plus` / `minus`, `ic_rec_win` / `draw` / `lose`처럼 **짝은 한 번에** 같이 뽑는다
