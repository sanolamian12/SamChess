# 시설 인물 호칭 더빙 — Google AI Studio 프롬프트 (2026-11-13)

내관 대신 화면에 서는 다섯 인물이 군주를 부르는 한마디. 내관 목소리(`voice/city/{LANG}/{호칭}_{LANG}.mp3`)와 같은 꼴이다.

> **최종 (2026-11-13 기획자)** — 새 목소리는 **병영 · 대장간 둘만** 쓴다(한 녹음 `voice/sources/병영_대장간_5개호칭_5개언어.mp3`를
> 잘라 `voice/city/army/` · `voice/city/blacksmith/`에 같은 것을 둔다). 태학 · 농지 · 약방은 **그림만** 바뀌고 목소리는 내관 그대로다.
> 붙인 기록은 `history/2026-11-13_안내인물_병영대장간.md`.

| 인물 | 그림 | 나오는 자리 | 녹음할 호칭 |
|---|---|---|---|
| 병사(무관) | `army_Lv1-2` … `army_Lv9-10` — 레벨마다 갑옷만 바뀐다 | 병영 · 일기토 설명 | 다섯 |
| 태학 학사 | `school` | 태학 | 다섯 |
| 농부 | `farm` | 농지 | 다섯 |
| 의원 | `doctor` | 약방 | 다섯 |
| 대장장이 | `blacksmith` | 대장간 | 다섯 |

**한 건물에서는 한 사람의 목소리만 나온다** — 인물마다 Style 하나 · Voice 하나로 호칭 다섯을 뽑는다 → 인물당 25개(호칭 5 × 언어 5), **모두 125개.**

## 쓰는 법

1. AI Studio → **Generate speech** → **Single-speaker**, Voice는 인물마다 적힌 것.
2. **Style 칸** — 그 인물의 「Style」 블록을 **통째로** 붙인다. 언어 · 발음 지시가 다 들어 있어 언어를 바꿔도 그대로 둔다.
3. **내용 칸** — 맨 아래 「호칭 표」에서 **한 칸만** 붙이고 뽑는다. 한 번에 한 파일. 다음 줄로 바꿔 가며 반복.
4. 마음에 안 들면 같은 설정으로 다시 뽑는다 — 한마디라 몇 번 돌려 고르는 편이 빠르다.

Voice는 추천이다. 들어 보고 바꿔도 된다(모두 남성 목소리 — 그림이 전부 남자다).
일본어를 히라가나로 적은 것은 한자 「殿」이 「でん」으로 읽힐 수 있어서다.

## 파일을 둘 자리

내관 녹음과 같은 꼴로, 인물 폴더만 하나 더 둔다. WAV로 받아도 된다(붙일 때 mp3로 바꾼다).

```
assets/Audio/voice/city/army/{LANG}/주공_KR.mp3 … 전하_KR.mp3
assets/Audio/voice/city/school/{LANG}/주공_KR.mp3 … 전하_KR.mp3
assets/Audio/voice/city/farm/{LANG}/…
assets/Audio/voice/city/doctor/{LANG}/…
assets/Audio/voice/city/blacksmith/{LANG}/…
```

`{LANG}`은 `KR` · `EN` · `PT` · `JP` · `CA`(중국어 — 기존 폴더 이름 그대로).

## 확인할 것

- 화면 글자의 호칭(`guide.honor.*`)은 아직 한국어에만 있다 — 번역을 넣을 때 **위 표의 단어와 맞춘다**(소리와 글자가 갈리지 않게).
- 기존 내관 녹음의 영어 · 포르투갈어 · 중국어 · 일본어 단어가 위 표와 다르면, 그쪽에 맞춰 이 표를 고친다.
