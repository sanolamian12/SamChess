# 꼬마 장수 그림 크기 보정 — 전투 동작 시트 작업 세션에 전달 (2026-11-14)

> **받는 쪽:** 전투 돌입 뒤 장수 동작(평상 · 이동 · 공격 · 마법 · 피격)을 4~5프레임으로 다시 그리는 세션.
> **보내는 쪽:** 부대 개편 세션(`history/2026-11-14c_부대개편_공격대수비대.md`) — 병영 · 부대 관리 화면의 꼬마 장수 크기를 맞췄다.
> 이 문서가 말하는 것은 **지금 그림 시트(`actions/{id}.png`)를 읽는 자리**와 **장수별 크기 보정표**다. 시트 모양이나 그림이 바뀌면 둘 다 영향을 받는다.

## 2. 지금 어디에 걸려 있나 — 메뉴 화면의 `OfficerStand` 하나

`OfficerStand`(`OfficerArt.tsx`)는 시트를 **CSS 배경**으로 그린다.

```ts
backgroundImage: `url(${actionSheetUrl(officer)})`,        // actions/{artKey}.png
backgroundSize: `${ACTION_FRAME_COUNT * 100}% 100%`,        // ACTION_FRAME_COUNT = 5 (ui/art.ts)
backgroundPosition: '0 0',                                  // 첫 칸 = 서 있는 자세
transform: `scale(${STAND_SCALE[officer]})`, transformOrigin: '50% 100%',   // 보정표에 있는 장수만
```

쓰는 화면: 병영 현황판의 부대 칸(`PlaceScreen.tsx`) · 부대 관리 목록(`SquadListScreen.tsx`).

**보정이 안 걸린 자리:**
- **전투 판(Phaser)** — `BattleScene.ts`가 같은 `actions/{id}.png`를 `load.spritesheet(… frameWidth 110)`로 읽는다. 주유 등은 판 위에서 여전히 커 보일 수 있다.
- **큰 자세 그림**(`OfficerArt` — `actions-hd/{id}.webp`의 무작위 칸, 장수 카드 · 오프닝 등).

## 3. 동작 시트 작업이 닿는 자리 — 바꾸면 함께 봐 주세요

1. **시트 모양이 바뀌면 `OfficerStand`가 깨진다.** 칸 수(`ACTION_FRAME_COUNT` = 5) · 한 줄에 칸이 나란히라는 전제(`backgroundSize` 가로 N배, 세로 100%) ·
   서 있는 자세가 첫 칸이라는 전제(`backgroundPosition: 0 0`)를 그대로 쓴다. 동작마다 4~5프레임이 되어 시트가 여러 줄 · 여러 장이 되면,
   **메뉴의 꼬마가 쓸 「서 있는 한 칸」을 어디서 읽을지**를 정해 `OfficerStand`(와 `ui/art.ts`의 `actionSheetUrl` · `ACTION_FRAME_COUNT`)를 함께 고쳐 주세요.
   같은 상수를 `OfficerArt`(큰 자세 그림의 무작위 칸)도 쓴다.
2. **그림이 바뀌면 보정표를 다시 잰다.** 위 값은 지금 그림의 첫 칸에서 잰 것이다 — 새 평상 자세가 오면 `tools/measure_stand_area.py`를 새 시트에 맞는
   `--dir` · `--frames` · `--frame`으로 돌려 표를 다시 옮겨 적는다(표에 없던 장수가 커지거나, 지금 줄인 장수가 더는 크지 않을 수 있다).
3. **권하는 방향(기획자 결정 필요):** 시트를 **구울 때**(`tools/build_action_sheets.py`) 장수별 크기를 맞춰 두면 메뉴 · 전투 판 · 큰 그림이 모두 같은 크기로
   나온다. 그러면 `STAND_SCALE` 표는 걷어도 된다(그때 이 표와 `OfficerStand`의 `transform` 한 줄을 함께 지운다). 화면에서 줄이는 지금 방식은
   메뉴에만 걸려 있다.
4. **곁가지:** `audio/attackSfx.ts`의 표는 `actions-hd/*.webp`의 **공격 칸(셋째)**을 보고 적었다 — 공격 칸 자리가 바뀌면 그 표도 본다.
