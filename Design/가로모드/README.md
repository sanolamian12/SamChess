## 지금 붙어 있는 것 (코드)

- **켜는 법**: 주소 `?orient=landscape` (기억됨) · `?orient=portrait`. 환경설정 단추는 아직 없다 — `screens/orientation.ts`의 `setOrientation()`을 부르면 된다.
- **프레임**: 가로는 화면을 꽉 채운다(16:9 ~ 2.2:1). 글자 기준 `rem = max(12px, 높이 / 40)` (`useFrameFit.ts`의 `LANDSCAPE_REM_DIV`) — 1080p에서 27px로 세로 최대 프레임과 같다. `--board` = 높이.
- **모양**: 전부 `packages/client/src/landscape.css`의 `:root[data-orient="landscape"]` 아래. `style.css`는 안 건드렸다(세로는 그대로).
  - 전투: 위 · 판 · 아래 → 왼쪽 · 판 · 오른쪽(90° 눕힘). 배치 · 정찰의 맞바꿈도 좌우로.
  - 장면 화면(현황 판이 화면 바로 밑): 왼쪽 = 뒤로 · 명패 · 현황, 가운데 = 그림, 오른쪽 아래 = 명령.
  - 목록 화면: 제목 한 줄, 큰 판(목록)은 왼쪽 단, 나머지 · 명령은 오른쪽 단(명령은 맨 아래).
  - 배경: 세로 그림을 가운데 기둥(높이 × 0.45)에 그대로 두고 양옆은 같은 그림을 흐리게(`.scr-art-fill`). **가로 그림이 오면** `.scr-art`를 화면 전체로 펴고 바탕 층을 걷는다.
  - 안내 내관 · 튜토리얼 말풍선: 오른쪽에 세로 모양 기둥(높이의 62%)을 세워 그 안에.
- **순회 통로**: 개발 서버에서만 `window.__screen.go(화면)` (`App.tsx`).

## 확정할 때 정할 것 (가안을 보며)

1. **글자 크기** — `LANDSCAPE_REM_DIV` 40. PC에서 크다/작다? 휴대폰 가로(최소 12px)는 목록이 빠듯하다.
2. **목록 줄 수** — 가로는 낮아서 쪽당 줄 수를 그대로 뒀다. 넓어진 폭으로 두 열 목록을 할지.
3. **전투 순서 판** — 가로에서 칸이 세로로 길어져 다섯 줄 아래가 빈다. 열 줄까지 보일지.
4. **수비군 설정 · 방어 기록**처럼 판때기가 셋 이상인 화면의 배치.
5. **메인 · 산 너머** — 새 그림을 「바깥 늘리기」로 받으면 핫스팟 좌표는 비율만 옮기고, 새로 그리면 다시 잡는다.
