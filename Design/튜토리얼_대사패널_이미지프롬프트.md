# 튜토리얼 대사 패널 — 이미지 생성 의뢰서 (2026-10-26)

S급 튜토리얼에서 안내 패널 사이사이에 **등장인물의 대사**를 띄운다. 왼쪽 정사각형 칸에 말하는 장수의 초상화를 넣고,
오른쪽 긴 판에 대사를 쓴다. 그림은 **두 장**을 만든다. 게임은 이 둘을 붙여 한 줄로 놓는다.

> ✅ **받음 (2026-10-26)** — 두 장 다 검은 바탕 JPG로 왔다(초상 액자 2048², 대사 판 4128×1024 — 판 자체는 약 7:1).
> `assets/icons/ui/dialog_portrait.jpg` · `dialog_line.jpg` → `npm run ui` → `public/ui/dialog-portrait.png`(480×477, 구멍 투명) ·
> `dialog-line.png`(1600×225). 화면은 `style.css`의 「튜토리얼 대사 패널」 절.

| 그림 | 비율 | 어디에 |
|---|---|---|
| ① 초상화 액자 | 1 : 1 | 왼쪽 — 액자 안에 그 장수의 수묵 초상(`public/battle/{id}.jpg`, 200×200 정사각형)이 들어간다 |
| ② 대사 판 | 4 : 1 (가로 : 세로) | 오른쪽 — 위쪽에 장수 이름, 그 아래에 대사 한두 줄(70자 이하)이 들어간다 |

```
┌────────┐┌──────────────────────────────────┐
│        ││ 조조                             │
│  초상  ││ 「천하의 영웅은 오직 그대와 이       │
│        ││   조조뿐이오.」                    │
└────────┘└──────────────────────────────────┘
   1 : 1                  4 : 1
```

- **비율은 4 : 1로 간다.** 700px 화면에서 액자 140px + 판 560px가 딱 맞고, 70자 대사가 두 줄에 들어간다.
  5 : 1로 하면 높이가 112px로 줄어 두 줄을 넣기가 빠듯하다. 판은 9분할로 늘려 쓰니, 4 : 1로 받아도 화면에서 4.5 : 1 정도로는 늘릴 수 있다.
- **글자는 그리지 않는다.** 이름과 대사는 게임이 글꼴로 얹는다. 열 개 언어로 바뀌어야 하고, 생성 도구는 글자를 틀리게 쓴다.
- **화풍은 지금 전투 UI와 같은 벌**이다. 짙은 가죽 바탕에, 붉은 옻칠이 벗겨진 테와 쇠 모서리 장식을 둔다(`panel-battle-officer.png`와 같은 재질).
  초상이 흰 종이에 그린 수묵이라, 액자 안쪽은 **종이를 끼우는 얇은 금빛 테**로 둔다. 그래야 밝은 초상이 짙은 판 위에서 떠 보이지 않는다.
- **아군과 적군은 같은 그림을 쓴다.** 진영은 게임이 이름 색(아군 남색 · 적군 붉은색)으로 가른다. 그림을 두 벌 만들면 한쪽만 낡는다.

## 납품 규격

| | ① 초상화 액자 | ② 대사 판 |
|---|---|---|
| 형식 | PNG, 투명 배경 | PNG, 투명 배경 |
| 크기 | **512 × 512** | **2048 × 512** |
| 안쪽 | **가운데 78%(약 400×400)가 완전히 투명한 구멍**이다. 초상은 그 뒤에 깔린다 | 안쪽은 **무늬 없이 평평한 가죽 · 종이 면**이다. 글자가 그 위에 앉는다 |
| 테 두께 | 사방 같게, 그림 폭의 약 11% | 위아래는 그림 높이의 약 11%, 좌우 끝은 그림 폭의 약 4%. 장식은 **네 모서리에만** |
| 파일 이름 | `dialog_portrait.png` | `dialog_line.png` |
| 놓는 곳 | `assets/icons/ui/` (다른 UI 원본과 같은 곳) | 〃 |

**② 판의 변 가운데는 장식 없이 곧게** 둔다. 9분할로 늘릴 때 변 가운데가 늘어나는데, 거기에 장식이 있으면 길게 뭉개진다.
장식은 모서리 안에서 끝낸다.

## 검수

- 두 장을 **나란히 붙였을 때 한 벌**로 보이는가. 테의 색 · 굵기 · 모서리 쇠붙이가 같은가. 다르면 접두는 그대로 두고 다시 뽑는다
- ① 가운데가 **정말 투명한가**. 반투명한 가죽이 남아 있으면 초상이 흐려진다. 투명 배경을 체크 무늬로 띄워 확인한다
- ② 안쪽이 **평평하고 비어** 있는가. 흰 글씨 두 줄이 올라가도 읽히는가
- ② 변 가운데에 **장식이 없는가**(늘렸을 때 뭉개지지 않는가)
- 글자 · 도장 · 숫자 · 사람 얼굴이 **하나도 없는가**
- 지금 전투 화면의 장수 판(`panel-battle-officer.png`) 옆에 놓아도 **같은 게임**으로 보이는가

## 받은 뒤 (개발 쪽 메모)

- 굽기는 `tools/build_ui.py`의 이름 표에 두 줄을 더한다 → `public/ui/dialog-portrait.png` · `dialog-line.png`
- 대본에는 안내와 대사를 나눠 적는다. 안내는 지금 그대로 `lines`에 두고, 대사는 **누가 하는 말인지** 장수 id를 함께 적는다.
  이름과 초상은 그 id로 찾는다(`combatantById` · `artKey()`). 도적은 `bandit` 그림을 쓴다
