## 모든 단계에 공통인 완료 조건

- `npm run typecheck` · `npm test` 통과.
- `npm run smoke:ui` **끝까지 완주** — 「화면 연동 스모크 통과」 줄을 보고 나서 통과라고 한다.
  단계가 바꾼 DOM에 맞춰 스모크를 **같은 세션에서** 고친다. 검사는 글자가 아니라 `data-*`로 건다.
- **700px 폭 스크린샷**으로 눈 확인(CLAUDE.md — 480px에서는 안 보이는 것이 있다) → 기획자에게 보여 준다.
- 도적떼 방어전(25×15 판)과 데모(`?demo=1`)도 같은 무대를 쓴다 — 한 번씩 띄워 본다.
- 이 파일의 표를 고치고, `history/`에 그 세션의 md를 남기고, 커밋·푸시.

### 2. 골격 — 세 칸 무대 ⬜

설계 §0 · §3.

- [ ] `screens/BattleStage.tsx`를 세 칸으로: `#top`(`#order` · `#gameinfo`) / `#board` / `#bottom`(`#cmd` · `#ctx`).
- [ ] 카드 줄(`#cards-north` · `#cards-south`, `ui/cardStrip.ts`)을 걷는다. `style.css`의 `#frame` 격자와
      `.strip` 높이(`--board × .415`)를 새 칸 높이로.
- [ ] **전투가 끊기지 않게** — 이번 단계에서 새 판은 빈 틀이어도 되지만, 옛 떠 있는 판(`#control` · `#prep` ·
      `#hud`)은 새 자리에 **임시로 담아** 한 판을 끝까지 둘 수 있어야 한다. 옮겨 담은 자리는 주석에 「임시 — N단계에서 갈음」.
- [ ] 스모크: 카드 줄 검사(`.uc` · `.strip`)를 걷고 새 칸 넷이 서 있는지·판이 정사각인지·판이 가려지지 않는지 건다.
- 완료 조건(공통 외): 3v3 · 5v5 · 도적떼 판에서 AI와 한 판을 끝까지 둔다.

### 3. 위 칸 — 순서 판 · 게임 정보 ⬜

설계 §1(90·92·93쪽) · §2(`turnForecast` · `skillStatus`).

- [ ] 순서 판: 배치 중 **전원**(두 줄 1~5 / 6~10), 전투 중 **지금부터 5번째까지**. 줄 = 순번 · 기물 · 이름 · WT · 표시등.
      아군 파랑 · 적군 주황. 지금 차례는 들여쓰기 + 큰 글씨, WT 칸은 「차례」. 나머지 WT는 **일, 소수 둘째 자리**.
- [ ] 표시등 다섯 색: 노랑 SP 부족 · 초록 준비 · 회색 사용 후 · **빨강 봉인** · 없음. 누르면 고유기술 설명(재생 없이 닫기만).
- [ ] 상태가 바뀔 때마다 예보를 다시 그린다(예보는 「다들 넘긴다」 가정이라 틀릴 수 있다 — 기획자 확정).
- [ ] 게임 정보: 전투 N일차 · 북군 SP(정수) · 턴오버 · 남군 SP · 턴오버 · 남은 시간.
      내 차례 [항복] / 상대 차례 [턴 가져오기](= `forceSkipTurn`, 20초 뒤 켜짐). **AI 대전은 남은 시간 `-` · [턴 가져오기] disabled.**
- [ ] 옛 HUD(`ui/hud.ts`)를 걷는다. ⋯(기록)은 6단계의 [...]로 가므로 그때까지는 임시 자리.
- [ ] 주사위 쪽지가 뜰 때 순서 판의 동점 줄을 함께 짚어 줄지 — 화면 보고 기획자와 정한다(설계 §5-1 끝).

### 4. 아래 칸, 전투 — 명령 판 · 맥락 판 ⬜

설계 §1(94~97쪽) · §3 · 「고유기술 물음」.

- [ ] `ui/controlModal.ts`(977줄)를 **흐름(상태 기계)과 그리기**로 가른다. 조준 후보·켜짐은 엔진(`commandsFor` · `castCandidates`).
- [ ] 왼쪽 명령 판: **첫 줄 「명령을 선택하세요」**, 그 아래 6칸(이동 · 공격 / 명상 · 책략 / 아이템 · 대기).
- [ ] **[이동]을 눌러야 이동 범위가 깔린다** (지금은 차례가 오면 바로 깔린다).
- [ ] 오른쪽 맥락 판: 명령 전 **비어 있음** → 「이동할 위치를…」·「공격할 대상을…」·「대상을…」+[취소] → 확인창.
- [ ] 확인창 넷: 책략·아이템(성공확률 `illusionChance`) · **공격(데미지 범위 · 치명타, `forecastAttack`)** ·
      **명상(「MP를 N 회복합니다」, `meditateGain`)** · **대기(「차례를 마칩니다」)**. 공격·명상·대기 확인은 새로 생긴다.
- [ ] 고유기술 물음 패널(오른쪽): 「고유기술을 쓰시겠습니까?」 / 배너(누르면 상세, 애니메이션 없음) / [사용 (SP n)] / [미사용].
      이때 왼쪽은 **내 장수 카드**. [사용]·[미사용] 뒤에야 명령 6칸.
- [ ] 적 차례: 왼쪽 = 지금 차례 적 장수 카드, 오른쪽 = 대상을 고르기 전 **비어 있음** → 지목된 대상 카드.
- [ ] 장수 카드 컴포넌트를 **하나** 만든다(6단계 팝업도 쓴다). 속은 `InspectPanel`의 그리기.
- [ ] 옛 `#control` · `#dialog`(`.cast-confirm` · `.ctl-prompt`)를 걷는다. 스모크의 `#control` 20곳 · `.cast-confirm` 11곳을 옮긴다.

### 6. 판 위 ⬜

설계 §1(98쪽) · 「전투 기록 [...]」.

- [ ] 시스템 메시지: 판 **왼쪽 위**, 동시에 최대 3줄, 새 줄이 밀어 올린다(`ui/systemLog.ts` 표시부).
- [ ] 그 자리 **첫 줄**에 `[...]` — 로그가 찍히는 동안 숨고, 다 찍히면 드러나 누르면 전투 기록. 항복은 기록에서 빠진다(3단계에서 게임 정보로 갔다).

- [ ] 「상태 배지 설명」 스모크가 **개편 전부터 건너뛰고 있다**(그 순간 걸린 상태가 없다) — 상태를 걸어 두고 실제로 돌게 만든다.
