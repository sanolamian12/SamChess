## 프롬프트 (복사해서 쓰기)

```
전투 화면의 다국어를 붙이자. 지금 메타 화면(도시·궁궐·대장간 등)은 t()로 열 언어를
쓰는데, 전투 화면만 문장이 코드에 한국어로 박혀 있다.

시작 전에 CLAUDE.md와 Design/GDD.md를 읽고, 아래 두 문서도 본다:
  history/2026-09-10_대장간_실제플레이확인_제조기간분단위_장비다국어_카드레이아웃.md
  docs/NEXT_전투UI_다국어.md   ← 이 파일. 실측 수치와 갈림길이 적혀 있다

핵심 갈림길 셋을 먼저 정하고 시작해라 (내 답이 필요하면 물어라):

1. 조사(josa) — packages/client/src/ui/eventText.ts의 josa()는 한국어 전용이다.
   「누가 무엇을 했다」를 언어마다 어순이 다르게 짜야 해서, 값만 갈아 끼우는
   장비 이름 다국어와는 성격이 다르다. 문장을 통째로 t() 키 하나로 두고 각
   언어가 제 어순으로 쓰게 할 것인지(권장), 조각을 조립할 것인지 정해라.

2. 엔진이 들고 있는 한국어 이름표 — packages/rules/src/types.ts의
   STATUS_META(22개)·TERRAIN_META(3개)가 label·desc를 한국어로 갖고 있다.
   룰 엔진은 UI 언어를 알면 안 되므로(CLAUDE.md의 계층 규칙), 화면이 id로
   다시 고르는 방식이 맞다 — 책략 칩이 이미 그렇게 한다
   (packages/client/src/i18n/story.ts의 pickTacticNameById 주석 참조,
   그게 없어서 카드의 책략만 혼자 한국어로 떠 있던 사고가 있었다).

3. 범위 — 아래 §범위의 15개 파일을 다 할지, eventText.ts(로그)만 먼저 할지.
   controlModal.ts가 46개로 가장 많고 eventText.ts가 45개다.

지켜야 할 것:

- 전투 로그 문구를 고정한 회귀가 하나도 없다. describeEvents()를 부르는 검사가
  0건이라, 실제로 최근에 같은 문구가 두 자리(본문·시전 요약)에 있는 것을 놓쳤다가
  우연히 잡았다. 이번 작업에서는 검사를 먼저 만들고 옮겨라 — 안 그러면 옮기다
  빠뜨려도 아무도 안 잡는다.
- 한 문장이 두 자리에서 만들어지는 경우가 있다(위 사고). t() 키로 옮길 때
  같은 사건을 적는 자리가 더 있는지 확인해라.
- 새 키는 ko.json에 먼저 넣고(그것이 StringKey의 출처다) 열 언어를 채운다.
  ko.json에 없는 키를 t()로 부르면 타입 검사가 잡는다.
- 검증은 npm run typecheck · npm test · npm run smoke:ui 셋이다. smoke:ui는
  전투 화면을 실제로 도는 유일한 검사이니 언어를 바꿔 가며 돌 수 있는지 봐라.

주의: 이 저장소의 다른 언어 json에는 이미 키 222개가 빠져 있다(도시·부대·전적·
장터 등 메타 화면). 이번 작업과 무관한 기존 구멍이니 섞지 말고, 손대려면 따로
얘기해라.
```

### 어려운 자리 셋

**1. 조사가 한국어 전용이다.** `eventText.ts`의 `josa()`는 받침을 보고 「이/가」를
고른다. 이건 **문장을 조각으로 조립한다**는 전제 위에 있는데, 다른 언어는 어순이
달라 같은 조각 순서로 못 만든다. 장비 이름·효과 다국어(2026-09-10)는 **값만**
갈아 끼우면 됐지만 이쪽은 문장 구조가 언어마다 바뀐다.

**2. 엔진이 한국어 이름표를 갖고 있다.** `packages/rules/src/types.ts`의
`STATUS_META`(22개) · `TERRAIN_META`(3개)가 `label`·`desc`를 한국어로 들고 있고,
화면은 그걸 그대로 찍는다(`TERRAIN_LABEL`이 `TERRAIN_META`에서 만들어진다).
룰 엔진이 UI 언어를 알면 계층이 깨지므로 **화면이 id로 다시 고르는** 방식이 맞다.
`story.ts`의 `pickTacticNameById`가 정확히 그 사연으로 생겼다 — 그게 없어서 장수
카드의 책략 칩만 혼자 한국어로 떠 있었다(2026-09-03).

**3. 회귀가 없다.** `describeEvents()`를 부르는 검사가 **0건**이다. 실제로
2026-09-10에 「성지가 생겼다」 문구를 고치면서 **같은 문구가 두 자리**(본문
`describeEvents`, 시전 요약 `collectEffects`)에 있는 것을 놓쳤다가, 한국어
리터럴을 세다가 우연히 발견했다. 옮기는 작업은 빠뜨리기 쉬우므로 **검사를 먼저**
만드는 편이 안전하다.

### 섞지 말 것

다른 언어 json에 **이미 키 222개가 빠져 있다**(`ko.json` 433개 기준). `city`·
`squad`·`records`·`market`·`result` 등 **메타 화면**의 기존 구멍이고 전투와 무관하다.
이번 작업으로 새로 생긴 것이 아니므로 함께 세지 말 것.
