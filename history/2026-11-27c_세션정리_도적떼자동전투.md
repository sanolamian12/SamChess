> 「도적떼 출몰!」 팝업을 세로로 늘려 [지금 전투]와 [닫기] 사이에 노란 두루마리 [자동 전투](아이콘 `ic_opp_ai`)를 넣는다.
> 누르면 아군 · 적군 전투력으로 결말을 예측하는 다이얼로그를 하나 더 띄우고, 직접 전투는 건너뛴다.
> 승리 예측이면 군량을 안 빼앗기는 대신 보상도 없고, 패배 예측이면 실행할 때 군량을 빼앗긴다.
> — 오래 하다 보면 「군량은 지키고 싶은데 전투는 번거로운」 때를 위한 편의.

## 이 세션에서 정한 것 (기획자에게 알렸고 그대로 두기로 함)

| 결정 | 까닭 |
|---|---|
| 동점은 패배 | 도적이 버틴다고 본다 — 경계에서 공짜 승리가 안 나게 |
| 보초병이 없어도 누를 수 있다(아군 0 → 언제나 패배) | 항복과 같은 결말이라 막을 이유가 없다 |
| 패배 약탈 = 항복 약탈(출몰한 도적 전부) | 「직접 싸워 지면 살아 남은 도적만큼」보다 크거나 같다 — 자동이 직접 전투보다 싸지 않게 |
| 전투력은 대전의 `unitPower`, 계수는 도적 수의 모드 하나로 양쪽 | 새 눈금을 만들지 않는다. 성채 · 판 크기 · 부상 · 컬렉션은 안 본다 |
| 화면의 예측과 서버의 정산이 같은 함수, 다르면 409 `raid.autoChanged` | 판을 연 뒤 보초병을 바꾸면 「본 것과 다른 결말」이 날 수 있어서 |
| 결말은 `won` / `lost` + `auto: true` | 새 상태를 만들면 농지 현황 · 메인 · 소리 · 관리자가 모두 한 갈래씩 더 가져야 한다 |

도적 전투력(레벨 = 농지 레벨): 1~5명 = **100 · 261 · 443 · 473 · 648**. Lv1 장수 한 명의 3v3 전투력은 20 ~ 295(중앙 182)라,
농지 Lv1 도적 하나는 웬만한 장수 하나로 「승리 예상」이 나온다.
