# 2026-09-16 부대 저장(배치에서 확정) · 고유기술 음향 누락 · 연출 중 배경음악 정지

전날 붙인 두루마리 연출([2026-09-15](2026-09-15_고유기술연출_두루마리개편.md))을 기획자가 실제로
플레이해 보며 나온 셋을 고쳤다. **셋 다 「화면은 아무 말도 안 하는」 부류다.**

## 1. 편성한 부대가 저장되지 않았다 — 단추가 화면 밖으로 밀렸다

기획자 보고는 「부대를 편성했는데 저장이 안 된다」였다. **재현되지 않았다** — 코드도 데이터도
멀쩡했고, 기획자가 스스로 원인을 찾아냈다: **보유 장수가 늘자 편성 화면의 [등록 완료]가 화면
아래로 밀려 안 보였고**, 대신 누른 [목록으로]는 저장하지 않는 단추였다.

**고친 방법** — 배치(남군·북군) 편집기의 [저장]이 **부대까지 확정하고 목록으로 간다**
(`SquadEditScreen`의 `deploySide` 분기). 구성이 아직 성립하지 않으면 예전처럼 편성 화면으로
돌아간다. 배치를 마친 사람이 저장할 길을 잃지 않는 것이 요점이다.

- **[등록 완료]가 밀리는 layout 자체는 그대로다** — 알고 남긴 것. 기획자에게 알렸다.
- 한 번의 [저장]은 한쪽 진영만 확정한다(목록으로 나가므로). 양쪽을 넣으려면 다시 연다.
- `smoke_meta.ts`의 `makeSquad(..., deploy: true)`가 이제 [등록 완료]를 안 누르고
  **목록으로 갔는지**를 본다 — 안 고쳤으면 없는 단추를 누르며 30초 기다렸을 것이다.

### 찾아가는 길에 확인한 것 (원인은 아니었다)

- 계정(「테스트도시」)의 `squads` 0 · `squadSeq` **1** — 저장됐다 지워진 것이 아니라 **한 번도
  도착하지 않았다**. 이 한 값이 「덮어썼나」를 먼저 지웠다.
- 그 프로필을 **임시 계정에 복제해 실제 화면으로** 부대를 만들어 보니 `PUT /profile → 200`,
  DB `squads` 1. 계정 데이터·서버 코드 둘 다 무죄. (임시 계정은 지웠고 원본은 읽기만 했다.)
- `npm run smoke:meta` 통과 — 새 계정의 부대 만들기·삭제·수정·배치는 멀쩡했다.

### ⚠ 남은 진짜 구멍 — 저장 실패가 화면에 안 뜬다

`storage.ts`의 `saveProfile()`은 어떤 실패든 **`console.warn` 한 줄**로 삼키고 `offline = true`만
켠다. 그런데 **그 깃발을 읽는 화면이 하나도 없다**(`isOffline()`을 부르는 곳은 개발용 통로뿐).
토큰 갱신이 실패하면 `getAccessToken()`이 조용히 `signOut()`까지 하므로, 그 뒤로는 **모든
저장이 실패하는데 화면은 평소와 똑같다.** 이번 건의 원인은 아니었지만 **다음 「저장이 안 돼요」는
이것일 수 있다.** 고치자고 제안해 두었다(미결).

## 2. 「용맹전진」에 성우 대사가 없었다 — 코드가 아니라 **빌드를 안 돌린 것**

원본 `assets/Audio/Specialskills/{5개 언어}/`에는 40종이 다 있는데 `public/skillvoice/`에는
**135개(27종)뿐**이었다. 더빙이 늘어난 뒤 `npm run audio`를 안 돌려 **13종이 무음**이었다.
돌리니 200개(40종 × 5언어)가 됐다.

**곁가지로 하나 더** — 전날 새로 연결한 두루마리 시작 효과음 `specialskillstart.mp3`도
`public/effects/`에 없었다(같은 이유). 즉 **어제 「소리가 난다」고 적은 그 소리가 실제로는
안 나고 있었다.** 스모크는 소리를 못 듣고, `playSfx`는 404를 조용히 넘긴다(설계대로다) —
**「원본에 있는데 public에 없다」를 아무도 안 본다**는 것이 이번에 드러난 자리다.

## 3. 연출이 도는 동안 배경음악을 멈춘다 (기획자 지정)

전투 배경곡 위에 시작 효과음과 대사가 겹쳐 대사가 묻혔다.

- `bgm.ts`에 `holdBgm(on)` 신설 — **끄는 것(`playBgm(null)`)이 아니라 멈춤**이다. 같은 곡을
  **멈춘 자리에서 이어서** 튼다(되감으면 8초마다 곡 머리가 반복된다). 붙들린 동안 곡이 바뀌면
  이름만 기억했다가 풀릴 때 새 곡을 튼다. 페이드는 250ms — 곡 넘김(700ms)보다 짧아야 시작
  효과음과 덜 겹친다.
- `SkillFx`에 `end` 큐를 더해 **걷히는 프레임**에 알린다. `play()`가 내부에서 부르는
  `finish(false)`는 안 알린다 — 연출이 잇따르면 배경음악이 껐다 켜졌다 한다.
- 씬이 `start → holdBgm(true) + 시작 효과음`, `action → 성우`, `end → holdBgm(false)`로 잇는다.

**실제 브라우저에서 잰 순서**(오디오 `play`/`pause`를 가로채 기록):

| 연출 기준 시각 | 소리 |
|---|---|
| 0.00초 | 시작 효과음 |
| 0.28초 | 배경음악 멈춤 (250ms 페이드) |
| 1.61초 | 성우 대사 (두루마리가 다 펴진 뒤) |
| 8.21초 | 배경음악 재개 |

## 검증

- `npm run smoke:meta` 통과 — 배치 [저장] → 목록 확인 포함
