# 평타 효과음 — 무기별 네 가지 (2026-10-12)

평타 소리는 장수와 상관없이 `battle_attack` 하나였다. 기획자가 `assets/Audio/effects/`에 `attack_fist` · `attack_sword` ·
`attack_arrow` · `attack_chain` 넷을 넣었고, **판 위 장수 그림이 무엇으로 때리는가**로 갈라 연결했다. 작업 브랜치 `result-screen-design`.

## 1. 기획자 지정

| 무기 | 소리 |
|---|---|
| 주먹 · 부채 | `attack_fist` |
| 칼 · 창 | `attack_sword` |
| 활 | `attack_arrow` |
| 유성추(감녕) | `attack_chain` |
| 그 밖 | `battle_attack` 그대로 |

## 2. 분류 — 그림을 하나씩 봤다

`public/actions-hd/*.webp` 261장(장수 260 + 도적 `bandit` 한 벌)의 **공격 칸(셋째)**을 6×4 접촉 시트로 찍어 훑고,
애매한 50장은 320px로 키워 다시 봤다.

| 소리 | 수 | 들어간 것 |
|---|---|---|
| fist | 110 | 맨주먹, 부채(학우선 · 파초선 · 접부채) |
| sword | 108 | 칼 · 단검 · 창 · 삼지창 · 극 · 도끼 · 구겸(장획) · 방패 든 칼(왕평), 도적 |
| arrow | 3 | 하후연 · 주유 · 마충 |
| chain | 1 | 감녕 — 기억대로 유성추는 감녕뿐이었다 |
| 그대로 | 39 | 두루마리 · 붓 · 피리 · 지팡이 · 몽둥이(허저 · 고패 · 사마사 · 서상) · 채찍(채훈 · 송비 · 양송) · 방패(양망) · 옥새(원술) · 책(미축) |

판단으로 정한 것(기획자 승인):

- **황충은 칼 소리** — 활을 등에 멨지만 공격 칸은 단검 둘이다. **정본은 사서가 아니라 그림**이다.
- 도끼 · 극 같은 날붙이 장병기는 「칼이나 창」에 넣었다.
- 책사는 **부채면 주먹 쪽, 두루마리 · 붓이면 그대로**. 가후 · 제갈근 · 곽가처럼 부채인지 붓인지 애매한 그림은 부채로 봤다.

분류 스크립트로 다섯 묶음의 합이 그림 261장과 정확히 맞는지(중복 · 누락 · 없는 id 0)를 확인했다.

## 3. 코드

- `packages/client/src/audio/attackSfx.ts`(새) — `FIST` · `SWORD` · `ARROW` · `CHAIN` 표와 `attackSfxFor(officerId)`.
  열쇠는 장수 id가 아니라 **`artKey()`** — 도적 다섯이 `bandit` 한 벌을 함께 써서 소리도 같다. 표에 없으면 `battle_attack`.
- `audio/sfx.ts` — `SfxId`에 넷을 보탰다. 파일 이름이 곧 id라 `npm run audio`가 `public/effects/`로 그대로 옮긴다.
- `battle/BattleScene.ts`의 `playSoundCue` — `attackHit` 큐에서 `cue.ev.unit`의 장수를 찾아 고른다.
  쓰러진 장수도 `state.units`에서 빠지지 않아 찾기가 늘 성공한다(못 찾으면 옛 소리).
- `test/attackSfx.test.ts`(새) — 표의 열쇠가 **전부 실제 그림 열쇠인가**. 철자가 틀린 id는 오류 없이 옛 소리로 떨어져
  「그 장수만 안 바뀐다」로만 보이기 때문이다. 기획자가 짚은 자리(감녕 · 하후연 · 관우 · 제갈량) · 그 밖(채훈 · 법정) · 도적도 고정한다.
  **「누가 무슨 무기인가」 자체는 회귀가 못 지킨다** — 그림을 새로 구우면 표도 다시 본다.

## 4. 검사

- `npm run typecheck` 통과 · `npm test` **836 / 836**.
- `npm run audio`로 mp3 넷을 `public/effects/`에 옮겼다.
- 소리는 헤드리스에서 못 듣는다 — 실제 전투에서 귀로 확인은 기획자가 했다(「잘 적용했어」).

## 5. 남은 것

- `npm run audio`가 매번 「매칭 못한 고유기술 성우: 화용도의석조조_*」를 찍는다 — 이번 작업과 무관, 원래 있던 경고.
- 그림이 바뀌거나 새 장수가 들어오면 `attackSfx.ts` 표를 다시 채운다(빠지면 옛 소리로 조용히 물러난다).
