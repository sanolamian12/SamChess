## 2. 「이각」 — 되돌리는 절차가 미리 적혀 있었다

`assets/Chars/` 파일명을 표기 표준으로 삼는 규칙(GDD §9) 때문에, 당시 파일명이었던
`이곽.png`가 역사 표기 `이각(李傕)`을 밀어내고 표준이 되어 있었다.

**그런데 초상화 파일은 이미 `이각.png`로 바뀌어 있었다.** `Chars/`와 `Chars-noback/` 양쪽
모두 `이각.png`인데 데이터만 `이곽`을 가리켰다. 앞선 세션(`Chars → Chars-noback`)에서
파일명 쪽만 반쯤 되돌아간 것으로 보인다.

> **커밋된 `build-report.json`의 `problems: []`를 믿으면 안 된다.** 그건 파일명을 바꾸기
> 전에 생성된 것이었다. 추출기의 이미지 대조는 양방향(`names - images`, `images - names`)이라
> 실제로 돌렸으면 2건이 fail로 잡히고 exit 1이 났을 상태였다.
> **에셋을 손댔으면 `npm run extract`를 다시 돌려야 한다.**

되돌리는 절차는 GDD §9와 HANDOFF에 이미 적혀 있었다 — 파일명 + `NAME_FIXES` 두 곳.
그대로 따랐고, id는 이름 슬러그라 `i-gwak` → `i-gak`으로 함께 바뀌었다.
`i-gwak`을 참조하는 코드는 없어 마이그레이션은 없었다.

남은 정규화 3건(`관훙→관흥` · `장노→장로` · `장요→장료`)은 파일명이 바른 표기 쪽이라 그대로 둔다.

## 3. 기획자가 내린 결정 — 시간 표기

**확정: `time`은 엔진 안에서만 쓴다. 플레이어에게 보이는 글은 전부 일(日)이다.**

근거가 되는 환산은 이미 확정돼 있었다 — `time 100` = 게임 내 1일 = 실시간 1초.
`WT`도 같은 단위라 `WT 100` = 1일이다.

| 대상 | 전 | 후 |
|---|---|---|
| 지속시간 | `time 190 동안` | `1.9일 동안` |
| 주기 | `time 100마다` | `1일마다` |
| 대기시간 증감 | `waiting time -100` | `WT −1일` |

**`waiting time`이라는 영문을 `WT`로 통일한 이유** — 용어표(§2) · 책략표(§3.7) ·
유닛 타일의 세 번째 바가 전부 `WT`인데 설명문만 영문이었다. 플레이어가 설명에서 읽은 말과
화면에서 보는 바의 이름이 같아야 한다. 「대기시간」도 후보였지만 타일 바 라벨이 `WT`인 이상
그쪽에 맞춰야 표기가 하나로 떨어진다.

**엔진 단위를 남긴 곳** — GDD §3.3의 `WT = 190 − 통솔력` 기준값 표와
`time 90/190/290/490` ↔ 1/2/3/5 사이클 대응. 여기서 숫자를 일로 바꾸면
`1.9 − 통솔력/100`이 되어 근거가 읽히지 않는다.

## 4. 구조에서 기억할 것

**변환은 출력 직전 한 번만 한다.** `to_days()`가 `build_tactics()`와 `extract_skills()`
두 곳에서만 불린다. 소스(엑셀 스킬 시트 · `TACTICS` 리터럴)는 `time` 표기 그대로다.

이유는 두 가지다.
- 엑셀은 읽기 전용이라 애초에 손댈 수 없다. 스킬 설명은 시트에서 그대로 읽어 오므로
  **출력 직전 정규화가 유일한 경로다.**
- `TACTICS`는 PPT 원문을 옮긴 것이라 대조할 때 원문형이 편하다.

→ 부작용: `grep "1.9일"` 로는 소스를 못 찾는다. `time 190`으로 찾아야 한다.

**정규식 두 개가 서로 간섭하지 않는다.**

```python
_WT_RE   = re.compile(r"\bwaiting\s+time\s*([+\-])\s*(\d+)")
_TIME_RE = re.compile(r"\btime\s*(\d+)(\s*마다)?")
```

`_TIME_RE`가 `waiting time -100`을 잡을 것 같지만, `time ` 뒤가 `-`라 `(\d+)`에서 막힌다.
`waiting time + 110`(부호 뒤 공백)도 `_WT_RE`가 흡수한다 — 엑셀에 실제로 이렇게 적혀 있다.

**「마다」만 붙여 쓴다.** `(\s*마다)?`로 뒤따르는 「마다」를 같이 먹어 `time 200 마다` →
`2일마다`가 된다. 「동안」·「안에」·「후」는 띄어 쓰는 자리라 공백을 남긴 채 놔둔다.
이걸 구분 안 하고 `\s*`로 뭉뚱그리면 `1.9일동안`이 나온다.

**부호는 U+2212(`−`)다.** GDD 표기와 맞췄다. ASCII 하이픈은 폭이 달라 표에서 섞이면 눈에 띈다.
