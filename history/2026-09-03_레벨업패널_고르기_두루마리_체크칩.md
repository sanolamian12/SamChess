# 2026-09-03 — 레벨업 「고르기」 판, 두루마리·체크 칩으로 다시 그리다

> 현재 상태는 [`HANDOFF.md`](../HANDOFF.md)에, 사양은 [`Design/GDD.md`](../Design/GDD.md)에
> 있다. 이 문서는 **왜 그렇게 정했고 무엇을 확인했는가**만 적는다.

## 1. 요청

궁궐 → 장수 일람 → 장수 카드 → [레벨/스킬 관리]가 여는 판(`LevelUpPanel`)의
**「고르기」 걸음**(레벨 업을 누른 뒤 능력 택1 + 책략 택1을 고르는 화면)이
궁궐 나머지와 화풍이 달랐다. 스크린샷을 주고받으며 일곱 차례에 걸쳐 다듬었다 —
아이콘 입히기 → 위치·체크 칩 → 두루마리 두 장 → 증분 표기 → 소모 MP.

「고르기」 UI(`Picker`)는 전면 화면(`LevelUpScreen`)과 **같은 컴포넌트**라
구조 변경은 양쪽에 다 간다. 화풍(그림·색)만 `.scr-officers`로 좁혔다 —
전면 화면은 아직 이 리스킨 대상이 아니다(「화면 하나씩」, 2026-09-02부터의 방침).

## 2. 화면이 어떻게 바뀌었나

| 자리 | 전 | 후 |
|---|---|---|
| 판이 뜨는 y | 카드 그림 아래(`'art'`) | 카드 시작점(`'top'`) — 여유가 커져 판 안 스크롤이 잘 안 생긴다 |
| HP·MP·AT 줄 | 어두운 상자 하나 | 칸(80%) + 체크 칩. 켜짐은 `icons/confirm.png` 하나로 |
| 책략 택1 | 이름 단추 둘 **나란히** + 설명 상자 **따로** | **두루마리 두 장이 위아래로** (위 지원책 · 아래 환술) |
| 두루마리 안 | — | 이름 + `(MP: n)` + 체크 칩 / 설명 / 발동 조건 |
| [뒤로] | 있음 | 없음 — 우상단 [X]가 그 자리다 |

## 3. 「고른 줄만 초록으로 칠하기」를 걷어낸 이유

체크 칩이 생기기 전까지는 선택 표시가 배경색뿐이었다. 칩이 생긴 뒤에도 칠이
남아 있으니 **짙은 초록 위에 먹색 글자**가 되어 되레 안 읽혔다("초록색 음영
때문에 글자가 더 안 보이고 있어").

칠의 출처는 내가 쓴 규칙이 아니라 **공용 `.opt.on`**(`background: #1e3a2f`)이었다.
`button.lv-stat-row`(0,0,1,1)로는 `.opt.on`(0,0,2,0)을 못 이겨,
`button.lv-stat-row.on`처럼 **`.on`까지 적은 선택자**로 따로 눌러야 했다.
`color`는 일부러 안 건드렸다 — `inherit`로 되돌리면 `.place-panel`의
크림색(어두운 화면 기준값)을 물려받아 양피지 위에서 또 안 보인다.

## 4. 회색 증분과 실제 결과는 **다른 값**이다 ★

처음엔 안 고른 줄이 `+0`으로 보이는 게 아깝다는 요청("실제 증가값을 표시하되
색만 옅은 회색으로")을 받아, 줄마다 `growthPreview(inst, 그 줄의 stat)`을 물어
그 줄만 꺼내 썼다. 그랬더니 **결과 칸까지 가정치가 됐다** — `MP 5 +2 → 7`.
실제로 오르는 건 고른 하나뿐이므로 이건 거짓말이다.

칸마다 뜻을 갈라 다시 적었다:

| 칸 | 뜻 | HP를 골랐을 때 MP 줄 |
|---|---|---|
| `now` | 지금 값 | `5` |
| `add` | **고르면** 오를 양 — 회색, 실제로는 안 더해진다 | `+2` |
| `next` | **실제로** 적용될 값 — 안 고른 줄은 `now` 그대로 | `5` |

구현은 `next`·`range`를 「지금 고른 것」 기준(`growthPreview(inst, stat)`)으로
그대로 두고 **`add`만 줄마다 따로 물어 얹는다**. 어느 쪽이든 숫자를 내는 것은
언제나 엔진이다 — 화면이 증분을 다시 계산하지 않는다는 규약은 그대로다.

**화면만 봐서는 그럴듯해서 안 걸리는 종류의 거짓말**이라 스모크에 못을 박았다 —
「안 고른 줄의 결과 칸은 지금 값 그대로」 · 「고른 줄은 결과가 늘어 있다」.

## 5. 두루마리 두 장 — 「높이가 흔들리는 문제」가 애초에 사라졌다

원래는 이름 줄(택1 단추)과 설명 상자가 따로였다. 고른 쪽 설명만 보이니 둘을
견주려면 번갈아 눌러야 했고, 글 길이에 따라 상자 높이가 흔들려 **그걸 막는
장치**(`.lv-desc-stack` — 두 설명을 같은 그리드 칸에 겹쳐 두고 안 고른 쪽만
`visibility: hidden`으로 숨겨 늘 더 긴 쪽 높이를 쓰게 하는)까지 만들어 뒀었다.

두루마리 두 장으로 바꾸면서 **둘 다 늘 펼쳐지니 견주기도 되고 높이도 애초에
안 흔들린다** — 그 장치는 같이 지웠다. 「문제를 푸는 장치」보다 「문제가 생기지
않는 배치」가 먼저다.

설명 안의 이름 칩(`<b class="chip">증폭</b>`)도 뗐다 — 이름이 두루마리 제목으로
올라갔으니 같은 화면에 두 번 적힌다.

## 6. 발동 조건은 **공식을 말로 옮긴 것**이라 못을 박아 뒀다

두루마리 셋째 줄에 학파별 발동 조건을 적었다(책략마다가 아니라 **학파마다
하나**다).

- 지원책 — `발동 % = (자신의 지력 + 아군의 지력) %`
- 환술 — `발동 % = (자신의 지력 - 적군의 지력 + 20) %`

엔진과 대조해 확인했다 — `FORMULA.supportRate`는 `clamp(0,100, 자신 + 대상)`,
`FORMULA.illusionRate`는 `clamp(0,100, 20 + 자신 − 대상)`으로 문구와 일치한다.
다만 이건 **숫자가 아니라 공식의 서술**이라 공식이 바뀌면 조용히 어긋난다
(실제 확률은 전투에서 `illusionChance()`가 대상까지 보고 낸다). CSS와 TSX
양쪽에 「출처는 `FORMULA.*`이고 바뀌면 `levelup.trigger.*` 열 언어를 같이
고쳐야 한다」고 적어 뒀다.

## 7. 책략 이름·설명의 다국어 — **배선만** 해 뒀다

이 판의 라벨은 이미 `t()`를 지나고 있었지만 **책략 이름·설명은 아니었다** —
`TacticData`에 `nameI18n`/`textI18n` 필드 자체가 없었다. 고유기술은
`assets/Languages/sam_skills.csv`라는 언어별 소스가 있는데 책략에는 없다.

번역 원본이 없으니 지금 채울 수 있는 것은 없다 — 그래서 **화면 쪽 배선만**
했다(사용자 확인 후 결정). 필드를 옵셔널로 더하고
`pickTacticName()`/`pickTacticText()`(`i18n/story.ts`)를 `pickSkillName`과
같은 규약으로 만들어 이 화면 전체에 통과시켰다. 지금은 언제나 한국어로
물러나지만, 소스가 생기면 **화면 코드는 다시 안 고쳐도 된다.**

## 8. 밟은 지뢰

- **주석을 잘못 닫아 규칙이 통째로 버려졌다.** 이미 `*/`로 끝난 주석 뒤에
  설명 세 줄을 덧붙였더니, CSS 파서가 그 글과 뒤따르는 `.lv-pick > .k { … }`를
  **한 덩어리로 삼켜** 규칙을 버렸다. 증상은 「글씨는 커졌는데 아이콘만
  사라졌다」 — `display: inline-flex`가 날아가 `.k`가 인라인 상자가 되자
  **인라인 요소에 안 먹는 `::before`의 `width`/`height`**가 무시된 것이다.
  CSS는 깨져도 오류를 안 내므로 화면을 봐야만 안다. 그 규칙에
  「`inline-flex`가 요점」이라는 경고를 달아 뒀다.
- **DOM을 나누면 스모크가 보던 자리가 바뀐다.** 한 줄을 「바깥 단추 + 안쪽 칸」
  으로 가르면서 `data-stat`·`.on`이 바깥으로 옮겨 갔는데, `smoke_meta.ts`는
  `.lv-stat`(이제 안쪽 칸)에서 그걸 읽고 있었다. 셀렉터를 `.lv-stat-row`로
  옮겼다 — 검사가 보는 것은 「줄」이지 「칸」이 아니다.
- **`stat_frame_raw.png`은 안 맞았다.** 정사각 금테 액자라 납작한 줄에 씌우니
  네 귀퉁이 장식이 짓눌렸다. **일단 배경 그림 없이** 두고,
  `docs/PROMPT.md`에 「능력치 줄 명패」 절(가로 5:1 · 밝은 나무색 · 좌우 테두리를
  위아래보다 얇게)을 새로 적었다. `build_ui.py` 배선과 CSS 두 줄은 주석으로
  남아 있어 그림만 오면 바로 붙는다.
