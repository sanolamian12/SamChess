# 2026-09-24 장터/상점 UI 재구성 — pptx 75~88쪽 「UI update 260924」

기획자가 pptx에 장터 목업 13쪽(76~88)을 더하고 열두 가지를 덧붙였다. 앞 세션들(09-23 두 번)이
장터를 「현황판 + 명령 셋」으로 세우고 아이템 16종을 붙여 놓은 자리에, **화면 전개를 목업
그대로** 다시 세웠다. 도중에 규칙 셋이 바뀌었고(8연 · 카드 정리 · 초기화 아이템), 뽑기 섬광을
생성 AI 그림 대신 **직접 그렸다.** 디테일 손질은 다음 세션으로 넘겼다.

## 3. 규칙이 바뀐 것

- **8연 72냥** — `economy.json`의 `gachaPull.ten` → **`multi`** `{gold: 72, count: 8}`. 키 이름을
  바꿨다 — 수가 또 바뀌어도 이름이 거짓말을 하지 않게. `GachaPullKind`도 `'single' | 'multi'`.
- **카드 정리** — `recyclableCards()`가 풀 장수는 전부, 보관함 장수는 1장 남기고. 다 쓴 칸은
  지운다. **`recycleSources()` 신설** — 쓸 카드가 3장 이상 **이고 같은 등급에 받을 장수가 있는**
  풀 장수(골라 놓고 막히지 않게). 받을 장수는 기존 `recycleTargets()`에서 자신을 뺀 것.
- **아이템 장바구니** — `canBuyMarketBasket()`/`applyBuyMarketBasket()`/`marketBasketGold()` +
  `POST /market/items`. 한 개씩 `canBuyMarketItem()`을 지나며 **앞의 것을 적용한 상태에서** 다음을
  보므로 「하나하나는 되는데 합치면 금화·자리가 모자란다」를 잡는다. **전부 사거나 아무것도 안 산다**
  — 한 개짜리를 여러 번 부르면 가운데서 막혔을 때 반만 산 채로 남는다.
- **초기화 둘은 장터에서 사서 바로 쓴다** — 서버 경로(`/academy/reset`·`/officer/respec`)는 이미
  있었다. 화면만 옮겼고 `LevelUpPanel`·`LevelUpScreen`의 [재설계]와 `RespecModal`을 지웠다.
- **아이템 지급은 병기를 대장간으로 돌린다** (85쪽 문구) — 전에는 병기를 든 채 아이템이 우선할
  뿐이었다. 들고 있으면 한 번 되묻는다.

## 4. 섬광 — 그려서 굽는다 (`tools/build_burst.py`, `npm run burst`)

옛 `reveal-*.png`(생성 AI 2×2 네 칸)는 260ms마다 뚝뚝 끊기고 알파 가장자리에 점 잡음이 있었다
(기획자: 「허접하다」). **생성 AI는 같은 폭발의 연속된 순간을 못 그린다** — 칸마다 다른 폭발이 된다.
그래서 numpy로 모임 → 섬광 → 충격파 → 빛줄기·가로 렌즈 플레어 → 불티 → 반짝이를 시간 함수로
계산해 **24칸 6×4 시트 × 등급 넷**(B 파랑 · A 빨강 · S 보라 · E 황금, 기획자 지정)을 굽는다.
시드 고정이라 늘 같은 그림이고 `assets/` 없이 돈다. 한 번 굽고 대조 그림을 보고 **빛줄기를 키우고
고리를 얇게·빨리 사라지게** 다듬었다. 알파는 밝기 그 자체라 보통 합성으로도 빛처럼 얹힌다.

- 단발은 가운데 하나를 크게, 8연은 **장마다 제 등급색으로** 흩어져 120ms 간격으로 터진다.
  첫 섬광의 가장 밝은 순간에 화면이 한 번 하얗게 번쩍이고, 눌러서 건너뛸 수 있다.
- **후광** — A·S·E만(lv3_blue / lv4_purple / lv5_gold, 기획자 지정). 대장간은 돌기만 하는데
  여기서는 **돌면서 부풀었다 줄어든다** — 한 `@keyframes`에 둘을 함께 적었다(`transform`을
  둘로 나누면 뒤의 것이 앞의 것을 덮는다).

## 6. 밟은 것 ★

- **팝업이 몸통만 덮었다.** 판을 파일 셋으로 가르자 팝업이 `.place-body` 안에서 그려졌고,
  배경 화면 규칙(`.scr-bg > *` → `position: relative`)에 갇혀 가리개가 제목 바를 안 덮었다.
  내 스크린샷에서는 「그럴듯해」 보였고 **`smoke:meta`의 「팝업이 프레임을 덮는가」가 잡았다**
  (CLAUDE.md 「배경 위 팝업」 절과 같은 자리). 대장간처럼 화면의 직계 자식으로 두려고
  **포털(`Layer`)**로 `.scr` 바로 밑에 올렸다.
- **개발용 지급 목록이 화면을 늘렸다** — 용병 시장에 260명 목록을 두니 화면이 뷰포트보다 길어져
  바닥 명령 판이 떨어지고, **섬광이 화면 아래쪽으로 밀려 첫 스크린샷에 안 보였다.** [금화 충전]
  판으로 옮겼다.
- **스모크의 시드 id가 두 번 개량됐다** — 태학 연구 시드를 `academyTopics(1)[0].id + '-plus'`로 적었는데 그 함수가
  이미 개량형 id를 돌려줘 `…-plus-plus`가 되어 조용히 버려졌다(화면이 「되돌릴 연구가 없다」로
  말해 줘서 잡았다).
- **스모크가 넓은 화면에서만 섬광을 0개로 셌다** — 760px을 2배로 찍는 동안 1.1초 섬광이 끝났다.
  **세고 나서 찍는다.**
- **떠 있던 `server-api`(8787)는 옛 코드였다** — `/market/items`도 `multi`도 모른다. 사용자가 띄운
  프로세스라 안 건드리고 **8788 + Vite 5174를 따로 띄워** 확인했다. `smoke:meta`에 `SMOKE_API_PORT`를
  더했다. ⚠ **사용자 쪽 8787은 재시작해야** 8연·[결제하기]가 돈다.

## 7. 목업과 다르게 적은 것 — 다음 세션에서 기획자 확인

- **태학 연구 초기화 설명** — 목업은 「태학 레벨만큼 즉시 완료」, 규칙은 「**전에 끝냈던 레벨까지**」
  (`instantUntil`). 규칙 쪽으로 적었다(「태학 레벨까지」로 두면 안 해 본 레벨의 대기를 10냥으로 건너뛴다).
- **보관함 장수는 정리 목록에 안 뜬다** — 장수 일람(`officerRows`)이 풀만 본다. 규칙은 재료로 받는다.
- 태학 초기화와 재설계가 **같은 두루마리 아이콘**이다.
