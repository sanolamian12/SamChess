## 2. 도시 이름 강제 변경

욕설 · 사칭 이름을 운영이 바꾼다. 결정(기획자): **새 이름은 관리자가 적는다 · 3일 대기를 비운다 · 우편으로 알린다.**

| 자리 | 내용 |
|---|---|
| meta `adminRename.ts` (새) | `canForceRenameCity` · `applyForceRenameCity`(금화 그대로, `cityNameChangedAt`을 **칸째** 지운다) · `forceRenameMail`(보상 없는 공지, 사유를 그대로 싣는다. 한국어 · 영어 — 다른 언어는 우편 규칙대로 한국어로 물러난다). 이름 꼴은 게임의 `normalizeCityName` · `CITY_NAME_MAX`, 대기 일수는 `RENAME_COOLDOWN_MS`에서 |
| meta `admin.ts` | 권한 `rename` — `ADMIN_PERMISSIONS` · `ROLE_PERMISSIONS`(관리자 · **CS 둘 다**) · `PERMISSION_LABELS` |
| 계약 `admin/types.ts` | `AdminAuditAction`에 `city.rename`(묶음 `city`가 저절로 생긴다) · `RenameResponse` · `CityNameMax`(리터럴 `12`) |
| 서버 `store.ts` | `forceRenameCity()` — `mutateWithAudit`에 **같은 트랜잭션에서 함께 할 일**(`inTx`)을 받는 칸을 더해 우편을 넣고 `mailId`를 로그 `params`에 싣는다. 우편 넣기는 `insertMailTx()`로 뽑아 관리자 보내기와 함께 쓴다. 이름이 겹치면 `CityNameTakenError` → 409 |
| 서버 `routes.ts` | `POST /admin/users/:uid/rename { name, reason }` — `requireAdmin(…, 'rename')` |
| 화면 `RenamePanel.tsx` (새) | 계정 상세의 지급 패널 아래. 입력 → 문장으로 확인 → 실행, 사유 필수(「알림 우편에 그대로 보인다」), `can('rename')`이 아니면 안 그린다. 길이 `12 satisfies CityNameMax` |
| 화면 `AuditPage.tsx` | `city.rename` 이름 · `city` 묶음 · 내용 「옛 이름 → 새 이름 · 알림 우편 #n」(옛 이름은 전후 값에서) |

### 결정과 이유

- **겹침은 미리 조회하지 않고 DB에 맡긴다** — 게임의 `/city/rename`과 같은 이유(조회와 쓰기 사이에 남이 끼면 통과한다).
  계정 쓰기가 거절되면 같은 트랜잭션의 우편 · 로그도 함께 되감긴다 — 스모크가 「409 뒤 우편 수 · 로그 수가 그대로」로 본다.
- **감사 로그는 `city.rename` 한 줄** — 알림 우편을 `mail.send` 줄로 따로 적지 않는다. 한 사람이 한 일은 하나이고, 우편 번호가 `params`에 있다.
  보낸 우편 목록에는 그 관리자 이름으로 뜬다(`sent_by`).
- **CS에게도 준다** — 이름 고치기는 CS가 받는 신고의 대부분이고, 되돌릴 수 있고(다시 바꾸면 된다), 로그가 남는다. 거두려면 `ROLE_PERMISSIONS.cs`에서 한 줄.
- **알림 우편은 보상이 없어 CS 상한과 무관하다.**
- 사유가 플레이어에게 보이는 것은 **정지 사유와 같은 결**이다 — 화면 입력칸이 그렇게 안내한다.

## 검사

- **오늘 만든 검사가 일했다** — 계약에 `city.rename`을 더하자마자 화면이 `ACTION_LABEL` · `GROUP_LABEL` 둘 다 TS2741로 깨졌다(이름을 붙이기 전).
  `CITY_NAME_MAX`를 13으로 바꾸면 `RenamePanel.tsx`가 TS1360, 되돌리면 통과.
- 회귀 `adminRename.test.ts` 3건 — 금화 그대로 · 대기 비움(칸째) · 강제 변경 뒤 게임 이름 변경이 바로 됨, NFC · 빈 이름 · 길이,
  **가장 긴 이름 둘 + 사유 500자**에서도 알림 우편이 `parseMailDraft`를 그대로 통과. `adminRoles.test.ts`의 CS 권한 목록에 `rename`(의도한 변경).
- `smoke:admin` — 사유 · 이름 · 같은 이름 400, 평범한 사용자 403, **대소문자만 다른 남의 이름 409이고 우편 · 로그가 안 남는다**,
  성공하면 앞뒤 공백 뗀 이름 · 대기 비움 · 게임 우편함에 알림(사유 · 새 이름 포함) · 감사 로그 한 줄. CS도 바꾼다. 27건 통과(exit 0). 첫 실행은 CS가 한 일을 세는 표에 새 개명 한 줄이 안 들어가 떨어졌다 — 의도한 변화라 기대값에 더했다.
- `npm test` 1023 통과 · `typecheck` · `typecheck:admin` · 관리자 `npm run build` exit 0.
- 화면은 눈으로 보지 않았다 — 정지 패널과 같은 꼴(같은 클래스)이다.
