## 왜 이 작업인가

사용자가 "간판·메인·환경설정에 이미 입힌 목판·양피지 화풍을 랭킹 화면에도
일관되게 입히고 싶다"며 시작했다. 실기기 스크린샷을 주고받는 반복 피드백
세션이었고, 그 과정에서 세 가지 곁가지가 붙었다 — ① 요청한 에셋이 도착할
때마다 배선, ② 장수 카드 레이아웃 자체의 여러 차례 재설계, ③ 랭킹 3화면과
인물 서사가 사실 "한국어 한 벌만" 있었다는 걸 발견하고 다국어를 마저 배선.

## 한 일 — 크게 여섯

### 1. 디자인 스펙 아티팩트 + 에셋 요청 목록

기존 화풍(목판 버튼 3종·두루마리 필드·환경설정 패널/명패/칩)을 훑어 랭킹
3화면에 적용 가능한 재사용 지도와, 새로 필요한 에셋(장부 패널·메달 3종·
인장·랭킹 메뉴 아이콘 3종·넓은 명패)의 생성형 AI 프롬프트를 Artifact로
정리해 전달했다. 사용자가 이 아홉 장을 만들어 왔고, `tools/build_ui.py`의
`FRAMES`/`ICONS` 딕셔너리에 등록해 `npm run ui`로 구웠다.

### 2. 랭킹 3화면 화풍 리스킨 — 기존 자산 재사용 + 반복 조정

- **드롭다운(모드·상대 필터)** — 원래 브라우저 기본 `<select>`였는데, 닫힌
  상자는 CSS로 꾸며도 **펼친 목록은 OS가 그려서 손댈 수 없었다**. `SortMenu`가
  이미 쓰던 「버튼 + 뜨는 패널」 모양으로 통째로 바꿔 `RankingCommon.tsx`에
  `Dropdown` 컴포넌트를 새로 만들었다 — 닫힌 상자·펼친 목록 둘 다 이제 진짜
  화면 요소라 나머지와 같은 그림(장부 패널 + 나뭇결/옥색 칩)을 그대로 쓴다.
  마지막엔 "3 vs 3"·"전체"·[정렬 필터] 세 자리를 전부 같은 참나무 목판으로
  통일했다(`.btn.sm .rk-select`).
- **검색·정렬 버튼** — 대나무(ghost, 배경 없이 얇은 테두리만)라 "버튼처럼 안
  보인다"는 피드백에 오크 채움으로 바꿨다가, 검색 버튼만 환경설정 [닫기]와
  같은 옥색 목판(`btn-primary.png`)으로 다시 갈라 "가장 자주 누르는 동작"을
  색으로 표시했다.
- **검색창·검색/정렬 버튼 레이아웃** — "8:2 → 7:3"으로, 정렬 버튼 줄은 검색
  버튼과 **정확히 같은 그리드 비율**(`grid-template-columns: minmax(0,7fr)
  minmax(0,3fr)`)을 써서 폭이 항상 픽셀 단위로 맞아떨어지게 했다. 두 번
  걸린 함정: ① `flex:1`만으로는 반반이 안 지켜진다 — flex 아이템의 기본
  `min-width: auto`가 "내용보다는 안 줄어든다"를 먼저 적용해, 입력창+버튼
  둘을 담아야 하는 검색 칸이 계속 더 넓게 밀려났다(`min-width: 0`으로 해결).
  ② 검색창 높이가 옆 버튼들과 안 맞아 보여, 글자 크기를 80%로 줄이고
  세로 테두리·패딩도 비례해 줄였다.
- **표 데이터 줄** — 처음엔 어두운 화면 기준 색(짙은 남색 상자)을 그대로
  써서 "디자인이 안 입혀진 것처럼" 보였다. 색 띠·박스를 걷어내고 장부
  패널 양피지 위에 먹색 글씨로 바로 쓰는 방식으로 바꿨고, 줄 사이엔
  그라디언트로 흉내 낸 붓선을 넣었다 — **진짜 붓 선 이미지는 아직 없다**,
  자리(`assets/icons/rule_line.png`)와 프롬프트만 전달해 뒀다.
- **1·2·3위 메달·"내 정보" 인장** — 순위 숫자를 금·은·동 메달 이미지로
  갈음(`color: transparent` + `background-image`, DOM엔 숫자가 그대로 남아
  스크린리더는 정상적으로 읽는다). "내 도시/부대/장수" 소제목엔 인장 아이콘을
  붙였다 — **인장 파일이 두 차례 교체됐다**(`seal_mine.png` → `seal_mine2.png`,
  파일명이 헷갈릴 수 있다며 사용자가 다시 올림 — `tools/build_ui.py`의
  `ICONS` 매핑 키만 바꾸고 출력 id는 그대로 유지해 CSS는 안 건드렸다).
- **뒤로가기 버튼** — 가장 많이 뒤집힌 요소. 이미지 화살표(`button_backarrow.png`)
  하나로만 세우되, 처음엔 글자를 화살표 꼬리 안에 넣었다가(다국어 번역
  길이가 제각각이라 "좁은 꼬리 안에 다 들어온다는 보장"이 없다는 지적으로)
  **글자를 이미지 밖 오른쪽으로 완전히 뺐다** — 이제 어떤 언어가 와도
  버튼이 옆으로 늘어날 뿐 깨지지 않는다. 크기도 최종적으로 지금의 1/3로
  줄였다.
- **표 머리(`.rk-thead`)·"보기" 버튼·"총점" 안내문** 색도 전부 어두운 화면
  기준이라 양피지 위에서 묻혀, 먹색 계열로 다시 칠했다.

### 3. 장수 카드 재설계 — 여덟 차례 사용자 지정

pptx 53쪽 원안에서 시작해 스크린샷 피드백을 받을 때마다 구조가 계속
바뀌었다. 최종 상태:

- **팝업으로 전환** — 처음엔 표 위에 인라인으로 떠서 표 전체를 밀어내렸다.
  환경설정과 같은 `.modal-back`(화면을 덮는 가리개)으로 감싸 진짜 팝업으로
  바꿨고, 장수 랭킹 화면에서만 `align-items: flex-start`로 세로 정렬을
  가운데에서 위(제목 바 바로 아래)로 옮겼다.
- **액자를 완전히 뺐다** — 장터 가챠와 같은 등급 액자(`market/frame-{grade}.png`)를
  둘렀다가, 처음엔 `object-fit: cover`로 인물이 잘렸다(→ `border-image` +
  `object-fit: contain`으로 1차 수정) → 그래도 "액자 자체가 자리를 너무
  먹어 캐릭터가 작아 보인다"는 지적에 **액자를 통째로 없애고 캐릭터 그림만**
  남겼다. 그만큼 왼쪽 칸 높이가 줄어, 오른쪽 정보 줄도 `space-between` 대신
  `flex-start`로 촘촘히 쌓게 했다. 캐릭터:정보줄 비율도 4:6 → 3:7로 다시
  조정하고, 넓어진 자리만큼 정보 줄 글자를 키웠다(.64rem → .78rem).
- **색 띠·검정 음영 제거** — 파랑/보라/초록/갈색 왼쪽 띠 + 어두운 목재
  배경이던 네 줄을, "내 장수" 표처럼 장부 패널 양피지 위에 먹색 글씨로
  바로 쓰는 방식으로 바꿨다(표 데이터 줄과 같은 처리를 카드 안에도 적용).
- **이름 줄 배지 버그** — "내 장수" 표의 등급 배지(`.rk-nm .gr`) 디자인을
  "그대로 가져와 폰트만 키워 달라"는 요청에 처음엔 박스 모양(패딩·둥근
  정도)만 옮기고 **정작 배색(`background`/`color`, `--g-bg`/`--g-fg`)을
  빠뜨려서** 그냥 검은 글자로 나왔다 — 스크린샷으로 발견해 두 줄을 마저
  옮겼다.
- **"전적" 이름표 추가** — "0/0/0" 앞에 "적 격파"와 같은 스타일로 "전적"을
  붙였다. 새 번역 키(`ranking.card.record`) 10개 언어 전부 추가.
- **닫기 버튼** — 목판 프레임을 씌웠다가 "다른 프레임 없이 X 아이콘만"으로
  걷어냈다.
- **인물 열전 프레임 — 두 번 헛짚었다.** 처음엔 대나무(`btn-ghost.png`)를
  테두리 줄로만 둘렀는데(`border-image` without `fill`), **`btn-ghost.png`가
  다른 목판 그림들과 같이 "그 자체로 이미 완성된 배경"(대나무 틀 + 안쪽
  양피지)이라는 걸 놓쳐서** 안쪽 양피지가 안 쓰이고 테두리만 남아 "이미지가
  깨졌다"로 보였다. `fill`을 넣어 고쳤더니 이번엔 **트리밍이 문제였다** —
  `build_ui.py`의 알파 경계상자 트리밍이 "텍스트 영역을 최대화"하려고
  이미지 바깥 여백을 이미 잘라내 버려서, 테두리로 두르기엔 여백이 부족했다.
  사용자가 스스로 원인을 짚고 **`textfield.png`(검색창에 이미 검증된 그림·
  슬라이스 값)로 갈아타자**고 정리해 최종적으로 그걸 썼다.
- **삼능력(무력·지력·통솔) 아이콘화** — 번역마다 낱말 길이가 달라 줄바꿈이
  들쭉날쭉하던 걸 언어 중립적인 아이콘으로 바꿨다. 사용자가 생성형 AI로
  받아 온 첫 시도(`stat_might.png` 등)는 **알파 채널이 전부 불투명이고
  검정 배경 + 금테 장식이 그림에 통째로 박혀 있어** 그대로 못 썼다 —
  자동으로 배경을 지우는 것도 검·투구의 짙은 음영이 같이 뜯길 위험이 커
  포기하고 재생성을 요청했다. 사용자가 원본 넷(`stat_might_raw`·
  `stat_intellect_raw`·`stat_leadership_raw`·`stat_frame_raw`, 전부 알파
  있음)을 다시 올려, 파이썬으로 물체를 프레임 중앙에 합성해 붙였다(1차).
  그런데 "프레임에 넣으니까 그림이 너무 작다"는 피드백으로, **프레임 없이
  `_raw` 원본을 그대로 쓰고 아이콘 크기를 1.1rem → 1.9rem으로 키우는 것**으로
  최종 정리했다(`build_ui.py`의 `ICONS` 매핑을 `stat_*` → `stat_*_raw`로
  바꿈).
- **전적 표기 통일** — "0/0/0"의 슬래시 앞뒤에 공백을 넣어 "0 / 0 / 0"으로
  (10개 언어 `ranking.wdl` 전부).

### 4. 랭킹 다국어 전면 배선

랭킹 3화면·장수 카드가 참조하는 `ranking.*` 문자열 49개(+ `records.filter.*`
3개, + 이번에 새로 생긴 `ranking.card.record`)가 **지금까지 한국어에만
있었다**(`t()`가 없는 키를 한국어로 물러나는 구조라 화면은 안 깨졌지만
다른 언어 사용자에게는 랭킹 전체가 한국어로만 보이고 있었다). 9개 언어
파일 전부에 채웠다 — "장수"→general/武将/жанжин, "부대"→squad/部隊/эскадрон
같은 용어는 이미 다른 화면(병영·장터 등)이 쓰던 번역을 그대로 따랐다.
스크립트로 9개 파일이 한국어 원본과 키 개수·이름까지 정확히 일치하는지
검증했다.

### 5. 장수 랭킹에 모드 필터 추가

"장수 일람(전적 화면)은 이미 3v3/5v5를 나눠 보는데 장수 랭킹만 없다"는
지적으로, `officerRankRows(profile, filter, mode?)`(`@samchess/meta`)가
선택적 모드 인자를 받도록 넓혔다 — `mode`가 있으면 `sumTally(inst.record,
{...whereOf(filter), mode})`로 직접 계산하고, 없으면 기존 `totalTally()`
그대로다. `packages/server-api/src/ranking.ts`의 `queryRanking()`도 같은
인자를 그대로 넘기도록 한 줄 고쳤다. 도시·부대 랭킹과 완전히 같은 구조가
됐다.

### 6. 인물 서사(장수 열전) 다국어 연결

`assets/Languages/sam_people.csv`를 다시 열어 보니 **애초에 9개 언어 열
(`bio_en`·`bio_ja`·`courtesy_en`… )이 전부 있었는데, 2026-08-27 첫 세션(G1)이
한국어(`bio_ko`/`courtesy_ko`) 한 벌만 연결하고 "다국어 실배선은 미룬다"고
코드 주석에 남겨둔 상태**였다. 그 미뤄둔 작업을 마저 했다.

- `tools/extract_data.py`의 `extract_bios()` — CSV 언어 접미사(`pt-BR`·
  `es-419`·`zh-Hant` 등 BCP-47 하이픈 표기)를 클라이언트 `Lang` 코드(밑줄
  표기)로 옮기는 매핑(`BIO_LANGS`)을 추가하고, `courtesyName`/`story`를
  언어별 맵으로 뽑는다. **218명 전원, 열 언어 다 채워져 있는 걸 실측으로
  확인했다**(스페인어·몽골어까지 전부 — 첫 세션이 남긴 51명 공백·8건
  이름 불일치는 이번에도 그대로다, 아래 참조).
- `packages/data/src/index.ts` — `OfficerData.courtesyName`/`.story` 타입을
  `string` → `Partial<Record<StoryLang, string>>`으로 바꿨다. `StoryLang`은
  클라이언트 `Lang`과 값이 같아야 하지만 이 패키지가 클라이언트를 참조할
  수 없어(의존 방향 반대) 따로 선언했다.
- `packages/meta/src/ranking.ts`의 `OfficerRankRow`도 같은 언어별 맵을
  그대로 실어 나른다 — **meta는 "지금 UI 언어가 뭔지" 모른다**, 그건
  클라이언트 `i18n`의 일이라 언어를 안 고르고 맵 전체를 낸다.
  `packages/client/src/i18n/story.ts`(신설)의 `pickStory()`가 그 마지막
  선택 지점 — `t()`가 번역 없는 키를 한국어로 물러나는 것과 같은 규약으로
  `map[currentLang()] ?? map.ko`. `OfficerDetailScreen`(장수 상세)과
  `OfficerRankingScreen`의 `OfficerCard`(장수 카드) 둘 다 이 함수를 거치게
  바꿨다.

## 이번 범위 밖 (다시 볼 자리)

- **붓 선 구분선 이미지** — 표 줄 사이 구분선이 지금은 CSS 그라디언트
  임시 대체다. 프롬프트는 사용자에게 전달했고(`assets/icons/rule_line.png`),
  받으면 `.scr-ranking .rk-row:not(.rk-thead):not(:last-child)::after`의
  `background`를 `background-image`로 한 줄만 바꾸면 된다.
- **인물 서사 51명 공백·이름 표기 불일치 8건** — 첫 세션이 남긴 공백 그대로다
  (금선↔김선, 왕개/왕누↔왕루/왕해, 장흥↔장흠, 주영↔주령, 포용↔포륭,
  한조↔한호). 어느 쪽이 맞는 표기인지 기획 확인이 필요하다.
- **`OfficerDetailScreen`(장수 상세, 38쪽)은 여전히 `courtesyName`을 안
  보여준다** — 이름만 적는다. 이번 세션은 장수 카드(랭킹 쪽)만 손댔다.
- **`assets/SpecialStatus/B_specialstatus.png`/`_cutguide.png` 매핑 공백** —
  첫 세션이 이미 발견해 범위 밖으로 남긴 것, 이번에도 손 안 댔다.
