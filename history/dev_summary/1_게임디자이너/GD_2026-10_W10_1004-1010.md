### 11g 장수 카드의 부상 표시 — 트랙 11 마감 (10-06)

엔진(`officerStats()`) · 서버 · 규칙(`isInjured` · `injuryHealsAt` · `canHeal`)이 9/4에 다 섰는데 **사람이 장수의 부상을 볼 곳이 병원 화면과 일람의
「건강/부상」 칸뿐**이었다. GDD §8.2의 「상세」는 원래 전면 화면(`OfficerDetailScreen`)이었지만 **바깥에서 들어오는 길이 없어**(9/2 · 9/25에 끊김),
실제로 장수를 들여다보는 자리인 **장수 카드 창**에 붙였다.

```
 [무] 80  [지] 52  [통] 71      ← 깎인 값 하나만, 짙은 붉은색 (원래 90/62/81)
          [부상]                 ← 라벨. 누르면 ↓
 자연 회복까지 60분 · 무·지·통 −10      (치료 중이면 「치료 중 (N분)」)
 [입원시키기]                   ← 병원이 있을 때만. 빈 치료실이 없으면 잠기고 이유를 적는다
```

- **깎인 값 하나만** — GDD §8.2 「40 (−10)처럼 나란히 두지 않는다」. 값은 엔진과 같은 −10 · 하한 1.
- 내 장수(일람)에만 보이고 남의 장수(랭킹)에는 안 보인다.
- 이것으로 **트랙 11(도시 확장)이 닫혔다.** GDD §8.2에 「지금 상세는 장수 카드 창이다」를 적었다.
- 남은 GDD §12 미해결 — 부대 편성 화면이 「부대 전투력은 부상을 안 본다」를 말해야 하는 것(이번 범위 밖).

### 2단계 — 세 칸 무대 골격 (10-06)

위(순서 판 · 게임 정보) / 판 / 아래(명령 판 · 맥락 판) 세 칸을 세우고, 새 판은 아직 빈 틀로 두고 옛 판(HUD · 커맨드 패널 · 배치 패널)을 새 칸에

### 3차 — 2차가 남긴 것 · 판 위 링 다섯 갈래 · 탁자와 지도 테 (10-08)

판단 넷을 화면과 함께 한 번에 물었다.

| 물음 | 확정 |
|---|---|
| 비켜 선 장수 팝업(`data-pos="left"`)이 셋째 시스템 메시지를 덮는다 | **지금대로(팝업이 위)** — 6단계 때 정한 「사람이 고른 것이 지나가는 말보다 먼저」를 유지 |
| 고른 명령 단추가 덜 갈린다 | **금빛 테 두르기** |
| 노랑(E) 시전 오라가 종이 지도 위에서 흐리다 | **진하게 굽기** |
| 명령 판 · 맥락 판 안쪽의 남색 상자 | **어두운 가죽색으로** |

**판 위 링을 다섯 갈래로 접었다.** 기획자가 「AI 대전에서 시전 오라를 한 번도 못 봤다」고 물었다 — 확인해 보니 **고유기술 40종 중 13종만** 시전 지연(WT 30)이
있고, 그 틈은 화면에서 **0.3초**였다(초당 100). 두루마리 연출이 걷히는 순간과 겹쳐 사실상 안 보였고, **헌제(E)는 즉시 발동이라 노랑은 실전에 한 번도 못 뜬다.**
이어서 기획자가 「SpecialStatus 그림이 난잡하다 — 몇 개로 통일하자」고 해 정리했다.

| 그림 | 뜻 |
|---|---|
| `cast-{등급}` | 고유기술 시전 중 |
| `14` | 고유기술이 건 나쁜 효과 |
| `2` | 책략이 건 나쁜 효과 |
| `17` | 고유기술이 건 좋은 효과 |
| `1` | 책략이 건 좋은 효과 |

- 여럿이면 **시전 → 고유기술 나쁨 → 책략 나쁨 → 고유기술 좋음 → 책략 좋음** 순으로 **3초 + 1초 페이드**.
- 「세는」 상태(유비 삼고초려의 3회 같은)는 고유기술 동그라미에 숫자로 — 그림 없이 먼저.
- 조종은 나쁨으로 접고 · 성지 칸 링은 없애고 · 선공은 좋음으로 · **일회성 `A`~`G`는 아예 안 쓴다**(판 위 연출을 다시 보겠다). → 결정·교훈 참조
- 제안으로 넣고 확인 대기 — 「즉시 WT 링」을 함정 · 경직 · 십면매복 · 장판하뢰까지 넓힌 것(일회성 `D`를 걷으면 「함정」 · 「경직」은 판에 흔적이 안 남는다.
  십면매복 · 장판하뢰는 「시전 중인 적을 늦추는」 카운터라 이제 맞은 쪽에 14가 뜬다).

**「전투 화면을 한 벌로」** — 기획자가 「원본 PNG는 투명한데 화면에선 오려 붙인 듯하다」고 짚었고(원인은 CSS), 탁자 바탕 · 지도 테 그림을 Gemini로 받았다.
지도 테는 네 번 바꿨다 — 나무 테(테두리) → 금빛 용무늬(디테일이 번진다, 기획자) → 금사슬(기획자가 접었다) → 금빛 밧줄 → **나무 테, 띠는 지도 바깥 · 귀퉁이쇠만 지도 위(최종)**.
상세 → 디자인 엔지니어 문서.

|---|---|
| 상대의 수가 한꺼번에 지나간다 — 서서가 「침묵」을 거는데 카메라가 가기도 전에 감녕 카드에 배지가 있다 | **한 박자씩**: 행동하는 장수 비춤 → 도착하고 1초 → 동작(대화창 첫 줄) → 대상 비춤 → 도착하고 1초 → 피격 → **배지** |
| 배지가 그냥 생긴다 | 자리가 **번쩍이고** 붙는다 — 나쁜 것 검정 · 좋은 것 흰색 |
| 이동 | 칸을 누르면 「이동을 확정하시겠습니까?」 [취소] [확정]. [취소]면 **즉시 출발점으로** |
| 8방향 아이템(탕약)이 판 전체로 물러난다 | **[공격]처럼** 확대한 채 8방향을 칠하고, 대상이 없으면 「범위 안에 아군이 없습니다」 |
| 맥락 판 단추 | [취소] = `button_alart`(금빛 두루마리), [확인] = `button_primary`(옥색 목판) |
| 확인창 단추 배치 | **두 층, 한 단추가 폭 전체, 진행 단추([확정] · [확인] · [사용])가 맨 아래** — 대기에서 시작해 이동 · 공격 · 책략 · 아이템 · 고유기술 물음까지 통일 |
| 고유기술 물음 | 기술 이름 · 라벨 그림을 **뺀다**(왼쪽 장수 카드가 보여 준다). 발동 시간 안내만 |
| 판 위 HP 바 | 칸 **아래**로 |
| WT 막대 | 끝을 **1.9일**로(3 → 1.9). 넘으면 온통 노랑 |
| 배지 설명 창 | `textfield` 두루마리 종이 |
| SP가 오를 때 | 노랗게 번쩍이며 숫자가 솟는다 |
| 차례를 받은 장수 | 순서 판의 그 칼만 한 번 번쩍 |
| 아이템 목록 | 왼쪽에 `market_items` 그림, 오른쪽 이름(밝게) · 효과(회색) 같은 크기 |
| 장수 카드 | HP/MP 막대를 입체로, 등급 보석이 5초마다 유리처럼 반짝 |
| 판 위 오라(링) | 돌면서 · 조금 줄었다 돌아오고 · 흐려졌다 돌아온다 |
| 상대의 명상 | 명상 자세를 비춘 뒤에 카메라가 옮겨 간다 |

- 상대 책략 한 번이 약 **1.3초 → 7.3초**가 됐다. 줄이려면 `FOCUS_*` 두 값이다(도착 1000ms · 머무름 1000ms). 내가 낸 수에는 「먼저 비추기」를 끈다(2초가 헛돈다).
- **기획자 판단 대기** — ① **탕약은 엔진이 자기 자신도 대상으로 받는다**(거리 0)라 「범위 안에 아군이 없습니다」가 거의 안 뜬다. 설명은 「8방향 내 아군 1명」이고 목우유마만
  「(자신 포함)」이라 의도가 갈릴 수 있다 — 규칙이라 손대지 않았다. ② 「클래스 엠블럼」을 등급 보석으로 읽었다 — 기물 그림을 뜻했다면 옮긴다.
  ③ 장수 카드의 HP 막대는 결과값을 곧바로 그린다(판 위 HP 바는 맞는 순간에 줄어든다) — 맞출지.

### 전투 화면 마무리 — 걷는 방향 · [항복] 목판 팝업 · 게임 정보를 그림으로 (10-10)

| 물음 | 확정 |
|---|---|
| 장수가 문워크한다 — 원인은? | 액션 시트 260장의 이동 · 공격 칸이 **전원 화면 오른쪽**을 본다. 판이 반전을 안 해서 왼쪽으로 걷는 수는 누구든 뒷걸음이었다(「장수에 따라」가 아니라 **그 수의 방향**) |
| 걸음이 끝난 뒤 방향 | **바라본 쪽을 기억** — 다음에 다른 쪽으로 움직일 때까지 |
| 행동할 때 | 공격 · 책략 · 아이템은 **대상 쪽**, 맞는 쪽은 **때린 쪽**을 본다. 같은 열이면 그대로 |
| [항복] 확인 | 시안 B — 판 위 가운데 **목판 팝업**(`panel-settings`). 단추는 맥락 판 그림 · 순서(위 [취소] 금빛 · 아래 [항복]). [항복]만 **붉은 목판**(`btn-forcedcancel`) |
| 게임 정보 — 진영 색 | 판의 **기물 아이콘 색**(아군 녹청 · 적군 구리)과 맞춘다 |
| 게임 정보 — 턴오버 | 점 셋(●●○) → 나중에 **구슬 홈 그림** 셋 |
| 남은 시간 | 5초 이하 **붉게 맥박**. 해시계를 오른쪽 끝, 그 왼쪽 가운데에 제한 — AI 대전은 **「시간제한 없음」**(영어 「Unlimited」) |
| 게임 정보 — 글자 | 번역되면 넘친다 → **그림으로**: 진영 = 깃발(북군 ↓ 구리 · 남군 ↑ 녹청), 나 = 투구 배지, 턴오버 = 모래시계를 움켜쥔 주먹, 남은 시간 = 해시계, 전투 n일차 = 해와 달 원반 + 「n일」(영어 「Day n」) |
| 줄 칸 | 어두운 바탕 · 테두리 **둘 다 없앤다** — 판때기 나무 위에 그림과 숫자만 |
| 구슬 홈 | 정사각 쇠판을 걷고 **놋쇠 원 테만** |

- 기획자 질문 「숨은 글자 때문에 [항복]과 해시계 사이를 비워 뒀나」 — **아니다.** 줄 사이 간격 7px + 남는 높이를 채우는 여백 9px였다.
- 알리고 그대로 둔 것 — 깃발 색(진영 고정)과 줄 색(나에게서 본 편)이 **북군으로 서는 온라인에서 엇갈린다.** 화살표가 진영을 말하니 그대로. 바꾸려면 깃발을 색별로 한 벌 더 받는다.
  「SP」 글자는 그대로다(그림으로 바꿀지 묻지 않았다).
