### 도적떼 방어전 — 농지의 하루 한 번 도전 (09-21)

트랙 11h에서 「그림과 현황 한 줄뿐」이던 농지를 채운 것이다. 기획자가 처음 준 사양을 검토해 열두 가지를 물었고,
답을 받아 아래처럼 굳었다. 규칙의 정본은 **GDD §5.11**이다.

| | 확정 |
|---|---|
| 출몰 | 농지 Lv1 이상 · **날이 바뀐 뒤 첫 접속**(KST 0시 경계) · 도적 수 = 농지 레벨 |
| 10분 | 처음 알림 [지금 전투]/[전투 준비] → 메인 도시 이름 밑에 [전투하기 m:ss] → 남은 1분에 다시 알림([지금 전투]/[항복]) → 10분이 지나면 자동 항복 |
| 출정 | 도적떼가 살아 있는 동안 병영 [출정하기]가 막힌다 |
| 도적 | 농지 Lv n → **King · Queen · Rock · Bishop · Knight**의 앞 n명. 무·지·통 30(WT 160), 레벨 = 농지 레벨(1~5), HP ↔ AT 번갈아. 책략·고유기술 없음. 도적 King을 잡으면 승리 |
| 파수꾼 | 농지 레벨만큼, **다 채우지 않아도** 1명이면 싸운다. Lv1은 King 고정, King은 언제나 필수. 부대(10개 중 어디든)에 든 장수는 불가. 병영에서 파수꾼을 부대에 넣으면 확인 뒤 농지에서 빠진다(반대는 없다) |
| 판 | 25열 × 15행. 북 25×5 도적 · 가운데 중립 25×5 · 남 25×5 파수꾼. 성채 3×3(x 11–13 · y 11–13, 0부터 센다), 파수꾼 King (12, 12) 고정 |
| 결말 | 승리 = AI 승리와 같은 보상(카드·재료·군량 — 파수꾼 3명 이하 3v3, 4명 이상 5v5의 군량). 패배 = **살아 있는 도적 × 10%** 약탈(패배 카드 없음). 항복·시간 초과 = **출몰한 도적 × 10%**. 무승부 = 없음. 전적·랭킹에 안 센다 |

온라인 대기열은 서버가 막지 않는다. → 결정·교훈 참조

- 약탈 = `min(지금 군량, floor(출몰 시 군량 × 도적 수 × 10%))` — 10분 동안 참가비로 써 버려 피하는 길을 막는다.

### Pawn 원거리 개편 — 마름모 ≤2 · 대상 1명 (09-22)

HANDOFF §7 후보 「Pawn 개편 — 같은 줄 둘 공격 → 원거리 공격」을 처리했다. 같은 날 태학 세션에서 기획자가 제기했고,
태학 **증폭+**가 Pawn의 두 대상 공격에 충전 둘을 한 번에 다 써서 **둘 다 크리티컬**이 나던 문제(GDD §5.12)를 함께 푸는 것이 목적이었다.

옛 Pawn은 이동 8방향 1칸 · 공격 **직교 1~2칸(8칸) · 최대 2명** · 위협 범위 33이었다. 후보 마스크마다 위협 범위를
`threatRange()`와 같은 방식(이동 목적지 전부의 공격 칸 합집합, 원점 포함)으로 계산해 기획자에게 보였다.

| 공격 마스크 | 칸 | 위협 범위 | 인접 공격 |
|---|---:|---:|---|
| 옛: 직교 1~2 | 8 | 33 | 가능 |
| **마름모(맨해튼 ≤2)** | 12 | **37** | 가능 |
| 맨해튼 =2 고리 | 8 | 37 | 불가 |
| 직교 1~3 | 12 | 45 | 가능 |
| 직교 2~3 | 8 | 45 | 불가 |
| 체비셰프 =2 고리 / 8방향 2칸 | 16 / 8 | 49 | 불가 |
| 맨해튼 2~3 | 20 | 57 | 불가 |

(비교: Rock 41 / Queen 39 / Bishop 37 / King·Knight 25)

**기획자 확정: 대상 1명 · 마름모 ≤2 (12칸, 위협 37).** 마름모는 둘째 대상을 잃는 대신 칸이 8 → 12, 대각 1칸이 새로 닿는다.
37은 Bishop과 같고 Rock(41)은 안 넘는다. 사각지대는 넣지 않았다. → 결정·교훈 참조

위협 범위 33은 CLAUDE.md의 「임의로 바꾸지 않는 확정 수치」였는데, 이번 것은 **기획자 결정으로 의도적으로 고친 것**이고 목록도 37로
고쳤다. GDD §3.2 기물 표·개편 설명·위협 범위 표, 행동 표(「Pawn은 최대 2명」 삭제), §5.12 증폭+ 항목 취소선, §12 미결 항목을 고쳤다.

### 태학 — 장수 훈련에서 「책략 개량 연구」로 (09-22)

트랙 11h의 마지막 건물. GDD §12에 「태학 세부 사양」이 미해결로 남아 있었다. 옛 사양은 「장수를 보내 무·지·통을 훈련 — 1시간 ·
Up당 +2」였는데, 현황을 정리해 보여 주자 기획자가 **「프로필에 `무 +0` `지 +0` `통 +0`이 덕지덕지 붙으면 디자인도 정책 관리도
복잡해진다」**며 방향을 바꿨다 — **책략을 연구해 개량형을 익히게** 이끈다. 사양은 **GDD §5.12**에 신설했다.

| | 결정 (전부 기획자 확정) |
|---|---|
| 단위 | **계정.** 연구하면 원본을 익힌 장수 전원이 개량형을 쓴다 |
| 주제 | 태학 레벨마다 3중 택1 · **Lv1부터 차례로**(처음엔 「순서 무관」 → 둘째 지정으로 뒤집힘) · 레벨마다 1개 → 태학 Lv5에서 개량 5개 |
| 진행 | 동시 1개 · 실제 1시간 · **무료** · 취소 허용 |
| 완료 | 전투가 아닌 화면에서 축하 팝업 + 「N명에게 일괄 적용」 안내 |
| 되돌리기 | 둔갑천서 같은 상점 아이템, 금화 10냥. 되돌린 뒤 **전에 끝냈던 레벨까지는 즉시**(둘째 지정 「태학 레벨까지」 → 셋째 지정으로 좁힘) |
| 전투력 | 반영 안 함 · AI 상대 개량 없음 · 적 개량형 숨김 |

**수치 검토에서 바뀐 것** — 기획자 초안 16종을 엔진의 실제 Effect 정의와 대조해 셋을 짚었다.

- **증폭+를 Pawn이 쓰면 한 번 공격에 두 번이 다 소모된다** — 충전이 「타격마다」 빠진다(`state.ts`의 `consumeCharge`).
  기획자 답: Pawn 자체를 원거리로 하향하고 싶었다 → 같은 날 Pawn 개편이 풀었다(위 절).
- **탈진+(3일마다 −2)는 처음 이틀 동안 원본보다 약하다** — 첫 피해가 주기 끝에 온다. 기획자 답: 장기적으로 강하니 그대로.
- **진화+(MP 1→0)는 아무도 안 고를 선택지** — 기획자 답: **빼고** Lv3~5를 다시 짜서 전 레벨 3중 택1로.

개량형 이름은 원본 + 「+」(열 언어 공짜), 설명만 새로 적었다. 엑셀 「도시 건물」의 태학 줄은 옛 사양(「훈련 보정 2/4/6/8/10」)이라
추출기가 「연구 주제 1~5」로 덮어쓰고, 엑셀이 갱신되면 스스로 알린다 — **기획자가 엑셀을 고쳐야 한다.**

### 시장 아이템 16종 — 사양 (09-23)

트랙 9(상점)가 2026-08-24부터 🔶로 멈춰 있었다. 「장터를 현황판 + 바닥 명령 판으로」에서 시작해 상품을 세다가
**「장수 아이템」이라는 새 품목군**으로 번졌고, 오간 결정이 전부 확정됐다.

| | 결정 | 뒤집힌 것 |
|---|---|---|
| 종류 | **Passive · Active 1회용 둘** | 처음엔 「Active 영구」를 포함한 셋. 망원경을 **정찰 단계 공개**로 옮기며 Passive가 됐다 |
| 소모 | **모든 아이템이 1회용** — Passive는 참전으로, Active는 사용으로 | 처음엔 Passive가 영구였다 |
| 칸 | 장수 하나는 **병기 또는 아이템 하나** | |
| 소모 시점 | **판이 열리는 순간**(참가비와 같은 자리) | 「끝난 뒤」로 두면 같은 아이템을 여러 판에 쓴다 |
| 환불 | 성립하지 않은 판 전부 · ~~안 쓴 Active~~(09-23 둘째 세션에서 「참전하면 소모」로 뒤집힘). **항복·패배해도 쓴 것은 안 돌아온다** | |
| 해금 | 시장 Lv2~Lv5, 부류(약·책·말·도구)마다 레벨당 하나 = **16종** | |
| 전투력 | **반영하지 않는다. 매칭도 안 본다**(A안) | |

사양을 정하며 잡은 것:

- **망원경은 시대가 안 맞는다**(17세기) → **척후기**(斥候騎). **폭약**도 화약이 당대 물건이라 한대의 **유황·역청 질항아리**로 그렸다.
- **해금 레벨이 「세기」이자 「흔함」을 동시에 정한다.** 대장간은 상한이 **보유**라 낮은 레벨 병기를 많이 가져도 그냥 낡은 무기였다.
  시장은 상한이 **하루 매물**이라 **낮을수록 싸고 많이 풀린다** — Lv2 칸이 이 게임에서 가장 많이 흐르는 주력이다. 그래서 청낭서가
  「모든 아군」에서 **「착용 장수만」으로 좁혀지고** 폭약이 **Lv3로 물러났다.**
- **마비산 지속은 90**(한 사이클). 100으로 두면 통솔이 높은 장수에게만 두 턴이 되어 같은 아이템이 장수마다 다르게 돈다.
  (다만 화면 표기는 `time 100 = 1일`이라 90은 **0.9일**로 뜬다 — 책략은 200을 써 「2일」로 떨어진다. 기획자가 90으로 확정했다.)
- **손자병법서의 ±1은 반감 뒤, 하한 0** — 약한 공격이 완전히 무효가 되는 것이 의도다(값으로 보정).
- 패시브 효과 요약(엔진 반영 자리는 시스템 엔지니어 문서): 말 WT −10/−20(절영은 조건부 −15로 **교체**, 합산 아님) · 적로 1회 생존 ·
  육도삼략 30% 반격 · 태평요술 MP −1(하한 0) · 우선 ±10%p(무조건인 0·100은 안 탄다) · 손자병법서 최종 ±1 · 청낭서(착용 장수 부상 면제) ·
  척후기(정찰 단계에 상대 책략 공개).
- 사양서는 `docs/시장 아이템.xlsx`로 신설했다(대장간 엑셀과 같은 규약, 「종류」 자리를 **부류**와 **종류(패시브/액티브)**로 가름).

### 조조 고유기술 교체 — 「화용도 의석조조」 → 「영웅론」 (09-25)

S급 30명의 고유기술을 훑어본 뒤 조조의 기술을 새로 설계해 갈아 끼웠다. 옛 기술(사망 시 1회 부활)은 엔진·화면에서 통째로 걷어 냈다.

**왜 바꿨나** — 「화용도 의석조조」는 **관우가 주인공인 일화**(관우가 의리로 조조를 놓아줌)라 조조가 무엇을 해내는 기술이 아니었다.
효과도 「죽기 전에 걸어 두는 보험」 하나라 판에 직접 개입하지 않았고, 같은 조조군의 순욱(조종)·가후(확정 환술)·곽가(사후 저주)와 비교해
존재감이 약했다. 조조의 능력치(무 75 · 지 94 · 통 98)와 「사람을 꿰뚫어 보는」 인물상에 맞는 기술로 바꾸기로 했다.

후보로 **협천자이령제후**(아군 전체 WT 단축) · **망매지갈**(아군 MP·회복) · **영웅론**(상대 고유기술 견제) 셋을 냈고, 기획자가 **영웅론**을 골랐다.
지금 S급에 상대 고유기술에 맞서는 기술이 없어 역할이 겹치지 않는다.

| 항목 | 결정 (기획자 확정) |
|---|---|
| 효과 | 적 1명의 고유기술을 **봉인** |
| 봉인 기간 | **게임 끝까지** — 「차동풍」으로 횟수를 돌려받아도 막힌다, 「결계」로 안 풀린다 |
| 시전 중인 적 | **그 자리에서 무산**(SP·횟수 환불 없음 — 시전 중 사망과 같은 규약) |
| 대상 | **고유기술이 남은 적만** — 사용 횟수가 있거나 시전 중, 아직 봉인 안 됨. 이미 쓴 적은 조준 불가 |
| SP · 시전 지연 | SP 6 그대로 · 지연 없음(발동 직전을 끊는 카운터라 제가 늦으면 뜻이 없다) |

「이미 걸린 효과를 지운다」는 넣지 않았다. → 결정·교훈 참조. AI는 바꾸지 않았다 — 조준 가능한 적 중 HP가 가장 낮은 적을 봉인한다
(시전 중인 적 우선은 기획자 판단으로 남김). GDD §12 B7을 영웅론으로 고쳤고 부활 관련 서술(종료 조건 · 연출 표 · §4.4 · §8 DSL 예시 ·
`countFallen` 설명)을 정리했다.

### Pawn 개편 뒤 기물 균형 재측정 (09-22)

`npm run power`(모드당 2만 판, 시드 20260817 — 옛 GDD §11-9 표와 같은 조건, 517초). 기물 효과는 Pawn = 0 기준, 능력치를 통제한 뒤의 전투력 점수다.

| | Queen | Knight | Rock | Pawn | Bishop |
|---|---:|---:|---:|---:|---:|
| 3v3 이전 (08-17) | +20.8 | +18.0 | +16.4 | 0 | −11.3 |
| **3v3 개편 후** | **+26.8** | +21.7 | +18.6 | 0 | −7.3 |
| 5v5 이전 (08-17) | +11.4 | +9.5 | +8.7 | 0 | +4.1 |
| **5v5 개편 후** | +11.8 | +9.6 | +10.2 | 0 | +5.4 |

칸마다 표준오차 3v3 ≈3.2 · 5v5 ≈3.6.

- **3v3** — 나머지 넷이 평균 +4점 올랐다. 기준이 Pawn이니 **Pawn이 약 4점(≈승률 1%p) 약해진 것**이다. 둘째 대상을 잃은 손해가 넓어진
  사거리보다 조금 크다. 여전히 Bishop보다는 위(Bishop z −2.2).
- **5v5** — 평균 +0.8, 사실상 그대로. Pawn은 개편 전에도 5v5 최하였다.
- 기물 조합만으로 갈리는 승률 폭: 3v3 8.0 → 8.4%p · 5v5 2.8 → 2.9%p.
- `npm run balance`(200판)도 돌렸지만 기물당 표본 ~155회라 오차가 ±4%p(Pawn 48.2 → 52.3%) — 판단에 쓰지 않았다.

**`POWER_MODELS`는 유지(기획자 확정).** 기물을 뺀 최종 모형의 계수가 전부 표준오차 1배 안팎에서만 움직였다.

| 특징 | 3v3 기존 → 새 | 5v5 기존 → 새 |
|---|---|---|
| at | 39.67 → 39.66 | 22.59 → 23.00 |
| hp | 6.57 → 6.59 | 3.63 → 3.61 |
| might | 1.47 → 1.45 | 0.78 → 0.77 |
| skillS | 34.1 → 30.8 (SE 3.5) | 16.5 → 17.4 (SE 2.5) |
| mp | 0.60 → **0** | 0.55 → 0.64 |

3v3 mp가 0이 된 것은 값이 변해서가 아니라 |z| 1.3이 「<2면 0」 문턱에 걸린 것이다. → 결정·교훈 참조. GDD §11-9에 새 표와 유지 결정을 적었다.

### 금화 경제 — 결제로만 생기는 금화 · 환불 없는 대장간 (09-25)

| 운영에서 무료 금화가 필요해지는 흔한 경우 | 대체 |
|---|---|
| 점검·장애 보상 | 군량·아이템 |
| 출석·이벤트·쿠폰 | 금화 대신 다른 재화 (지금은 없음) |

| 스토어 심사·QA 계정 | 계정에 테스트 표시. 환불·정산 대상에서 뺀다 |

### 영웅론의 일화 — 청매자주논영웅(靑梅煮酒論英雄) (09-25)

허도에 몸을 의탁한 유비가 채소밭을 가꾸며 뜻을 감추던 때, 조조가 푸른 매실에 술을 데우며 천하의 영웅을 논한다. 유비가 꼽는 이름을
하나하나 깎아내린 끝에:

> **「지금 천하의 영웅은 오직 그대와 이 조조뿐이오.」** (今天下英雄，惟使君與操耳)

유비는 수저를 떨어뜨리고, 마침 친 천둥을 핑계로 둘러댄다.

- **정사**: 『삼국지』 선주전 — 영웅 문답과 떨어뜨린 수저
- **배송지 주(『화양국지』)**: 천둥으로 둘러댄 대목
- **연의 창작**(21회): 청매·데운 술의 무대, 영웅 후보를 깎아내리는 문답

위 대사가 **성우 대사**다(기획자 지정). 4컷 순서는 정자에 마주 앉음 → 조조의 대사 → 천둥과 놀란 유비 → 엎어진 잔. 이름이 바뀌어 id도
바뀌므로(`hwa-yong-do-ui-seok-jo-jo` → `yeong-ung-ron`) 열 언어 이름·효과·유래를 추출기의 `SKILL_REDESIGNS`에 한 벌로 들고 간다.
