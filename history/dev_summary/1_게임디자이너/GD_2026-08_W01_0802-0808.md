### 5000판 밸런스 실측 — 기물은 고르고, A↔B급 사이가 가장 벌어진다 (08-02)
조건: 기준 AI, 전원 Lv1, 책략 없음. `npm run balance 5000`(22초).

```
선공 49.8%  후공 50.2%  판정승 0%  무승부 0%
결착 중앙값 time 1259(13일)  최대 2681(27일)   ← 상한 6000까지 2.2배 여유

등급별  S 66.5% / A 59.4% / B 47.3% / C 46.6% / D 40.7%
기물별  King 50.0 / Rock 51.2 / Bishop 47.6 / Knight 50.5 / Queen 52.4 / Pawn 48.2
```

해석:
- 선후공 차이가 없다.
- 기물은 47~52%로 고르다. GDD §11에서 우려했던 Queen · Knight는 문제없이 나왔다.
- 최대 결착 시간이 무승부 상한 `time 6000`의 절반에도 못 미쳐, 상한에 걸려 판정으로 가는 판이 없다(판정승 0%). 동점 무승부는 실측 0.02%.
- **A급과 B급 사이가 12%p로 가장 크게 벌어진다** — 과금 설계상 의도인지 기획 확인이 필요하다(아직 답 없음).

`tools/balance.ts`는 이후에도 Lv1 그대로 둔다 — 바꾸면 이 5000판 실측치와 비교가 안 된다. 실측 방법 상세는 QA 문서.

### WT 바는 「차오르는」 방향 · 배지는 개수만, 이름은 팝업 (08-03 ~ 08-04)
- GDD §3.10 원문 「WT(흰색→회색)」의 해석: 행동이 멀면 빈 회색, 차례가 다가올수록 흰색으로 차오르고, 제어권을 얻으면 금색으로 가득. 「다음이 누구냐」를 한눈에 읽기 위함이다.
- 상태이상 22종을 30px대 셀에 글자로 띄울 수 없어 타일에는 **점(dot)으로 개수만**, 무엇이 걸렸는지는 **독립 팝업**에서 읽는다. 팝업은 제어권과 무관하게 아무 기물이나 눌러 볼 수 있다(GDD §3.9 「정찰」의 기물 클릭과 같은 용도). 처음엔 제어 모달 하단이었다가 눈에 안 띄어 기획자 요청으로 승격.
- 타일 배지 4종의 자리(GDD §3.10): 좌상 고유기술 상태 / 우상 버프 / 좌하 급+레벨 / 우하 디버프.

### 설명문의 시간은 전부 일(日)로 (08-07 기획자 확정)
`time`은 엔진 안에서만 쓰고 플레이어에게 보이는 글은 전부 일이다. 환산은 이미 확정된 것 — `time 100` = 게임 내 1일 = 실시간 1초, `WT 100` = 1일.

| 대상 | 전 | 후 |
|---|---|---|
| 지속시간 | `time 190 동안` | `1.9일 동안` |
| 주기 | `time 100마다` | `1일마다` |
| 대기시간 증감 | `waiting time -100` | `WT −1일` |

영문 `waiting time`은 `WT`로 통일(타일 바 라벨과 같은 말). 엔진 단위를 남긴 곳은 GDD §3.3의 `WT = 190 − 통솔력` 기준값 표와 `time 90/190/290/490` ↔ 1/2/3/5 사이클 대응뿐이다. 설명문 38건이 바뀌었고 GDD §2에 표기 규칙을 신설, §3.7 · §3.8 · §4.2 효과 칸을 일 단위로 고쳤다. → 결정·교훈 참조
