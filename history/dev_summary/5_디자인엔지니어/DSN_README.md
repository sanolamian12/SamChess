# 5. 디자인 엔지니어

## 개요

**화면이 어떻게 보일지 정하고, 그것을 직접 코드로 입히는 사람.** 그림만 넘기는 디자이너가 아니라
CSS·마크업·에셋 가공 도구까지 손수 다루는 **디자이너 겸 엔지니어**다.
이 게임은 화풍(목판·두루마리·금테의 삼국지풍)을 화면마다 다시 입히는 「리스킨」 작업이 아주 많았다.
이 자리가 그 일을 직접 맡아야 클라이언트 엔지니어가 기능에 집중할 수 있다 —
소수정예 팀에서 **가장 먼저 「겸업형」으로 뽑아야 할 자리**다.

## 역할

| 축 | 하는 일 |
|---|---|
| **화풍·UI 비주얼** | 화면별 화풍 리스킨, 레이아웃·치수·글꼴, 9분할 액자(나무·종이 테두리), 아이콘·등급 배지, 700px 최대 화면에서의 눈검사 |
| **연출 그림·애니메이션** | 장수 액션 5자세, 시각효과, 지속형 링, 고유기술 두루마리 연출, 레벨업 도장, 주사위 같은 연출의 그림과 프레임 원본 |
| **에셋 파이프라인** (`tools/build_*.py`) | 장수 초상 배경 제거, 스프라이트·액션 시트 굽기, 화면 배경 자르기, 소리 파일 가공. 외주로 받은 원본을 게임에 들어갈 모양으로 만드는 도구 |

## 다루는 것

- `assets/` — 원본 그림·소리 (git에 올리지 않는다)
- `tools/build_*.py`, `tools/remove_char_background.py` — 원본을 `public/`으로 굽는 도구
- `packages/client/src/style.css` — 화면의 모양

## 다른 포지션과의 계약

- **↔ 클라이언트 엔지니어**: 모양은 이쪽, 기능은 저쪽. 9분할 값(`build_frames.py`의 `SLICE`와 CSS의 `border-image-slice`)처럼
  **두 곳에 같은 값이 있어야 하는 자리**는 도구가 맞는 값을 찍어 주게 만든다.
- **← 게임 디자이너**: pptx 쪽 번호로 화면 지시를 받고, 결과 스크린샷으로 확인받는다.
- **← 외주**: 일러스트·소리 원본을 받아 파이프라인으로 넣는다.

## 이 자리에 필요한 역량

UI 디자인, CSS(9분할 border-image, 레이어 쌓임 순서), 2D 애니메이션, Python 이미지 처리(Pillow 수준), 동양화풍 감각.
