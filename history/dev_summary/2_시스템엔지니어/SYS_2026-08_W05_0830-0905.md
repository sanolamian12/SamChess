### 지형 책략 판정 — `FORMULA.terrainRate`·`isTerrainTactic`·`terrainSucceeds` (09-03)

```
지형  clamp(내 지력 − 10, 0, 100)   ← FORMULA.terrainRate
```

- **표를 따로 안 적는다** — `isTerrainTactic(def)`이 「효과가 **전부** 칸(`kind: 'tile'`)을 겨누는가」로 본다. 지형
  책략이 늘거나 줄어도 데이터만 고치면 판정·확인창·레벨업 안내가 함께 따라온다.

### 도시 건물·부상·병원과 저장 형식 v4 (09-04)
`cityLevel`의 **뜻이 바뀌어**(능력치 → 게이트) 버전을 올렸다 — 「버전은 뜻이 바뀔 때만 올린다」에 정확히 걸리는 첫 사례.

| 필드 | 무엇 |
|---|---|
| `buildings: Record<BuildingId, number>` | **완전 레코드, 0 = 미건설.** 읽는 자리는 `buildingLevel()` 하나 |
| `buildCredits: number` | 남은 건설 기회 |
| `hospitalBusy: number[]` | 바쁜 room의 **해제 시각 목록** |
| `OfficerInstance.injuredAt?` | 부상당한 **시각** |
| `OfficerInstance.healingAt?` | 치료를 시작한 **시각** |

- **저장하는 것은 「사건이 일어난 때」이지 「끝나는 때」가 아니다** — 회복 60분·치료 1분이 엑셀에서 오므로, 끝 시각
  (`injuredUntil`)을 저장하면 값을 바꿔도 이미 저장된 계정은 옛 규칙으로 남는다(`grainAt`과 같은 결).
- **room에 번호를 붙이지 않는다** — 필요한 사실은 「몇 개가 바쁜가」뿐이라 `hospitalBusy`는 해제 시각의 목록이고,
  지난 값은 `syncCity()`가 지우므로 **살아 있는 길이가 곧 바쁜 수**다.
- **시계를 넣는 자리는 여전히 하나 — `syncCity(profile, nowMs)`**가 `syncGrain`을 감싼다(군량 정산 + 완치 정리 +
  지난 room 정리). 셋을 따로 두면 하나를 잊었을 때 조용히 낡은 값이 남는다.
- **건설 기회를 읽는 자리는 `buildCreditsLeft()` 하나이고 `null`이 「제한 없음」**(황궁). 화면이
  `profile.buildCredits`를 직접 보면 황궁의 예외를 빠뜨려 「최대 레벨인데 못 짓는다」가 된다.
- **v3 되접기** — v3에는 무엇을 지었는지도, 기회를 몇 번 썼는지도 없다. 기본 셋만 Lv1, 추가 넷은 0, 기회는
  `3 × 도시 레벨`을 그대로 남긴다. **지어 주는 것이 아니라 고를 기회를 돌려주는** 쪽(재설계가 카드를 돌려주는 것과
  같은 결). 처음엔 「그 도시 레벨에서 지을 수 있었던 것을 최대로 지은 상태」로 되만들었는데, 57쪽 해금표가 조건표가
  아님이 드러나며 근거가 사라졌다.
- **`toRosterEntries(profile, picks, nowMs?)`의 `nowMs`는 넣는 쪽이 뜻을 정한다** — 전투를 만들 때는 **넣는다**(부상을
  안고 싸운다), 전투력을 잴 때는 **안 넣는다**(어뷰징 경로 차단). 「빠뜨리면 조용히 안 걸린다」가 여기서는 사양이다.
- **서버 소유 필드 규칙을 meta에 둔다 — `authority.ts` 신설**(`SERVER_OWNED_FIELDS` · `guardServerOwned()`).
  `server-api`가 아니라 meta에 둔 것은 되접기와 같은 이유다 — 깨져도 화면에 아무것도 안 뜨고, `server-api`에 두면
  DB 없이는 부를 수도 없어 회귀가 안 선다. (서버 쪽은 서버엔지니어 문서.)
- **`buildingRows(profile)`가 화면 문장을 낸다** — 「60 → 110」과 「왜 지금은 안 되는가」. 화면이 `values[level]`을
  직접 펴면 만렙 경계에서 `undefined`가 샌다. 안 지은 건물의 문장을 고르는 자리도 규칙 하나(`BuildingRow.line`).
