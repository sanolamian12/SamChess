## 2. 개편 1단계 — 동점 순번 · 화면용 판정 함수 (09-27)

**결과** — **전투 규칙이 바뀌었다**: WT 동점을 그 순간의 난수가 아니라 **판을 만들 때 한 번 뽑은 순번**으로 가르고, 전투 도중 동점도 같은 순번을 쓴다. 덕분에 배치 화면이 차례를 처음부터 정확히 보여 줄 수 있다. 화면이 쓸 판정(고유기술 상태 · 명상 증가량 · 조준 · 명령 켜짐 · 순서 예보)을 엔진 한 파일로 모아 화면이 규칙을 다시 적지 않게 했다. 대가로 같은 시드라도 예전과 다른 판이 된다(배포 순간 진행 중인 판만 영향).

| 포지션 | 맡은 몫 (결과) |
|---|---|
| 게임 디자이너 | 동점 처리 규칙 변경을 기획 확정 #1로 정함 |
| 시스템 엔지니어 | 동점 순번을 엔진에 넣고 화면용 판정 함수를 신규 모듈로 모음 |
| 클라이언트 엔지니어 | 장수 카드의 고유기술 상태 표시를 엔진 판정으로 옮김 |

**맞물린 자리** — 기획 확정은 「전투 시작 때 뽑는다」였으나 시스템이 구현하며 「판을 만들 때」로 옮겼다 → 배치 화면 순서가 처음부터 맞고, 주사위 연출(주제 3)이 보여 줄 값이 생겼다. 엔진에 모은 판정 함수 중 화면이 실제로 쓰기 시작한 것은 카드 하나뿐이고 나머지는 2단계 이후 붙는다.

**검증** — 순서 예보를 실제 엔진 진행과 대조하는 신규 회귀(3v3·5v5 × 12시드), 일부러 깨 본 결함 넷이 처음엔 둘만 잡혀 입력을 고쳐 넷 다 잡음 · 옛 동점 규칙 회귀 넷 수정 · `npm test` **801 통과** · `smoke:ui` 완주(순서 변경으로 막힌 두 곳 수리). **결정** — 동점 순번은 「판을 만들 때」 뽑는다.
**남은 것** — `smoke:meta` · `smoke:raid` · `smoke:online`은 안 돌렸다(로드맵 8단계) · 판정 함수들을 화면에 붙이는 일.

## 3. 개편 7단계 — 동점 추첨 주사위 연출 (09-27)

**결과** — 배치 단계에 처음 들어올 때 WT 동점 무리가 있으면 판 가운데가 먹빛으로 가라앉고 주사위가 소리와 함께 굴러, 멈추면 양피지 쪽지에 「동점 — 순번 추첨 / 허유 → 곽가」를 띄운다(약 5.4초, 판을 멈추지 않는다). 순번은 엔진 값을 보여 줄 뿐이라 온라인 두 사람이 같은 결과를 본다. 기획자의 영상이 같은 세션에 와서 2단계보다 먼저 당겨 끝냈다.

| 포지션 | 맡은 몫 (결과) |
|---|---|
| 게임 디자이너 | 생성 AI로 주사위 영상을 직접 만들어 넘김, 새 문구 「동점 — 순번 추첨」 열 언어 |
| 클라이언트 엔지니어 | 배치 단계에 주사위 연출을 붙이고 확인 통로(`?dice=1`)를 둠 |
| 디자인 엔지니어 | 영상 배경을 걷어 알파 WebP 스프라이트로 굽는 도구(`npm run dice`)와 화면 모양을 잡음 |

**맞물린 자리** — 기획자가 「투명이든 검정이든 좋은 쪽으로」 넘긴 영상을 디자인이 배경을 걷되 먹빛 바탕으로 검정 느낌을 살려 받고, 클라이언트가 엔진의 동점 순번(주제 2)을 그 위에 띄웠다. iOS가 과녁이라 투명 WebM 대신 알파 WebP로 갔다.

**검증** — 세 바탕 대조 그림과 Playwright 스크린샷(굴러가는 중 · 멈춘 뒤)으로 눈검사. **결정** — 투명 WebM이 아니라 알파 WebP 스프라이트 · 로드맵 7단계를 먼저.
**남은 것** — 동점이 있는 진짜 배치 화면(계정으로 들어가는 판)에서 한 번 확인 · `dice.title` 한국어 외 아홉 언어 번역 기획자 검토.

## 4. 출정하기 — 지참품 판 제거 (09-26)

**결과** — 부대를 고르면 지참품 판이 명령 판을 화면 밖으로 밀어내 [대전상대 찾기]를 누를 수 없던 문제를, 기획자 지정에 따라 출정 화면에서 지참품 판을 빼서 풀었다. 지참 기능 자체는 장터의 지급 · 회수 길에 그대로 있고, 문구는 열 언어에 남겼다.

| 포지션 | 맡은 몫 (결과) |
|---|---|
| 게임 디자이너 | 「지참품 정책은 따로 정한다, 이 화면에서는 뺀다」로 지정 |
| 클라이언트 엔지니어 | 출정 화면에서 지참 판과 관련 연결을 걷음 |
| 디자인 엔지니어 | 지참 판 CSS를 걷음 |

**결정** — 출정하기에서 지참품 판을 뺀다(기능은 장터에 둔다).
**남은 것** — 지참품 정책 자체는 미정 · 예전에 출정 화면에서 지정해 둔 아이템은 계정에 남아 다음 판에 소모되는데 출정 화면에서는 안 보인다(거두려면 장터에서).
