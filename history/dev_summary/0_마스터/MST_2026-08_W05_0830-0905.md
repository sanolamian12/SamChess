## 1. 전투 밸런스 개편 — 크리티컬·지원책·고유기술 5종 (08-31 ~ 09-01)

**결과** — 크리티컬 확률이 `20 + 무력 차`(−10%p)로 내려갔고, 확정 발동이던 지원책 10종이 `시전자 지력 + 대상 지력` 확률 판정이 됐다(저지력 하위 약 37%만 걸러내는 의도). 이에 맞춰 전투력 계수를 모드당 2만 판으로 다시 쟀고(3v3 지력 가중치 +48%, 5v5 무력 −16%), 고유기술 5종(십면매복·신속·장판하뢰·식소사번·수성지주)의 수치를 조정했다.

| 포지션 | 맡은 몫 (결과) |
|---|---|
| 게임 디자이너 | 플레이 체감(「크리티컬이 너무 잦다」, 「지력 캐릭터가 메리트 없다」)에서 공식 두 개와 고유기술 5종 수치를 정하고 재적합 결과를 해석했다 |

## 2. 지형 상호배타 · 지형 책략 재정리 (09-01 ~ 09-03)

**결과** — 성지(수성지주)·화계·수계가 서로의 칸을 덮어쓰지 못하게 됐다. 이어서 지형 책략이 사실상 무조건 발동(지력 50이면 100%)이던 문제를 풀었다 — **수계·매립 삭제**, 진화 Lv6 → Lv7, 지형 책략 발동률 `내 지력 − 10`(바닥 0%) 신설. 책략은 18 → 16종이 되고 「레벨마다 지원 하나·환술 하나」로 예외가 사라졌다. 옛 저장의 수계·매립은 진화로 바뀌어 살아난다.

| 포지션 | 맡은 몫 (결과) |
|---|---|
| 게임 디자이너 | 「수성지주 위에 적이 불·물을 깔 수 있나」에서 출발해 양방향 상호배타를 요청하고, T1~T4(삭제·발동률·판정 기준·옛 저장 처리)를 확정했다 |
| 시스템 엔지니어 | 타일 필터 하나로 세 지형을 배타로 묶고, 지형 판정을 「효과가 칸을 겨누는가」로 데이터에서 읽게 했으며, 옛 성장 스택이 레벨을 잃지 않게 되접었다 |
| 클라이언트 엔지니어 | 확인창과 책략 설명 팝업이 지형 책략의 새 공식을 보여 준다 |

**맞물린 자리** — 기획의 질문 → 시스템 조사에서 「화계만 덮어쓸 수 있다」는 비대칭이 드러나 기획이 반대 방향까지 요청 → 필터 하나로 통일. 판정(엔진)과 표시(확인창)가 같은 순서(지형 → 지원 → 환술)로 갈라져야 한다는 것을 시스템이 맞춰 화면 숫자가 엔진과 어긋나지 않는다.

**검증** — 지형 상호배타 양방향, 발동률 경계(지력 10 → 0%), 확인창이 옛 공식으로 안 돌아감, 옛 저장이 진화로 살아남이 회귀로 박혔다. **결정** — 지형 책략 재정리 T1~T4, `water` 지형은 엔진에 남김.
**남은 것** — AI가 낮아진 화계 성공률을 반영해야 하는가는 아직 안 봤다.

## 3. 도시 건물 체계 · 부상 · 병원 · 황궁 (09-04 ~ 09-05)

**결과** — 도시 레벨 하나가 풀·군량·생산량·부대 상한을 다 정하던 구조를 **건물 일곱**(궁궐·병영·농지·병원·태학·시장·대장간)으로 갈랐다. 건물은 자재가 아니라 **건설 기회**(증축당 3회)로 짓고, 남는 다섯 칸을 황궁이 연다 — 황궁은 헌제 보유 시 **Lv11**. 전투에서 HP 0으로 퇴각한 장수는 **부상**(무·지·통 −10, 1시간 자연 회복, 병원 치료 1분 + room 5분 쿨)을 입는다. 도시 화면은 현황판(도시 관리)과 [건물 관리]로 갈리고, 산 너머 확장 도시와 황제 메인 배경이 붙었다. 저장 형식은 v3 → v4 → **v5**로 되접힌다.

| 포지션 | 맡은 몫 (결과) |
|---|---|
| 게임 디자이너 | pptx 54~59쪽 기반으로 건물 일곱·짓는 규칙·건설 기회·부상·병원 시간표·황궁 Lv11을 확정하고 화면 문구(소개 vs 현황)를 정했다 |
| 시스템 엔지니어 | 엑셀 「도시 건물」 시트 → `buildings.json`, meta에 건물·부상·병원·도시 정산, 저장 형식 v4·v5 되접기, 능력치를 읽는 자리를 하나로 모아 부상이 빠짐없이 걸리게 했다 |
| 서버 엔지니어 | 증축·건설·치료를 서버 경로(`/city/*`)로 옮기고, 부상을 안고 싸운 AI 판의 재생이 어긋나지 않게 전투 시작 시각을 받았다 |
| 클라이언트 엔지니어 | 확장 도시 두 겹 지도, 현황판·건물 관리 분리, 로딩 가리개, 완료 팝업, 황제 메인 배경을 붙였다 |
| 디자인 엔지니어 | 확장 도시·황제 배경, 이름표, 축하 판·로딩 판·팔괘 스프라이트·단추 둘·가마 그림 등 도시 UI 에셋 여섯 장을 붙였다 |

**맞물린 자리** — 시스템이 pptx 57쪽 격자를 해금 조건표로 읽고 구현했다가 기획의 설명(「시뮬레이션일 뿐」)으로 뒤집혀 규칙이 상수 하나(`도시 Lv2부터 짓는다`)로 줄었다. 병원은 시스템의 검산(목표 두 점을 동시에 만족하는 모델이 없다)을 받아 기획이 「치료 1분 + 쿨 5분」으로 정정했다. 「Lv1에 기회가 떠 있는데 못 짓는다」를 고치며 황궁을 Lv11로 올려 「다섯이 남는다」를 지켰고, 회귀가 숫자가 아니라 관계로 잡고 있어 그대로 통과했다.

**검증** — 회귀 498 → **504 pass**(남은 1건은 `assets/` 매핑 기존 실패), 「다섯이 남는다」를 규칙으로 도시를 끝까지 올려 센다. 브라우저로 Lv1 → 확장 도시까지 실제 계정으로 끝까지 봤다. **결정** — 57쪽은 해금표가 아니다, 부상은 전투력에 미반영(어뷰징 차단), 황궁 Lv11·시작 기회 폐지(v5).
**남은 것** — 병원 화면, 장수 상세의 부상 표시, 태학·시장·대장간 세부 사양, 황궁 연출(pptx 59쪽).

## 4. 서버 권위 확대와 새는 구멍 막기 (09-04 ~ 09-05)

**결과** — `PUT /profile`이 믿지 않는 필드가 자재·건물·건설 기회·병원·부상 시각까지 넓어졌고, 그 값을 바꾸는 모든 사건에 서버 경로가 생겼다(`/city/upgrade`·`/city/build`·`/city/heal`·`/market/materials`). H3d 이후 계속 새던 **AI 대전 참가비**(새로고침하면 되살아남)를 `/battle/fee`로 막았다. 「도시 삭제」가 CORS에 `DELETE`가 없어 안 지워지던 버그, 404를 「서버에 못 닿음」으로 읽고 로컬로 물러나 자재가 화면에서만 늘던 버그도 고쳤다.

| 포지션 | 맡은 몫 (결과) |
|---|---|
| 서버 엔지니어 | 도시·참가비·자재 경로를 만들고, 거부 이유를 400으로 돌려주며, CORS `DELETE`를 열었다 |
| 시스템 엔지니어 | 서버 소유 필드 규칙을 meta(`authority.ts`)에 두어 DB 없이도 회귀가 서게 했다 |
| 클라이언트 엔지니어 | 400과 「못 닿음」과 404를 가르고, 자재 구매만은 로컬 폴백을 안 하게 했다(금화만 사라지는 길 차단) |

**맞물린 자리** — 도시 필드를 서버 소유로 돌리며 「경로를 함께 만든다」를 세우자 AI 참가비 구멍이 같은 모양으로 보였다. 서버가 경로를 붙이기 전 프로세스로 떠 있던 사고가 클라이언트의 폴백 판단(404 처리)을 고치게 만들었다.

**검증** — 임시 서버로 새 경로 401 / 없는 경로 404 확인. `SERVER_OWNED_FIELDS` 회귀가 아무것도 확인하지 않던 것을 손으로 적은 기대 목록으로 고쳤다. **결정** — 자재 구매만 로컬 폴백 금지, 자재 가격은 기존 상수에서 파생(10개 = 금화 10냥).
**남은 것** — 온라인 거절 군량이 DB에 안 남는 문제(조사 중단), `PUT`은 `gold`를 여전히 믿는다, AI 무승부의 부상 수는 클라이언트 값.

## 5. 궁궐 화면 개편 — 장수 일람·카드 위 모달 (09-02 ~ 09-03)

**결과** — 랭킹의 양피지·목판·금테 화풍이 궁궐 전체로 넓어졌다. 장수 일람은 10개씩 페이지·등급순 기본 정렬이 되고, [레벨/스킬 관리]·[전적 보기]·고유기술·책략 설명이 전면 화면 대신 **장수 카드 위 모달**로 뜬다. 레벨업 대상은 3프레임 도장으로, 카드 그림은 전투 액션 시트로 움직인다. 「고르기」 판은 두루마리·체크 칩이 되고, 회색 증분과 실제 결과 값을 갈랐다. 레벨업 직후 카드가 옛 값을 보이던 버그도 사라졌다.

| 포지션 | 맡은 몫 (결과) |
|---|---|
| 게임 디자이너 | 화풍 통일·모달 전환·정렬·발동 조건 문구를 요청하고 스크린샷 피드백으로 반복 다듬었다 |
| 시스템 엔지니어 | 등급순·레벨순 정렬을 meta에 더했다 |
| 클라이언트 엔지니어 | 카드 위 이중·삼중 모달 구조, 위치 훅 공유, 팝업을 카드 밖에서 띄워 폭 맞춤, 카드 스냅샷 제거, 증분/결과 칸 분리를 했다 |
| 디자인 엔지니어 | 궁궐 리스킨, 레벨업 표시(금테 액자 실험 → 철회 → 도장 스프라이트), 고유기술 팝업 등급별 배경, 두루마리·체크 칩, 전적 판 색을 맞췄다 |

**맞물린 자리** — 기획의 스크린샷 피드백 → 디자인이 모양을, 클라이언트가 구조를 고치는 왕복이 주 내내 돌았다. 고유기술 팝업이 좁던 것은 CSS 숫자가 아니라 컴포넌트 구조(띄우는 자리)로 풀려 책략 팝업도 같은 자리를 쓴다.

**검증** — `smoke:meta`에 「안 고른 줄의 결과는 지금 값 그대로」를 박았다. 로그인 없는 정적 목업·임시 마운트로 눈검사하는 길을 찾았다. **결정** — 카드 위 모달 전환, 레벨업 액자 철회, 기본 정렬 등급순.
**남은 것** — 전면 화면 `LevelUpScreen`·`RecordsScreen`은 옛 화풍, 책략 아이콘 16종·능력치 줄 명패 그림 대기, 책략 팝업에 스모크 검사 없음.

## 6. 열 언어 텍스트 — 장수 열전·고유기술·책략 (08-31 ~ 09-03)

**결과** — 장수 열전이 **260/260명** 연결됐다(이름 표기 8건을 CSV 쪽으로 통일). 고유기술 31종의 고사를 조사해 열전을 새로 쓰고 40종의 이름·효과·유래를 10개 언어로 넓혔으며, 그 과정에서 「단치도강」이 「**단기도강**」으로 정정됐다. 언어별 소스가 없던 책략은 `sam_tactics.csv`(16종 × 10언어)를 새로 만들어 뜻 번역으로 채웠다. 장수 이름·고유기술·책략이 전투와 메타 전 화면에서 현재 언어로 뜬다.

| 포지션 | 맡은 몫 (결과) |
|---|---|
| 게임 디자이너 | 열전 CSV를 채우고, 고사 조사·톤 교정·출처 표기 방침을 정했으며, 번역 원고와 표기 규칙(고유기술은 「한자 (읽기)」, 책략은 뜻 번역)을 확정했다 |
| 시스템 엔지니어 | 추출기가 장수 이름·고유기술 유래/이름/효과·책략 다국어를 읽어 데이터에 붙이고, 책략 한국어 원문이 엑셀과 어긋나면 실패시킨다 |
| 클라이언트 엔지니어 | 이름·효과를 고르는 picker 함수를 전투·메타 전 화면에 통과시키고, 궁궐 새 키를 10개 언어에 채웠다 |
| 디자인 엔지니어 | 이름 정정에 따라 초상화·고유기술 연출 그림을 리네임·교체했다(연출 이미지 40/40종) |

**맞물린 자리** — 번역 에이전트 6개가 독립적으로 「單齒渡江」을 의심 → 기획이 「정확하지만 파급 큰」 전면 수정을 골라 엑셀·추출기·테스트·그림까지 따라갔다. 책략은 클라이언트가 소스 없이 배선만 해 두었다가 같은 날 기획이 CSV를 만들자, 원문을 직접 찍던 네 자리를 훑어야 실제로 켜졌다.

**검증** — 추출 로그 `[열전] 260/260명`, 고유기술 이름 40/40 · 효과 40/40, 책략 16/16. 번역은 부분 검수만(몽골어 대표 8건). **결정** — 이름 CSV 표기 통일, 고사 「출처는 투명하게·서술은 극적으로」, 단기도강 전면 수정, 책략 이름은 뜻 번역.
**남은 것** — 원어민 검수, 다른 고유기술 이름 전수조사, 전적 판 새 키 9개 언어, 언어를 바꿔 가며 브라우저 확인.

## 7. 사운드 · 지속형 링 애니메이션 (08-31 ~ 09-01)

**결과** — 새 효과음 다섯이 들어와 버튼 소리가 전투 안(커맨드/정보)과 밖(확인/선택/메뉴 이동)으로 갈렸고, 장터 진입음·수계 지형 소리·장수 카드 `paper` 소리가 붙었다. 「고유기술 성우가 배너보다 1~2초 늦게 난다」 버그를 고쳤다. 지속형 링 「불꽃」 6종이 검정 배경을 걷어 0.5초마다 도는 4칸 애니메이션이 됐다.

| 포지션 | 맡은 몫 (결과) |
|---|---|
| 클라이언트 엔지니어 | 효과음 분기·성우 재생 위치 수정, 링 프레임 재생(텍스처 모양으로 애니메이션 여부를 판별) |
| 디자인 엔지니어 | 효과음 파일 반입, 불꽃 링 6장을 투명화해 4칸 띠로 굽는 파이프라인 |

**맞물린 자리** — 디자인이 그림을 굽기만 하면 클라이언트 쪽 목록 없이 화면이 저절로 움직이게 규약을 맞췄다.

**검증** — 링 프레임 회귀 2건. 소리는 브라우저로 직접 들어보지 않고 코드 경로로만 확인했다. **결정** — 게이트에 걸리는 연출의 소리는 시각표 예외로 직접 튼다.
**남은 것** — 화계 생성·진화 소리 녹음, `hall_click`/`select_option` 갈림이 자연스러운지 실플레이 확인.
