## 1. 장수 일람 · 레벨/스킬 관리 · 둔갑천서 (08-17)

|---|---|
| 게임 디자이너 | 37~39쪽 화면 규칙(AT 범위 표기, [E]는 Y/N, 동점은 가나다), 「자리만 만든 것」 처리 원칙, 둔갑천서 되감기 확정 |

## 2. 부대 전투력 산출식 (08-17)

**결과** — 44쪽 「인접한 전투력끼리 매칭」의 눈금이 섰다. 등급이 아니라 능력치·레벨·고유기술 등급으로 재고, **격차 100 = 승률 73%**, 매칭 구간은 예상 승률 45~55%(`MATCH_BAND = 20`)다. 3v3 계수가 5v5의 1.65~1.75배라 두 모드는 서로 비교하지 않는다.

| 포지션 | 맡은 몫 (결과) |
|---|---|
| 게임 디자이너 | 눈금의 뜻 정의, 기획자와 갈린 네 자리 정리(카드 상한 B · 승률로 카드 등급 안 나눔 · 기물 제외 · 「000 점」은 예시) |
| 시스템 엔지니어 | 측정 하네스(`npm run power`)와 산출식(`power.ts`) — 계수는 실측값을 손으로 옮긴 상수 |

**맞물린 자리** — 시스템의 첫 적합이 「그럴듯한 계수, 표준오차 6435」(공선)와 헌제가 D급보다 세게 나오는 외삽을 냈다 → 모형을 고쳐 풀고, 도구가 표준오차를 늘 함께 찍게 했다. 기획자가 제안 넷 중 셋을 뒤집어 담합 방지 쪽으로 정리했다.

**검증** — 모드당 2만 판 + 별도 5천 판 보정, 예측 11구간 전부 ±3%p 이내, 회귀 +22. **결정** — 「점수가 아니라 승률 눈금」 · 전투력에서 기물 제외.
**남은 것** — Bishop 계수가 유일하게 음수(밸런스 과제).

## 7. 온라인 대전 서버 — H1 · H2a · H2b (08-19 ~ 08-20)

**결과** — 전송 층을 갈라(H1) 「판정 주체가 로컬이든 서버든 화면은 같다」를 만들고, 그 저편에 Colyseus 대전 서버(H2a)와 대기열·거절(H2b)을 세웠다. **브라우저 탭 둘로 사람 둘이 처음 붙었고 북군 화면이 처음 떴다.** 이탈·무응답 결말 표와 시간 규칙(배치 30초 · 정찰 30초 · 제어 20초 · 넘기기 3번 · 재접속 유예 60초 · 유휴 2분)이 확정됐다. 서버가 꺼져 있어도 AI 대전은 그대로 돈다.

| 포지션 | 맡은 몫 (결과) |
|---|---|
| 게임 디자이너 | 이탈·무응답 결말 표와 시간 셋의 관계 확정(사장님과), 참가비는 「방이 열린 순간」 |
| 시스템 엔지니어 | `timing.ts`(시간 상수와 관계식), 넘기기 3번 규칙 — 결말은 기존 항복 장치 재사용 |

## 8. 계정 · 로그인 · 서버 권위 정산 — H3a ~ H3d (08-20 ~ 08-21)

**결과** — Supabase 이메일 로그인이 필수가 됐고(게스트·카카오 없음) 계정은 별도 API 서버(`server-api`)의 Postgres에 산다. 참가비·거절·환불(H3b), AI 대전 결과(H3c, 판이 끝난 뒤 서버가 같은 시드로 재생해 검증), 온라인 결과·무승부 택1·시간 충전(H3d)이 차례로 서버 권위로 옮겨 갔다. **주 끝에 `PUT /profile`은 군량을 더 이상 믿지 않는다.**

| 포지션 | 맡은 몫 (결과) |
|---|---|
| 게임 디자이너 | 시간 충전이 서버 시계로 옮겨 가 「시계 역행」 문제가 사라짐(규칙 쪽 확인) |
| 시스템 엔지니어 | `replayLocalMatch()` — 사람의 의도 순서만으로 AI 대전을 처음부터 재생 |
| 서버 엔지니어 | `server-api`(Fastify + Supabase), 내부 API로 정산, 재생 검증 라우트, 온라인 정산과 `'settled'` 통보, `saveProfile`/`saveProfileTrusted` 분리 |
| 클라이언트 엔지니어 | 로그인 화면·비동기 저장(쓰기 큐), AI/온라인/무승부 결과를 서버에 먼저 맡기고 실패 시 로컬로 물러남 |

**맞물린 자리** — AI 대전 이관의 첫 안(봇이 앉은 방)을 사장님이 「AI 대전이 늘수록 서버 부하」로 뒤집음 → 시스템의 결정적 재생 함수 + 서버의 일회성 검증 요청으로 풀었다. 서버가 `PUT`의 군량을 버리자 무승부 군량 보상이 조용히 사라질 뻔해 전용 경로(`/battle/draw-result`)를 새로 냈다.

**검증** — 신설 `smoke:account`(진짜 Supabase), `smoke:meta` 1520줄 전면 재작성, `smoke:online`이 `server-api` 없이도 판이 끝까지 도는 것 확인. **H3d는 실제 소켓에서 돌려 보지 못했다.** **결정** — Supabase(Firebase·카카오 기각) · AI 대전은 「로컬 재생 + 서버 검증」 · `PUT`도 군량을 안 믿는다.
**남은 것** — 온라인 대전 로스터(`enlist.entries`)는 여전히 클라이언트 값(기획자 확인 필요), 무승부 경로 일부 클라이언트 값, 배포 전 이메일 확인 다시 켜기.
