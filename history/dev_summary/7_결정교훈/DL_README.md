# 7. 결정 · 교훈 (공통)

## 무엇을 정리하는가

**「무엇을 정했고, 무엇을 배웠나」의 기록이다.** 포지션이 아니라 모든 포지션에 걸친 공통 섹션이다.
나중에 「왜 이렇게 되어 있지?」라는 질문이 나왔을 때 답이 있는 곳이고,
새로 들어온 팀원이 **같은 지뢰를 다시 밟지 않게** 하는 곳이다.

포지션 문서에는 결정의 결과만 한 줄로 남고, 본문은 여기에 있다.

## 담는 것

### 결정
- **기획자 확정** 사항 — 규칙·수치·정책을 대표/기획자가 정한 것
- **구현 판단** — 설계를 어떻게 가를지 엔지니어가 정한 것
- **뒤집힌 결정** — 무엇을 → 무엇으로, 왜 바꿨나 (예: 부대마다 레벨을 낮추던 것을 없애고 장수 단위로 옮김)
- **기각한 대안** — 왜 그 길로 안 갔나 (예: AI 대전을 서버 방에 올리는 안 → 부하 때문에 기각, 재생 검증으로)

각 항목: **무엇을 · 왜 · 기각한 대안 · 누가(기획자 확정 / 구현 판단)**

### 교훈 — 밟은 지뢰
각 항목: **무슨 일이 있었나 · 왜 조용했나(화면·테스트가 왜 못 잡았나) · 어떻게 잡았나 · 이제의 규칙**

이 교훈들 중 반복될 만한 것은 저장소의 `CLAUDE.md` 「지켜야 할 규칙」으로 올라가 있다.
이 폴더는 그 규칙들이 **언제, 어떤 사고에서** 생겼는지를 시간순으로 보여 준다.
