### 대장간 실제 로그인 스모크 신설 — `smoke:forge` · `smoke:forge-ux` (09-10)

09-09 세션은 헤드리스 브라우저로 타이틀 화면 로드까지만 확인했다(콘솔 에러 없음, `vite build` 정상) — Supabase 로그인 정보가 없다고 여겼다. 09-10에 `.env`에 값이 다 있는 것을 확인하고 `smoke_meta.ts`의 Admin API 계정 생성 방식을 빌려 진짜 계정·진짜 로그인으로 들어갔다(`tools/forge_play.ts` → `npm run smoke:forge`). **「화면 오버라이드는 안 쓴다」** — `?forgeLevel=`을 쓰지 않고 대장간 레벨·금화를 서버에 `saveProfileTrusted()`로 심었고, 그 뒤로는 전부 화면을 눌렀고 1분은 그냥 기다렸다.

**도구 쪽 함정 셋** — 셋 다 「화면이 안 먹는다」와 구별이 안 되는 형태였다.
1. **`window.confirm`을 Playwright가 자동 취소한다.** [회수]의 확인창에 처리기가 없으면 기본이 「취소」라 단추가 고장 난 줄 알았다. `page.on('dialog', d => d.accept())`.
2. **콘솔의 「Failed to load resource」는 주소를 안 적는다.** `page.on('response')`에서 URL을 집어야 한다(결국 그 404는 계정 생성 직후 도시가 없을 때의 `GET /profile`이라 정상이었다).
3. **고정 `sleep`으로 서버 반영을 보면 붙었다 떨어졌다 한다.** 저장이 쓰기 큐를 지나므로 화면이 바뀐 시점과 서버에 남는 시점 사이가 0.8초~5초로 들쭉날쭉했다. 원하는 값이 될 때까지 폴링으로 바꿨다.

그리고 **도구가 만든 경주** — 폴링을 `getProfile()`로 했더니 그 read-modify-write가 날아온 `PUT`을 덮어 회수가 간헐적으로 안 남았다. 행을 날것으로 읽게 고쳐 0.8~1.4초에 안정적으로 남았고 **2회 연속 완주**했다(경로 자체의 문제는 서버 엔지니어 문서).

### `smoke:forge-ux` — 18항목으로 (09-11)

「안 도는 갈래」를 여럿 열었다 — 대개 **그 상태에 도달할 수 없어서** 검사가 헛돌던 자리다.

| 검사 | 왜 필요했나 |
|---|---|
| 팝업 안 장수 카드가 **위로 오는가** | z-index 셋 중 하나만 어긋나도 카드가 밑에 깔리는데 「떴는가」만 보면 통과한다 — `elementFromPoint`로 가운데 점을 본다 |
| 쪽 나누기 (지급 5개·고르기 8명) | 병기를 둘만 심으면 쪽 단추가 아예 안 그려진다 — 일곱으로 늘렸다 |
| 1쪽과 마지막 쪽이 **같은 높이인가** | 눈으로는 「살짝 들썩인다」로만 보인다 |
| 쪽 단추 다섯이 **한 줄에 드는가** | 접혀도 「있긴 있다」 |
| 화살표 **목판이 제대로 깔렸는가** | 그림이 `::before` 바탕이라 요소만 보면 늘 `none`이다 — 예전 검사는 무조건 통과했을 자리 |
| 나무판에 **체크가 켜졌는가** | 안 켜져도 [선택하기]는 눌린다 |
| 병기 그림이 아래 블록과 **같은 세로선인가** | 여백 한 값만 어긋나도 층이 진다 |
| 만렙 제작 목록이 **한 쪽에 두 줄인가** | 새 계정은 대장간 Lv1이라 한 쪽에 다 들어간다 — `?forgeLevel=5`로 밟는다 |
| [제작 취소] 팝업 | 진짜로 취소하면 뒤따르는 「완성까지 기다린다」가 못 돈다 — 열고 [취소]로 닫기만 한다 |
| 브라우저 대화창이 **안 뜨는가** | `confirm()`이 다시 새어 들어오는 것을 막는다 |

- **교체 확인은 스모크가 사실상 안 보고 있었다** — `page.on('dialog')`가 조용히 받아 넘겨서 팝업이 죽어도 통과했다. 이제 떠 있는 판의 문구를 읽고 [확인]을 누른다.
- 단추 치수(78×38)와 「글자가 잘리는가」, [장수 선택]·[장비 회수] 같은 크기(79×40)를 스모크가 함께 잰다.
- 다국어 넘침 `scrollHeight > clientHeight`(pt_BR · mn · ko) — 처음엔 이름 칸만 봐서 「상태」 칸 사고를 놓쳤고 **넘치는 칸을 전부** 훑도록 넓혔다. 그 뒤로 열 폭을 건드릴 때마다 이 검사가 먼저 빨개졌다.

- **「완성!」 팝업이 미지급 품목마다 뜬다**는 것이 드러났다 — 한 번만 닫던 스모크가 30초를 기다리다 죽었다.
