### `smoke:meta`가 죽어 있었다 — 아홉 군데 되살림 (09-04)
여러 세션에 걸쳐 낡아 **간판 화면에서 멈춰 있었다** — 그래서 AI 참가비 구멍을 아무도 못 봤다.

| 무엇 | 왜 낡았나 |
|---|---|
| 게임 이름 만민 → **만인** | `ko.json`만 바뀌고 검사가 안 따라갔다 |
| 지원 언어 5 → **10** | `pt`→`pt_BR`·`pt_PT`, `zh`→`zh_Hans`·`zh_Hant`로 갈렸다 |
| 환경설정 닫기 단추 선택자 | `.btn.ghost` → 모양이 바뀌자 조용히 못 찾음. **`data-action`으로 교체** |
| 캐릭터 풀 10 → **60** | 이번 트랙의 정당한 변경 |
| 도시 자리 셋 → **넷** | 랭킹이 2026-08-25에 더해졌는데 안 따라갔다 |
| CORS에 `POST` 누락 | 실서버는 열어 두는데 스모크 쪽만 낡았다 |
| 군량 세팅을 `PUT` → **서버 함수 직접 호출** | `PUT`이 `grain`을 버리게 됨. 시험용 뒷문을 API에 뚫는 대신 스모크가 제 안에서 띄운 서버의 함수를 부른다 — 제품에 남는 표면이 없다 |
| 자리 클릭에 `force` | 배경이 계속 흔들려 Playwright의 「멈출 때까지」가 안 끝난다(`element is not stable`). 「진짜로 눌리는가」는 바로 위에서 `elementFromPoint`로 따로 확인 |
| 서버 군량 확인을 **DB 직접 읽기**로 | `GET /profile`은 읽으면서 되써 폴링하면 동시 쓰기를 덮는다(거절 군량이 반영됐다가 다음 폴링에 되돌아감) |

**`[data-place]`로 거는 간판 검사**는 화면에 그 속성이 아예 없어 목록이 언제나 비었고, 빈 목록 위의 `for`는 조용히 지나갔다.
속성을 붙이자 곧바로 걸렸다. 재는 대상도 네모에서 **이름표**로 바로잡았다(병영·랭킹의 네모는 그림 왼쪽 끝에 일부러 붙여
