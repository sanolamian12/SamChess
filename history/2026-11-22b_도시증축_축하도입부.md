# 2026-11-22 — 도시 증축 축하 도입부 「용머리를 올리다」

도시 레벨 증축 축하(`CityUpgrade` → `Celebrate`)의 모음 5초에 대장간 · 태학과 같은 길로 장면을 붙였다(`intro="city"`, 기획자). 건물 짓기 · 건물 증축 축하는 그대로(세 빛 나선).

## 무엇
- **장면 — 카메라가 움직인다**(기획자: 「기어에 포커스로 시작 → 풍경 전체로 줌아웃 → 용머리 쪽으로 포커스 → 놓이자마자 햇빛에 빛나며 화면이 빛으로」):
  0~1.3초 거중기 밑동의 기어에 바짝(×3.2 → ×3.4), 톱니바퀴가 천천히(초당 약 90°) 돌며 밧줄이 감긴다 → 1.3~2.3초 궁궐 공사장 전체(×1)로 물러나며 밧줄 끝의 짐이 흔들리며 올라온다
  → 2.4초 짐이 도르래 밑에 닿고 기어가 멈춘다 → 2.6~3.4초 용마루 오른쪽 끝으로 다가가며(×2) 금빛 용머리가 밧줄째 내려온다 → 3.4초 「쿵」(살짝 튐 · 먼지 · 흔들림)
  → 3.55초 곧바로 「쨍」 → 3.7초부터 햇살이 퍼져 5.0초 하얗게. 그 뒤 「도시 증축 완료」 무대 그대로.
- **그림**: 기획자가 생성 AI로 뽑은 일곱 장(`assets/icons/ui/celebrate_intro/city/`, 주문서 `Design/축하연출_도시증축_도입부_프롬프트.html`) —
  배경(한낮의 궁궐 공사장, 용마루 오른쪽 끝이 빈 받침) · 거중기(기어 없이, 축만) · 기어 바퀴(정면, 따로 받아 돌린다) · 짐 · 용머리는 오리고, 반짝임 · 햇살은 검정 바탕 「더하기」.
  밧줄 둘(도르래 → 짐, 위 → 용머리)은 그림이 아니라 CSS다(길이가 변한다).
- **카메라**: 모든 층을 한 「세계」(`.cic-world`, `transform-origin: 0 0`)에 넣고 그 세계를 키우고 민다 — 점 (cx, cy)를 가운데 두는 이동은 (0.5 − z·cx, 0.5 − z·cy) × 판.
  단위는 판 크기(`container-type: size` → `cqw` · `cqh`)라 판 크기가 달라도 같은 장면이다. 가장자리가 배경 밖으로 나가지 않게 기어 쪽은 세로를, 용머리 쪽은 가로를 당겼다.
- **자리**: 그림 안의 비율로 쟀다(주석은 `style.css`의 `.cic-*` 머리) — 배경 받침 (792, 612)px, 거중기 도르래 밑 (92.5%, 14%) · 권양기 축 (38.5%, 79.5%),
  기어 가운데 (50%, 49.5%), 짐 고리 (50%, 2%), 용머리 받침 가로 19~89% · 밑면 93.5%. 같은 구도로 다시 받으면 그대로 맞는다.
- 소리: 축하음뿐(기어 삐걱 · 쿵 · 쨍은 주문서에 「있으면 좋음」).
- 눈으로 보기: `Design/축하연출_도시증축_도입부_완성본.html`(CSS 블록을 옮겨 둔 것 — CSS를 고치면 함께).

## 확인
- 완성본 페이지를 시각마다 멈춰 찍었고, 게임에서 시험 계정으로 [도시 증축] → 도입부(0.4 · 2.2 · 3.6초 사진) → 「도시 증축 완료」 무대까지 확인했다(계정은 지웠다).
- 처음 미리 보기에서 짐이 기어 클로즈업 동안 다 올라가 버려 물러날 때 안 보였다 → 오르는 때를 0.8~2.4초로 늦췄다.

## 다듬기 (기획자)
- 처음 기어를 천천히 — 초당 약 235° → 약 90°(1.7초에 150°, 2.4초까지 더 느려져 멈춤).
- 용머리를 좌우로 뒤집었다(머리가 오른쪽 — `scale: -1 1`). 받침 가운데가 그림의 54% → 46%가 되어 상자 자리를 다시 셈했다.
- 앉는 높이를 받침 블록 위(612px)에서 블록 아래 끝(640px)으로 — 받침이 블록을 덮고 기와에 착 붙는다. 반짝임은 뒤집힌 머리 자리로, 먼지 · 햇살도 그만큼 내렸다.
- 받침 가운데를 블록 가운데에 두던 것을, **받침의 오른쪽 끝을 용마루 끝 블록의 오른쪽 가장자리(814px)**에 맞췄다(왼쪽으로 판 폭 3.3%) — 받침 끝이 용마루 끝과 딱 맞는다.
- 블록 뒤로 삐죽 나온 턱(~825px)이 받침 오른쪽에 보여, 받침을 판 폭 1.3%만큼 다시 오른쪽으로 — 턱까지 받침이 덮는다.
