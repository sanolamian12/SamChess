# 도시 관리 · 건물 관리 — 글자를 아이콘으로, 효과는 확인 팝업으로 (2026-11-12)

궁궐 → [도시 관리] → [건물 관리]의 세 판을 기획자 지정대로 손봤다. 공통된 까닭은 **번역에 따라 판의 줄 수가 들쭉날쭉한 것**이었다 —
글자로 적은 현황(「현재 20 / 최대 20」이 무엇의 현재인지도 안 보였다) · 줄마다의 효과 문장 · 7rem에서 음절로 끊기던 몽골어 건물 이름.

## 도시 관리 — 윗판 2단: 증축 조건

- 왼쪽 단: 도시 레벨 · 건축 자재(옛 「(증축 조건 충족)」 표시는 걷었다). 오른쪽 단: **「증축 조건 Lv4 → Lv5」** + 그 아래 조건 칸들.
- 칸은 아이콘 + 숫자, 채우면 초록 · 못 채우면 붉은 글자(체크 그림은 붉어서 점처럼 보여 빼고 색만 쓴다).
  | 조건 | 아이콘 | 숫자 |
  |---|---|---|
  | 황제 옹립(최대 레벨에서) | `emperor` | 없음 |
  | 남은 건설 기회(남았을 때만) | `build-credit` | 남은 수 |
  | 보유 장수 | `tab-officer` | 보유 / 필요 |
  | S·A급 장수 | `grade-score` | 보유 / 필요 |
  | 건축 자재 | `res-materials` | 보유 / 필요 |
- **조건표는 meta가 낸다** — `upgradeChecklist(profile)`(`meta/src/city.ts`). `canUpgradeCity()`가 같은 표의 **처음 걸린 칸**을 이유로 돌려주므로
  화면의 빨간 칸과 [도시 증축] 밑의 이유가 갈라질 수 없다. 이유 코드 · 문장은 예전과 같다(`city.test.ts` 「증축 조건표」).
- [도시 증축] 단추: 「도시 증축 (재료 10 소모)」 → **「도시 증축 ([자재 그림] -10)」**. `city.upgrade`는 이름만 남겼다.

## 도시 관리 — 가운데 건물 판

- 판 제목 「건물」을 걷었다.
- 현황을 아이콘으로(`BuildingStatus`, 이 화면에만 — 건물 관리 · 건물 상세의 문장은 `buildingText.ts` 그대로):
  궁궐 `tab-officer` 현원 / 최대 · 병영 `res-grain` 현재 / 최대 · 장터 금화 · 자재 · 카드 셋 + 「구매」 · 농지 `grain-rate` 「+1/시간」(지으면 실제 생산량).
- **현황 칸이 오른쪽 벽에 붙는다** — 판의 칸이 `minmax(0,1fr) max-content max-content`(`.cty-blds-st`)라 현황 칸 폭은 가장 넓은 현황(장터)에 맞고,
  줄마다의 **첫 아이콘이 세로 한 줄**에 선다. 남는 폭은 이름 칸이 다 먹는다.

## 건물 이름 — 두 줄 안에 (`screens/fitNames.ts`)

- 단어 가운데서 안 끊는다(`overflow-wrap: normal`). 「Тариала / нгийн」이 「Тариалангийн / талбай」가 됐다.
- `useFitNames(lang)` — 이름마다 「두 줄을 넘는가 · 단어 하나가 칸보다 넓은가」를 재고 넘치면 `--nm-scale`을 0.05씩 내린다(하한 0.6). 배율은 이름 **전부**에
  같이 걸고 그림은 안 줄인다. `ResizeObserver`로 판 폭이 바뀌면 다시 잰다. 열 언어 583px · 몽골어 360px에서 줄일 일은 아직 없었다 — 더 긴 번역 · 더 좁은 화면의 안전판이다.
- 도시 관리와 건물 관리가 같은 훅 · 같은 칸(`.cty-blds-st`)을 쓴다.

## 건물 관리 — 줄은 단계만, 효과는 확인 팝업

- 줄: 이름 · **「Lv1 → Lv2」 / 「없음 → Lv1」**(만렙은 「Lv5」) · 단추. 효과 문장 칸(`.fx`)을 뺐다.
- [짓기]/[증축]을 누르면 **확인 팝업**(`BuildAskModal`, `data-modal="buildAsk"`): 건물 그림 · 이름, 큰 금빛 「없음 → Lv1」, 효과 한 줄(줄에 적던 `lineOf` 그대로),
  건설 기회 그림 -1, [짓기]/[증축] · [취소](`city.bld.cancel`). 확인하면 예전처럼 서버에 짓고 끝 팝업.
- 잠김 안내(`whyBuild`)를 **머리줄 바로 밑**으로 옮기고 판 폭에서 접는다(스페인어 · 이탈리아어가 오른쪽에서 잘렸다).
- 「— 지금 Lv1」을 지웠다 — `reason.build.cityLevelNew/Up` 열 언어에서 `{now}` 꼬리를 뺐다(meta의 한국어 원문 `reason`은 그대로 — 화면은 코드로 번역한다).
- 옛 「이름이 긴 언어는 두 단」 규칙(`[data-lang]` 셋)은 이 화면 하나만 쓰던 것이라 함께 걷었다.

## 다국어

새 키: `city.cond.head` · `city.cond.{emperor,credits,officers,topOfficers}` · `city.bld.market.buy` · `city.bld.farm.rate` · `city.bld.cancel` — 열 언어 다.
몽골어 「구매」는 「Худалдан авах」가 잘려 「Авах」로 줄였다. JSON은 줄마다 제 줄 끝을 쥐고 고쳤다(CRLF · LF 섞임).
