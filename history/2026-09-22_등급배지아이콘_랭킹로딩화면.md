## 1. 등급 배지 — 글자(`S`·`[A]`·「S급 카드」) → 그림

### 그림 굽기 — `tools/build_ui.py`의 `STRIPS` · `build_strip()`

원본 `assets/icons/Grade.png`(1003×231)에 배지 여섯이 **D · C · B · A · S · E** 순으로 가로로 서 있다.
`public/icons/grade-{d,c,b,a,s,e}.png`(128²)로 갈라 굽는다.

- **등분하지 않는다.** 1003 ÷ 6이 칸 경계와 안 맞고, S의 보랏빛 번짐과 E의 날개가 맞닿아 **알파 0인
  틈이 없다**(알파 8 기준으로는 칸이 셋으로만 갈렸다). 등분 자리 ±칸의 1/3 안에서 **알파 합이
  가장 작은 열**을 경계로 잡는다 — 실측 177 · 339 · 498 · 650 · 803. `build_backgrounds.py`의
  `cut_points()`와 같은 생각이다.
- **여섯을 같은 한 변의 정사각에 앉힌다.** 칸마다 따로 경계상자로 키우면 황제(E, 날개)만 작아 보이고
  D가 커 보인다 — 원본의 크기 관계를 그대로 둔다(한 변 = 가장 큰 칸, 세로는 여섯의 합집합).
- `public/icons/`는 git에 없다(에셋 방침) — 다른 자리에서는 `python tools/build_ui.py`를 한 번 돌려야
  그림이 나온다.

### 마크업 — 한 모양, 두 입구

```
<span class="gr" data-grade="S"><img src="icons/grade-s.png" alt="S"></span>
```

- 전투 UI(DOM)는 `ui/grade.ts`의 `gradeBadge()`, 메타 화면(React)은 `screens/GradeBadge.tsx`.
- **그림이 404면 예전의 색 글자 배지로 물러난다**(`data-fallback`). 배지가 통째로 사라지면 등급을 읽을
  길이 없다. React 쪽은 실패를 **등급별로** 기억한다 — 같은 자리에 다른 등급이 오면 다시 청한다.
- 등급 값은 언제나 `data-grade`에 있다. 스모크(`smoke_ui`의 상태 팝업 등급)도 글자가 아니라
  이 속성을 읽도록 고쳤다 — 화면 글자는 그림이 되며 사라졌다.

### CSS — 자리마다 `--gr` 한 줄

`style.css`에 「등급 아이콘」절(등급 색 변수 바로 밑)을 두고, 자리마다 따로 적혀 있던 글자 배지 규칙
열 개 남짓(배경·패딩·둥글기·글자 크기)을 **`--gr`(한 변) 한 줄**로 줄였다. 옛 줄이 남아 있으면
`background:` 단축 속성이 그림 뒤에 색 상자를 깔고 패딩이 그림을 찌그러뜨린다. 크기는 표 줄 1.3rem ·
랭킹 1.1rem · 카드 제목 1.9rem · 레벨업 제목 1.7rem · 카드 스트립 .95rem.

## 2. 랭킹 전용 로딩 화면 — `screens/RankingLoading.tsx`

랭킹은 들어가는 순간 서버를 부른다 — 메뉴는 `GET /ranking/mine`, 세 판은 `GET /ranking`. 그동안
순위 칸은 「—위」, 표는 비어 있다가 한 박자 늦게 채워져 「덜 그려진 화면」으로 읽혔다.

```
┌ 옻칠 판(panel-busy) ────────┐
│         장수 랭킹            │   ← 화면 제목과 같은 글자
│    🥈    🥇    🥉            │   ← 시상대 — 1위가 가운데 한 칸 위, 차례로 뛴다
│   (원반) 불러오는 중…        │   ← .busy-spin 그대로
└──────────────────────────────┘
          [ 뒤로 ]
```

규약 넷(`BusyVeil`과 같은 생각, 다른 점만):

1. **첫 응답까지만 덮는다.** 필터·검색으로 다시 부를 때는 표만 옅어진다
   (`.rk-table-wrap[data-loading]`). `useRankingRows()`가 `ready`(첫 응답 — 성공이든 실패든)를 돌려준다.
2. **뜸 180ms · 머무름 450ms** — `useRankingLoading()`. 짧은 왕복엔 안 보이고, 떴으면 번쩍이지 않게 잠깐 머문다.
3. **가두지 않는다** — 판 아래 [뒤로](`data-action="rankingLoadingBack"`). 가리개와 달리 입력을 막지 않는다.
4. **실패해도 걷힌다** — 「—위」·「불러오지 못했다」 안내는 원래 화면이 그대로 말한다.

새 에셋 없이 있는 그림(`panel-busy` · `loading-spin2` · `medal-*`)을 쌓았다. 문구는 기존
`ranking.loading`을 써서 번역을 더하지 않았다. 「움직임 줄이기」에서는 메달·원반이 멈춘다.
