# 농지 현황판 — 군량 아이콘 · 파수꾼 자리 다섯 (2026-09-25)

병영~전투 UI 개선 세션의 셋째 손질. 농지 메인 화면 윗판(현황판)을 다시 짰다.
기획자와 여러 번 주고받으며 크기·농도를 맞췄고, 아래가 최종이다.

---

## 1. 바뀐 모양

```
┌ 현황 ─────────────────────────────────────┐
│   농지 Lv3         │   🌾 +6/시간          │
│ 도적단 출현   퇴치 완료                     │
│ 파수꾼 배치 (3/3 명)                        │
│ [공손찬] [가후] [서황] [    ] [    ]        │   ← 판 폭 전부, 왼쪽부터
└──────────────────────────────────────────┘
```

| 자리 | 전 | 후 |
|---|---|---|
| 윗줄 오른쪽 | 「시간당 군량 2」 | **군량 아이콘 + 「+2/시간」** (영어 `+2/hour`, 열 언어 각자의 「시간」) |
| 둘째 줄 | 파수꾼 배치 | **도적단 출현** (올라왔다) |
| 「도적단 출현 :」 | 콜론 있음 | **콜론 뺌** — 열 언어 전부(`:`·`：`) |
| 셋째 줄 | 「파수꾼 배치 : 1/1 명 공손찬」(이름만) | 「파수꾼 배치 (1/1 명)」 한 줄 + 그 아래 **자리 다섯** |

군량 아이콘은 장터·병영·출정하기와 같은 `market/grain.png`이고 글자 크기의 1.625배다
(처음 1.25em에서 1.3배로 키움).

## 2. 파수꾼 자리 다섯

- **늘 다섯 칸**, 판의 폭을 다 쓴다(처음엔 제목 오른쪽 남은 폭만 썼더니 칸이 작았다).
- 세운 차례대로 **왼쪽부터** 채운다(King이 먼저 — 저장 차례가 곧 표시 차례).
- 한 칸 = 위에서부터 **등급 배지 + 장수 이름 → 초상화 → 기물 명패**.
  - 「클래스 아이콘」은 **등급 배지**(`GradeBadge`)로 읽었다 — [파수꾼 관리] 줄과 같은 것.
  - 초상화는 전투에서 기물로 서는 그림(`OfficerArt primary="portrait"`, 투명 배경).
  - 기물 명패는 [파수꾼 관리] 줄의 기물과 같은 목판(`.frm-pc`)을 한 치수 작게.
- **테두리**는 `assets/icons/frame_gold_2.png`(이미 `public/ui/frame-gold-2.png`로 구워져
  장터 아이템 액자에 쓰이던 것) — 장터와 같은 처리로 `::after`가 칸 위에 통째로 씌운다.
- **바탕**은 반투명 검정 — 장수가 선 칸은 **73%**, 빈 칸은 **45%**(채워진 자리와 빈자리가 농도로도
  갈린다). 검정은 밧줄 **안쪽으로 들여** 깐다(`inset: 2.5%`, `border-radius: 8%`) — 칸 전체를 칠하니
  밧줄의 둥근 모서리 밖으로 검은 귀퉁이가 삐져나왔다(밧줄은 그림 가장자리 0.4%~4.7%).
- **농지 레벨이 아직 못 연 자리**는 밧줄만 흐리게(`opacity .45`) — 바탕은 빈 칸과 같다.

### 초상화 크기 — 칸 비율 하나가 정한다

초상화는 칸에서 이름·명패를 뺀 높이를 채우므로 **칸의 `aspect-ratio`가 곧 그림 크기**다.
×1.3 → ×1.2 → ×0.9를 거쳐 **9 / 14**로 확정(700px 폭에서 초상화 높이 약 130px, 400px 폭에서 약 48px).

도중에 한 번 막혔다 — 넓은 화면에서는 그림이 칸 **안쪽 폭**에 먼저 닿아(`object-fit: contain`)
칸을 늘려도 안 커졌다. 그림을 **높이로 맞추고 폭은 넘쳐도 되게** 풀었다(`height: 100%;
width: auto`). 초상화는 좌우 10% 남짓이 투명이라 넘치는 몫은 빈 여백이고, 밧줄이 그 위를 덮으며,
칸 밖으로는 `overflow: hidden`이 자른다.

## 3. 다국어

| 키 | 변화 |
|---|---|
| `farm.summary.grain` | 「시간당 군량 {n}」 → **「+{n}/시간」** (en `+{n}/hour`) |
| `farm.info.raid` | 끝의 콜론 제거 |
| `farm.info.guardsLabel` · `farm.info.guardsCount` | **새 키** — 「파수꾼 배치」 · 「({n}/{max} 명)」 |
| `farm.info.guards` · `farm.info.guardsNone` | **지움** — 이름 나열이 자리 다섯으로 바뀌어 안 쓴다 |

`guardsCount`는 이름은 같지만 값이 「{n}/{max} 명」 → 「({n}/{max} 명)」으로 바뀌었다(괄호 포함).
열 언어 모두 같은 자리에 넣었다.

## 5. 확인

- `npm run typecheck` 통과, `npm test` 787건 통과.
- 모양은 CLAUDE.md의 「로그인이 필요한 화면도 눈으로 확인할 수 있다」 방식으로 봤다 —
  `style.css`를 `public/`에 잠깐 복사하고 마크업만 흉내 낸 HTML을 Playwright로 400px·700px에서
  찍고, 그림 크기는 `getBoundingClientRect()`로 재서 배율을 맞췄다(흉내 파일은 지웠다).
- **실제 계정으로 농지 화면을 띄워 보지는 않았다.** 스모크(`smoke:raid` 등)도 이번에 안 돌렸다.
