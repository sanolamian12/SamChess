## 2. 받기 · 자르기 (`tools/tutorial_dub_generate.py`)

- **뒤에서 받기:** `auto EN PT JP CA`가 키 셋(`C:\Users\user\.samchess\gemini_keys.txt`, 저장소 밖)으로 3분에 하나씩 받고 → 받아쓰기로 자르고 →
  듣기 판(`assets/Audio/voice/tutorial/{LANG}/_듣기.html`)을 갱신한다. 무료 한도는 키 · 모델마다 하루 10개라 하루 30명 안팎이다.
- **고친 것:**
  - 받아쓰기 호출이 SDK 시한을 무시하고 20분 넘게 걸려 있어, 호출을 스레드에 띄워 시한(받아쓰기 75초 · 음성 330초)을 넘기면 끊는다.
  - 받아 놓고 못 자른 원본은 도구가 켜질 때 먼저 자른다.
  - 막힌 키는 구글이 알려 주는 시각을 믿지 않고 30분마다 다시 찔러 본다.
  - 언어별 배역: `cast.json`에 `profile_{언어}` · `voice_{언어}`가 있으면 그것을 쓴다(확정된 다른 언어는 안 건드린다).
- **손질 두 가지 (원본을 다시 받지 않고):**
  - `Design/튜토리얼더빙/cut_fix.json` — 조각의 시작 · 끝을 손으로 정한다. 원본 서명(`size:mtime`)이 다르면 무시한다.
  - `{조각}_edit.(wav|mp3)` — 기획자가 손질한 조각이 자른 것을 이긴다. 장비 4번(메아리)이 네 언어 모두 이것이다.

## 4. 게임 연결

- **굽기:** `npm run audio`(`tools/build_audio.py`의 `sync_tutorialvoice`) — `voice/tutorial/{LANG}/{판}.say{n}.wav` →
  `packages/client/public/tutorialvoice/{판}.say{n}.{LANG}.mp3`. 말소리라 24kHz · 64k 모노, 다섯 언어 760조각 · 32MB.
  원본이 없어진 조각은 출력에서도 뺀다. 출력 폴더는 git 밖(`.gitignore`).
- **틀기:** `packages/client/src/audio/tutorialVoice.ts` — 대본 키 `tut.s.{판}.say{n}`에서 파일 이름이 바로 나온다(표가 없다).
  더빙은 `currentDubLang()`, 크기는 효과음(음성) 칸. `TutorialBattleScreen`이 대사 창이 뜰 때 틀고 넘기거나 닫으면 끊는다.
- **확인:** 회귀 `packages/client/test/tutorialVoice.test.ts`(S급 판의 대사 152줄이 전부 이름을 얻고 겹치지 않는다) ·
  다섯 언어 모두 152조각 빠짐없음 · 데모 판(`?tutorial=s-ga-hu`, KR · JP)에서 줄마다 재생 → [다음]에 끊김 · `npm test` 1492건 통과.

## 5. 밟은 것

- **모델이 프롬프트(영어 연기 지시까지)를 소리 내어 읽거나, 대본에 없는 대사를 지어낸다** — JP · CA에서 잦았다(첫 조각이 20~60초).
  원본 안에 진짜 대사가 있으면 다시 받지 않고 받아쓰기로 그 자리를 찾아 `cut_fix`로 자른다. 이웃 줄의 부르는 말이 앞 조각 끝에 붙거나
  빠지는 것도 같은 방법.
- **「더 무겁게」를 설명에 덧붙이는 것은 안 먹혔다** — 관우 CA가 오히려 가벼워졌다. 성우 자체를 바꿔야 했다.
- **원본을 손으로 바꿔 끼울 때 받기 도구와 겹친다** — 끼우기 전에 그 화자가 대기열에 있는지 보고, 끼운 뒤 원본 서명과 `cut_fix`의 서명을 맞춰 본다.
- **듣기 판의 「확인 완료」 체크는 받기와 무관하다** — 브라우저에만 적는 표시다(기획자가 체크를 안 해서 다시 받았다고 오해했다).
