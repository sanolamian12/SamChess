# 편성 부대 목록 — [분류] · 검색 걷기 · 보유 수 아이콘 · 정렬 셋 · [수비군 지정] (2026-11-14)

기획자가 바로 앞에 정한 「부대 이름을 없애고 1군 · 2군으로」(`d8d8162`의 `Design/부대번호_설계.md`)를 **철회**하고 새로 지정했다.
설계 문서와 HANDOFF §7의 가리킴은 지웠다(git 기록에는 남는다). **부대 이름은 그대로 둔다.**

## 화면

- **[분류]**(전체 · 3v3 · 5v5)와 **검색칸**(부대명 또는 장수명)을 걷었다. 두 모드는 한 표에 섞이고 맨 앞 「인원」 열이 줄마다 모드를 말한다.
  그만큼 목록 판이 낮아졌다(`.sqd-list`의 `min-height` 8rem → 0 — 다섯 줄 칸은 그대로).
- 「부대 2 / 10」 → **부대 아이콘**(`icons/tab-squad.png` ← `assets/icons/ui/tab_squad`, 병영 [부대 관리] · 랭킹 탭과 같은 그림) + 「2 / 10」.
  글자는 `aria-label`에 남겼다(`squads.count`).
- 같은 줄 오른쪽에 **[정렬]** — 생성일(만든 차례, 오래된 것이 위 · 기본) · 부대명 · 전투력(큰 쪽이 위). 「장수 이름」 정렬은 없어졌다.
  생성일은 계정의 부대 차례로 낸다(`createdAt`은 옛 부대에 없다). 한국어 「부대 이름」 → 「부대명」.
- 단추 판 [새 편성] 아래 **[수비군 지정]** — 누르면 목록이 「고르는 중」(고를 수 있는 줄이 옅은 금빛, 성립 안 하는 부대는 흐리게 막힘)이 되고
  안내 한 줄 「수비군으로 삼을 부대를 누른다.」 · 단추는 [그만두기]. 줄을 누르면 `setGarrison`(그 부대의 모드 수비군) → **수비군 설정 화면**.
  거기서 [뒤로]는 목록으로 돌아온다(`garrisonPolicy` 화면의 `from: 'squads'`). 고를 부대가 없으면 단추가 잠긴다.
  수비군 설정 화면 자체는 기획자가 이어서 손본다.

`squads.filter` · `squads.search` · `squads.noResult` · `squads.sort.members`를 지웠다.
