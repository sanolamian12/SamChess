# 2026-11-27f 전투 아이템 — 화면 개편 · 재고 걷음 · 구매 연출 · 섬광 가장자리

기획자 코멘트를 따라 장터 「전투 아이템」(`market/ItemShop.tsx`)을 용병 시장 · 도시 물자의 꼴로 다시 짰다.
관리자 화면(`../SamChessAdmin`)은 `marketTaken`을 읽던 두 곳을 함께 고쳤다.

## 재고(하루 매물)를 걷었다

- 「시장 Lv − 해금 Lv + 1」개를 하루에 푸는 규칙을 걷었다. **구매를 막는 것은 금화와 보관함 상한(`(시장 Lv − 1) × 20`)뿐**이다.
  물량은 보관함 상한이 이미 막고, 재고는 사람만 불편하게 했다.
- 「오늘 산 수」(`marketTaken`)도 함께 없앴다. 타입 · 서버 소유 목록 · 되접기에서 지웠고, 옛 계정의 값은 되접기가 버린다
  (버전은 그대로 — 필드가 빠질 뿐이다). `market.test.ts`에 「옛 값은 버린다」 회귀를 더했다.
- 관리자 화면: 시장 탭의 「오늘 산 수」 줄과 지급 표의 「하루 매물」 문구를 지웠다.
- GDD §6.5의 「하루 매물」 줄은 지운 줄로 남기고 까닭을 적었다. HANDOFF의 옛 갱신 문단에도 표시를 했다.
- ★ **기획자가 「물량이 다 나갔다」를 본 까닭은 코드가 아니라 서버였다.** 게임 API가 11:14에 켜졌고 재고를 걷은 코드는 15:04였다 —
  `npm run server-api`는 파일을 다시 읽지 않는다. 다시 띄운 뒤 진짜 서버로 장터 Lv2에서 탕약을 한 개씩 4번 + 묶음 3개를 사 통과(보유 7)를 봤다.

## 화면

- 머리 판: 금화 | 보관함 그림 + 보유/최대(가득이면 붉은 글자).
- 목록 판: 한 쪽에 카드 셋(그림 | 이름 · 가격 / 효과). 쪽 번호 없이 판 위 · 아래 나무 테에 큰 화살(오르내림)을 얹는다.
  위 화살이 오를 때 잘리지 않게 이 판만 몸통의 `overflow`를 풀었다(뿌리 `.scr`가 막으므로 스크롤은 안 생긴다).
- 카드 높이 · 판 높이는 **열 언어 × 모든 아이템 가운데 가장 큰 것**으로 고정한다 — `useAllLangLayout`에 `panel: false`(숨은 사본으로 재는 자리)와
  `width`(가장 넓은 줄의 폭을 `--row-w`로)를 더했다. 효과 글은 언제나 두 줄 자리를 잡는다.
- 카드를 누르면 곧장 「구매할까요?」 판. 못 사면 잿빛이고, 누르면 내관이 까닭을 말한다.
- 판 밑에 [보관함으로](쪽빛 붓 획 + 까딱이는 상자). 보관함이 비면 막힌다.
- 효과 글: 탕약 · 차 · 목우유마에서 「(자신 포함)」을 뺐다(아군에 자신이 든다). 대완마는 「착용 장수의 WT −10」.
  정정은 `extract_data.py`의 `MARKET_ITEM_TEXT_FIXES` · `MARKET_ITEM_TEXT_I18N`이다.

## 구매 연출 (`Celebrate`의 `coins`)

- 작은 급인데 제 도입부를 쓰는 하나다(1.8초, `COINS_MS`).
- 화면이 어두워지고, 바닥에서 금화 스물넷이 물결 일곱으로 「짤그랑」 터지며 약한 분수처럼 오르다 하얘진다.
  금화 자리 · 시각은 고정 값(`COIN_DROPS`)이라 난수가 없다.
- 무대: 뒤는 물자 상자(`ui/cel-stock.png` ← `assets/icons/ui/shop/ic_mk_stock`, 대장간의 모루 자리)이고,
  앞에 산 아이템의 **금테 메달**(`market-items/medal-{id}.png`, `build_market_items.py`의 `build_medals`)이 튀어나온다.
  붓 획 한 줄(획 색 = 해금 레벨)과 「보관함에서 확인해주세요.」가 이어진다(`market.bought.hint` × 열 언어).
- 소리 `coin_clink`는 **임시로 합성한 금속음**이다(`assets/Audio/effects/coin_clink.mp3`). 같은 이름으로 바꿔 넣으면 그대로 쓴다.
- 시나리오 HTML은 만들지 않았다 — 새 그림 주문이 없고 짧아서 실제 화면으로 고쳤다.

## 섬광의 사각형 티 (모든 `BlinkGlow`)

- 돌리면 가장자리에 마름모가 비쳤다. 까닭은 둘이었다.
  - 그림이 16:9라, 세로로 뻗은 빛줄기가 위 · 아래 변에서 끊겨 있었다(흰 별빛은 맨 윗줄 밝기 49).
  - 흰 별빛에 옅은 안개가 넓게 깔려 있었다.
- `build_ui.py`의 `glow_fade`로 고쳤다 — 내접 타원으로 가장자리를 0까지 줄이고(`GLOW_FADE`), 바깥으로 갈수록 옅은 안개만 깎는다(`GLOW_HAZE`).
  색은 원래 밝기로 편다(지운 뒤의 투명도로 나누면 옅어진 자리가 하얗게 탄다).
- 처음 값(바닥 48)은 빛줄기 끝까지 짧게 해서 30으로 낮췄다.
- 그림은 git 밖이다 — 다른 PC에서는 `public/ui/glow-blink*.png`를 지우고 `npm run ui`(mtime으로 건너뛰므로).
