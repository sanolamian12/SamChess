# 입장 영상 · 가입 오프닝 (2026-10-19)

기획자가 「전에 로그인하면 카메라가 하늘로 올라갔다 내려오며 메인으로 바뀌는 연출을 넣었는데 안 보인다」고 물었다.
찾아보니 **소재만 있고 이은 적이 없었다.** 그 자리에서 입장 영상을 붙이고, 이어서 새 계정용 가입 오프닝을 기획자와 몇 차례 주고받으며 만들었다.
커밋 `5890a02`(main에 푸시).

## 1. 「안 보인다」의 정체

- 처음엔 [입장] 뒤의 **입성 로딩**(가마 · 「도시를 불러오는 중」, `EnterLoading`, 10-13)을 말하는 줄 알고 재 봤다 — 실제 앱에서 프레임마다 재니
  1.3~3.2초 동안 정상으로 떴다(Playwright, 시험 계정). 기획자가 말한 것은 그게 아니라 **시간대별 영상**이었다.
- `assets/opening/`에 `입장동영상_1_낮` · `_2_황혼` · `_3_밤`(10초, 720×1280, 9월 11일)이 있었는데 **그것을 부르는 코드가 git 어디에도 없었다** —
  클라이언트 소스 · `public/` · 전체 이력 · stash · 매달린 커밋(`git fsck`)까지 뒤졌다. 세션 기록은 9/22 이후만 남아 그 전 사정은 알 수 없다.
- 프레임을 뽑아 보니 영상은 **간판 그림과 같은 성문 앞 → 하늘(독수리) → 메인 그림과 같은 저잣거리**로 끝난다 — 겹쳐 넘기기에 꼭 맞는 소재였다.

## 2. 입장 영상 — 간판 [입장] → 메인

- 흐름: [입장] → 입성 로딩(인증 · 프로필 왕복) → **시간대 영상**(`screens/EnterCine.tsx`) → 메인. 시간대는 배경과 같은 `currentBand()`(7~16 낮 · 16~20 황혼 · 나머지 밤).
- **메인은 영상 밑에서 이미 서 있다.** `App.tsx`가 계정을 읽자마자 화면을 메인으로 바꾸고 그 위에 영상을 덮는다 — 영상이 끝나 흐려질 때(0.7초) 비치는 것은
  그림까지 다 받은 메인이고, 영상 끝 장면과 메인 배경이 같은 저잣거리라 이음매가 안 보인다.
- 영상은 **계정을 안 뒤에** 튼다 — 새 계정(도시 이름 짓기로 가는 길)에 성 안 장면을 틀어 놓고 끊을 일이 없다.
- 안 트는 경우: 새 계정 · 끊긴 판으로 곧장 돌아가는 길(AI 판 · 온라인 재접속 표가 있으면) · 저장된 세션으로 새로고침.
- **못 돌면 막지 않는다** — 파일 없음(`error`) · 재생 거부(소리를 끄고 한 번 더) · 4초 동안 시작 안 함이면 곧장 지나간다.
- 소리: 영상 동안 배경음악을 붙들고(`holdBgm`) 끝나면 이어 튼다. 음소거는 같은 스위치(`bgmMuted`). [입장] 클릭이 사용자 조작이라 소리 자동재생이 허락된다.
- [건너뛰기]는 0.9초 뒤에 오른쪽 위에. 영상은 입장 팝업을 여는 순간 **미리 받아**(Blob URL) 로그인 왕복 동안 다 받는다. 포스터(첫 프레임)를 깔아 검은 번쩍임이 없다.
- 앱 틀은 1:2, 영상은 9:16이라 `cover`로 좌우를 약 11% 자른다.

### 낮 · 황혼은 20초 한 파일에서 자른다 (기획자 지정)

- `입장동영상_1_2_낮_황혼.mp4`(20초)에 낮 · 황혼 두 편이 이어 붙어 있다. 장면 전환 검출(`select='gt(scene,0.25)'`)로 **9.833초 = 24fps의 236번째 프레임**을 찾았다.
- 앞 절반은 `_1_낮`과 같은 영상(프레임 차이 평균 1.4/255 — 인코딩 차이)이고, **뒤 절반은 `_2_황혼`과 다른 영상**이다. 그래서 낮 · 황혼 둘 다 20초 파일에서 쓴다.
- 자르기는 **프레임 단위**(`trim=start_frame/end_frame`, 소리는 `atrim`)로 — 시각(`-ss`)으로 자르면 키프레임에 붙어 경계가 밀린다. 경계 앞뒤 다섯 프레임을 찍어 다른 시간대가 안 섞인 것을 봤다.

### 굽기 — `npm run opening` (`tools/build_opening.py`)

- 원본이 10초에 4~7MB라 휴대폰에서 [입장]마다 받기 무겁다. 해상도는 그대로, H.264 CRF 26 + `+faststart`로 줄였다(2.4 · 1.8 · 1.5MB). 포스터 JPG도 함께.
- 다시 구울지는 시각이 아니라 **원본 sha1 + 자르는 프레임**으로 정한다(`public/opening/sources.json`). 원본 폴더나 ffmpeg가 없으면 건너뛴다고 알리고 통과(에셋 방침).
- `public/opening/`은 `.gitignore` — 다른 PC에서는 `npm run opening`을 한 번 돌린다.

## 3. 가입 오프닝 — 새 계정이 도시 이름을 지은 뒤

기획자와 네 번 주고받으며 모양이 정해졌다. 최종:

1. **첫 대사**(석양 위, 한 줄씩 1.3초) — 도시 이름을 지으면 곧장 시작.
   > {ID}는 구국제민(救國濟民), 곧 나라를 구하고 백성을 살리라는 뜻을 받들어 거병하니, / 거점의 이름을 「{도시}」라 하였다. / 그 뜻을 함께할 다섯 인재가 모였나니…
2. 그동안 **다섯 장수가 다가오는 그림 일곱 장**(`opening_2~8`)이 0.5초마다 겹쳐 넘어가 8에서 멈춘다.
3. **판 위 W 대형** — `slot-first` 판(2:1)이 뜨고 처음 받은 다섯이 **한 명씩 「팡」**(D → C → B → A → S, 0.65초 간격, 작게 났다가 1.25배로 부풀고 자리 잡음, 효과음 `battle_collection_open`).
   왼쪽부터 D · B · S · A · C, 위 줄 B · A · 아래 줄 D · S · C. 크기는 C · D 1 · A · B 1.1 · S 1.2배. 그림 밑에 등급 표시 + 이름(궁궐 · 병영과 같은 Song Myung).
4. **둘째 대사**(장수들 그림자 위) — 천하를 통일하고 백성이 안정되는 그날까지! / 도시의 흥망과 이들의 운명이 그대에게 달렸다!
5. **[성 안으로 들어가기]** → 8번 장면 한가운데로 0.7초 파고들며 하얗게 번쩍 → 흰 섬광 속에서 1.45배로 뜬 메인이 줄어들며 자리 잡는다. **입장 영상은 안 튼다**(기획자 확정).

### 만든 방식

- **그림은 배경과 같은 층(`ScreenChrome`의 `artOverlay`)에 겹친다.** 도시 이름 짓기 화면의 배경 `new-city.jpg`가 곧 `opening_1`과 같은 장면이라 2부터 그 위에 얹었다.
  층을 따로 두면 배경만 드리프트로 흔들려 겹치는 순간 그림이 어긋난다. 그림은 png 원본(360×640) 그대로 JPEG로만 바꿨다(기획자 선택 — 영상에서 720p로 다시 뽑는 안은 안 택함).
- **화면이 바뀌는 순간을 넘는 전환은 두 곳에 나눴다.** 파고들기 · 번쩍은 가입 화면(`.ngo-leaving`, `.ngo-flash`), 메인이 줄어드는 쪽은 App(`#frame[data-arrive]`) —
  가입 화면은 그때 이미 내려가 있다. **이음매는 흰색이다** — 앞이 흰색으로 끝나고 뒤가 흰색에서 시작한다.
- W 대형의 크기 기준은 판 안쪽 폭(`container-type` + `cqw`) — C · D가 17cqw. 둘째 대사 · 단추의 아래 칸(`.ngo-foot`)은 처음부터 높이를 잡아 둬, 내용이 들어올 때 판이 밀려 올라가지 않는다.
- `{ID}`는 **로그인 이메일의 @ 앞**(기획자 확정) — 이 게임에 따로 지은 이름이 없다. 한국어 조사는 값에 붙인다 — `josaOf(id, '은는')`에 「은는」을 더했고,
  「(이)라」는 `copulaOf()`를 새로 뒀다(`ui/eventText.ts`). 다른 언어는 조사 자리 없이 그 언어 어순으로.
- 계정은 이름을 지은 순간 이미 서버에 있다 — 오프닝 도중 창을 닫아도 다음 [입장]은 메인으로 간다(오프닝은 다시 안 뜬다).

### 거쳐 간 모양 (버린 것)

- 처음엔 장수 공개를 **장터 1회 뽑기 연출**(`CardRewardReveal` — 효과음 · 섬광 · 카드 · [확인])로 다섯 번 돌렸다 → 기획자가 [확인] 없이 2초로 → 그래도 다섯에 약 21초가 걸렸고,
  기획자가 섬광 없이 판 위 「팡」으로 바꿨다(약 3초). 자동 넘김(`autoMs`)을 위해 고쳤던 `CardRewardReveal`은 원래대로 되돌렸다 — 장터 · 도적떼는 영향 없음.
- 판 그림: `panel_done`(9분할) → `slot-first.png`(세로 그림을 9분할로 2:1에 폄 — **안쪽 구름무늬가 찌그러졌다**) → 기획자가 **2:1로 다시 그린 `slot-first2.jpg`를 통째로** 깐다.

### 굽기

- `npm run opening`이 가입 그림 일곱 장(`public/opening/signup-2~8.jpg`)도 굽는다.
- `npm run ui`(`build_ui.py`)가 `slot-first2.jpg` → `ui/slot-first.png`(폭 1400, 바깥 검정 약 21px를 걷음). 판 비율 2.02 → 2:1 상자에 `100% 100%`.
- `build_ui.py`의 검은 바탕 걷기가 **`.jpg`일 때만** 돌았다 — 확장자만 `.png`이고 바탕이 불투명 검정인 그림(`slot-first.png`)이 검은 테를 두른 채 구워졌다.
  「투명 칸이 하나도 없는 png도 걷는다」(`opaque()`)로 고쳤다. 이 조건에 걸리는 그림은 그것 하나뿐인 것을 확인했다(다른 그림 결과 불변).

## 4. 문구 — 열 언어

- 새 키: `enter.skip`(건너뛰기) · `newgame.say` · `newgame.say2` · `newgame.enter`(성 안으로 들어가기). 줄은 `\n`으로 나누고 화면이 한 줄씩 띄운다.
- 「구국제민」은 한자를 두고 바로 뒤에 뜻을 풀었다(한국어 「곧 나라를 구하고 백성을 살리라는」). 일본어 · 중국어는 그 언어의 한자 표기.
- 다른 언어 문장은 이 세션에서 옮긴 것 — **기획자가 번역을 확인하기로 했다**(몽골어는 특히).
- 줄 끝: 이 저장소의 i18n JSON은 CRLF/LF가 섞여 있다. Edit 도구로 한 줄을 고쳤더니 ko.json **전체**의 줄 끝이 바뀌었다(`--stat` 2,253줄) — HEAD 원본에서 다시
  「이웃 줄의 줄 끝을 따라」 넣었다. Python 텍스트 쓰기도 `NewGameScreen.tsx` · `build_opening.py`를 CRLF로 바꿨다 — LF로 되돌렸다. CLAUDE.md에 이미 적힌 함정 그대로다.

## 7. 교훈

- **소재가 있다고 이어진 것은 아니다.** 기획자는 「붙였는데 안 보인다」로 기억했지만 코드는 한 번도 없었다. 「왜 안 되지」 전에 「부르는 자리가 있나」를 grep · git 이력으로 먼저 본다.
- **Playwright의 Chromium은 H.264를 못 푼다.** 영상이 곧장 `error`로 걷혀 「못 돌면 지나간다」 갈래만 시험된다 — 실제로 보려면 Edge(`channel: 'msedge'`)로 띄운다.
  거꾸로 다른 `*_ux` 도구들이 지금 통과하는 것은 그 우연 덕이다(로그인 뒤 10초 영상이 메인을 덮지 않는다) — CLAUDE.md에 적었다.
- **세로 그림을 9분할로 눕히면 테는 살아도 안쪽 무늬가 찌그러진다.** 9분할은 가운데가 무늬 없는 판일 때만 안전하다 — 무늬가 있으면 목표 비율로 그린 그림을 통째로.
- **「정확히 그 단계」를 기다리는 검사는 앞 단계가 늦으면 지나쳐 버린다.** 그림이 4번일 때를 기다리다 앞의 그림 받기 확인이 늦어 5번으로 넘어간 뒤라 시간 초과가 났다 — 「4 이상」으로.
- **화면이 바뀌는 순간을 가로지르는 전환은 양쪽이 같은 색에서 만나야 한다.** 한 컴포넌트가 다 하려 하면 그 컴포넌트는 이미 내려가 있다.
