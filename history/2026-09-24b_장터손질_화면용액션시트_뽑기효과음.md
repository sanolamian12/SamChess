앞 세션(`2026-09-24_장터상점UI_재구성.md`)이 목업대로 세워 둔 장터를 **기획자가 화면을 한 장씩
눌러 보며** 손질했다. 화면 손질이 대부분이고, 그 사이에 드러난 것 둘이 제법 크다 —
**화면의 꼬마 장수가 흐린 이유는 해상도**였고(전투용 110² 시트를 늘려 그렸다), **「원본이 없는
장수 8명」은 원본이 없던 게 아니라 파일 이름이 틀려 있었다.**

- **장수 카드 셈을 한 자리로** — 장터 현황판과 용병 시장 머리 판이 「합 n장 · 정리 가능 m장」을
  함께 보여 주므로 `cardTally()`(`market/parts.tsx`)로 모았다. 두 판이 따로 세면 한쪽만 낡는다.
- **「보유 카드 : 4 → 1」의 숫자 하나만 칠하기** — 번역문을 `{to}` 자리에 표식을 넣어 갈라 그 숫자만
  감싼다. 문장을 조각으로 나눠 적으면 어순이 다른 언어에서 조각이 어긋난다.
- **장터의 참나무 단추 규칙에 `:not(.pg-btn)`** — 부대 목록·출정이 이미 밟은 자리. 안 빼면 화살표
  목판이 참나무 액자에 갇힌다(같은 세기라 파일에서 아래인 장터 쪽이 이긴다).
- 더는 안 쓰는 문구 `market.recycle.use`는 지웠다. `market.reveal.title`(「뽑았다」)은 남아 있다 —
  부르는 자리는 없다.

## 2. 도는 후광이 가로 스크롤을 만들었다

뽑기 결과의 후광이 부풀 때 가로 스크롤이 생겼다 사라졌다 했다. **돌아가는 네모는 45°에서 외접
상자가 √2배**라, 그림은 판 안에 있어 보여도 **상자**가 판을 넘었다.

- 배율을 옛 값의 80%로 — 단발은 `@keyframes mkt-halo`의 `.86 ↔ 1.06` → `.69 ↔ .85`, 8연 칸은
  `.mkt-portrait.sm .mkt-halo`의 `inset -22%` → `-7.6%`(상자 1.44배 → 1.152배).
- **8연 칸은 따로 크기를 잡고 있어** 첫 수정이 거기엔 닿지 않았다 — 기획자가 8연을 눌러 보고 알았다.
- 판(`.modal.mkt-done`)에 `overflow-x: hidden`을 걸어 둔다. 네 칸이 판 폭을 꽉 채워 양끝 칸 후광의
  상자가 판을 스칠 수 있는데, 그림이 둥글어 상자 귀퉁이가 잘려도 보이는 빛은 안 잘린다.

## 3. 화면용 액션 시트 — `public/actions-hd/` (흐림의 원인은 해상도)

뽑기 결과의 꼬마 장수가 번져 보였다. 원본(`assets/CharsAction/`)은 한 칸 307px인데
`build_action_sheets.py`가 **전투 판 한 칸에 맞춰 110²로** 굽고, 화면은 그걸 118px 남짓으로 —
2배 화면에서는 236px로 — **늘려** 그리고 있었다. 장수 카드·장수 상세도 같은 시트다.

기획자와 세 안(따로 굽기 · 110px로 작게 그리기 · `pixelated`)을 놓고 **따로 굽기**로 정했다.

- 도구가 **한 번의 처리에서 크기만 달리** 두 벌을 뽑는다 — 배경 제거·몸통 찾기·잔디 제거는 한 번
  (`build_one(path, sizes)`). 칸 안 자리(몸통 90%·발끝 95%)가 같아서 화면이 어느 쪽을 그려도 같다.
- **240² WebP** — `quality 88`, 알파는 무손실. 한 명 ≈ 85KB로 **110² PNG와 거의 같은 크기**다
  (260명 20.3MB vs 21.2MB).
- 전투 판은 계속 110²(`frameWidth: 110`에 묶여 있다). 화면(`OfficerActionArt`)만 큰 시트를 쓰고,
  **없으면 110²로, 그것도 없으면 초상화로** 물러난다(`actionSheetHdUrl` → `actionSheetUrl` → `OfficerArt`).
  큰 시트를 안 구운 사람 화면도 예전처럼 보인다.
- 건너뛰기는 **두 벌이 다 있어야** — 큰 시트가 나중에 생겨 110²만 있는 사람이 흔하다.
- `actions-hd/`는 `.gitignore`(`actions/`와 같다). 다른 기계에서는 `npm run actions`를 다시 돌린다.
  전체 굽기가 1분 반 남짓 → **10분 남짓**으로 늘었다.

## 4. 「원본이 없는 장수 8명」은 이름이 틀린 파일이었다

도구가 몇 주째 「아직 원본이 없는 장수 8명」과 「대응 장수가 없는 파일 8건」을 **따로** 찍고
있었는데, 둘을 나란히 놓자 한 글자씩 틀린 짝이었다. `CharsAction/`은 290건이지만 30건은 같은
장수의 png·jpg 둘이라 이름은 260개다.

| `Chars/` 표기(표준) | 틀려 있던 파일 |
|---|---|
| 김선 | 금선.png |
| 송헌 | 송겸.png |
| 왕해 | 왕개.png |
| 왕루 | 왕누.png |
| 장흠 | 장흥.jpg |
| 주령 | 주영.jpg |
| 포륭 | 포용.png |
| 한호 | 한조.png |

기획자 확인 뒤 `assets/CharsAction/`의 파일 이름을 바꾸고 여덟만 다시 구웠다 — **260/260**.
이 여덟은 그동안 전투 판에서도 액션 시트 대신 초상화로 섰다. `assets/`는 git에 없으므로 **다른
기계의 원본 폴더에서도 같은 이름 바꾸기가 필요하다.** 표준은 언제나 `Chars/`의 파일명이다.

★ **「없다」와 「못 맞췄다」를 따로 세면 짝이 안 보인다.** 경고 두 줄이 같은 수(8)였는데 몇 주를
지나갔다.

## 5. 뽑기 효과음

`assets/Audio/effects/`의 `cardx1.mp3`(단발) · `cardx8.mp3`(8연) → `npm run audio`로 `public/effects/`.

- **단발** — 소리가 먼저, 섬광은 **1.5초 뒤**. **8연** — 소리와 **동시에**.
  값은 `MercView.tsx`의 `PULL_SOUND` 한 자리다.
- 소리는 무대(`BurstStage`)가 아니라 **부르는 쪽이 튼다**(단발·8연이 다른 소리다). 무대는 `lead`로
  첫 섬광과 화면 번쩍임(`.mkt-flash`의 `animation-delay`)만 민다. 기다리는 동안 눌러서 건너뛸 수 있다.
- `market_ux.ts`의 섬광 스크린샷은 **1.5초를 다시 적지 않고** `.mkt-burst[data-frame]`(첫 칸이 실제로
  그려질 때)을 기다린다 — 연출 길이를 스모크에 다시 적으면 한쪽만 낡는다(CLAUDE.md의 「스모크는 첫
  실패에서 멈춘다」 절).
- **소리가 실제로 나는지·박자가 맞는지는 귀로만 확인된다** — 검사는 소리 없는 브라우저로 돈다.
