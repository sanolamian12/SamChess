# 2026-09-01 — 고유기술 열전(고사 조사 · 10개 언어) 신설 · 고유기술 밸런스 5종 조정

> 이 문서는 **한 대화 세션의 기록**이다. 프로젝트의 현재 상태와 규칙은
> [`HANDOFF.md`](../HANDOFF.md)와 [`Design/GDD.md`](../Design/GDD.md)가 정본이며,
> 여기는 "무엇을 왜 그렇게 정했는가"와 "어디서 넘어졌는가"를 남긴다.

## 왜 이 작업인가

사용자가 장수 정보 카드의 장수열전처럼, 고유기술 소개 화면에도 다국어 열전을
띄우고 싶어 했다. 순서는 사용자가 직접 정했다 — ① 40종 고유기술과 효과를
전부 리스트업, ② 그중 S급 30종 + E급 1종(고사가 있는 31종)의 실제 출처를
조사, ③ 한글 확정본을 다듬어 락인, ④ 그다음에야 10개 언어 번역. 도중에
"십면매복 WT를 +0.5→+0.9로" 같은 순수 밸런스 수정 요청이 별개로 끼어들었고,
그 작업이 번역 파이프라인에서 발견한 한자 오탈자 수정과 맞물렸다.

## 한 일

### 1. 리스트업 — 40종 고유기술 정리

`packages/data/generated/uniqueSkills.json`을 읽어 등급별로 정리했다. A급 4·
B급 5·E급 1(공용 10종, 여러 장수가 공유)과 S급 30(전용, 1인 1기술)으로
나뉜다는 구조를 먼저 확인했다.

### 2. 고사 조사 — 리서치 에이전트 4개 병렬 실행

S급 30 + E급 1 = 31종을 8개씩 4그룹으로 나눠 `general-purpose` 에이전트에게
각각 "정사(『삼국지』)/배송지주/『삼국지연의』 중 어디가 출처인가, 정사와
다르면 뭐가 다른가"를 조사시켰다. 결과가 상당히 흥미로웠다 — 대중에게
익숙한 장면 다수가 실제로는 연의(소설) 전용 창작이었다:

- **온주참화웅(관우)** — 정사에서 화웅을 벤 건 관우가 아니라 **손견**.
- **차동풍(제갈량)** — 동남풍은 완전 창작, 정사는 화공 성공을 계절풍으로 설명.
- **연환계(방통)** — 정사에 방통의 적벽대전 참전 기록 자체가 없다.
- **화용도 의석조조(조조)** — 조조의 진창길 탈출은 배송지주 근거가 있지만
  관우가 그 길목을 지켰다는 서사는 순수 창작.
- **백보천양(황충)** — 원래 춘추시대 명궁 양유기의 고사를 연의가 차용.

이 발견을 바탕으로 사용자와 함께 "출처를 투명하게 명시하되(강한 왜곡 논쟁
방지), 이름 자체의 근거가 약한 항목(강동지호·단치도강·수성지주·가후지책 등)은
인물평·정황 중심으로 서술한다"는 방침을 정했다.

### 3. 한글 확정본 작성 · 톤 교정

31종 전부 한글로 초안을 썼다. 1차 초안에 대해 사용자가 "'끼인 천자',
'이미지에 그대로 얹었다', '접수하며 올라갔다' 같은 표현이 기술의 이미지를
깎아내린다 — 백기겁위영·변화무쌍처럼 사건을 그 자리에서 벌어지는 것처럼
직접 서술하는 쪽이 낫다"는 피드백을 줬다. 한 발 물러난 메타 설명체(“이
표현은 후대에 굳어졌다” 류)를 걷어내고 극적 서술로 31종을 다시 썼다 —
출처 태그는 본문과 분리해 괄호로만 남겨, 사실 검증 가능성과 서사적 몰입을
동시에 지켰다.

### 4. 10개 언어 번역 — 에이전트 7개 병렬 실행

확정된 한글본을 번역 에이전트 7개(영어 · 일본어 · 중국어[간체+번체] ·
몽골어 · 이탈리아어 · 스페인어[중남미] · 포르투갈어[브라질+유럽])에 병렬로
맡겼다. `assets/Languages/sam_people.csv`에 이미 있는 관우 열전 예문을
스타일 앵커로 주고, 인명 표기 관례(병음/신자체/키릴 표기 등)를 언어별로
지정했다. 결과가 워낙 방대해(31개 × 10개 언어) 각 에이전트가 스크래치패드에
파일로 저장하고 완료 보고만 짧게 하도록 했다.

**여기서 예상 밖의 수확이 있었다** — 6개 언어 에이전트가 **서로 정보 교환
없이 독립적으로** 단치도강(허저)의 한자 "單齒渡江"이 이상하다고 지적했다.
齒(이빨)가 고사 내용(노를 저어 강을 건넌 일화)과 안 맞고, "單騎渡江"(홀로
말 타고 건넘)의 오기로 보인다는 것. 여러 언어로 번역하며 원문을 반복해서
곱씹게 만든 이 파이프라인 구조 자체가 오탈자 검출 수단으로 작동한 셈이다.

### 6. 밸런스 수정 5종

사용자가 별도로 요청한 수치 변경:

- 십면매복 WT `+0.5일 → +0.9일`, 신속 WT `-0.3일 → -0.5일`,
  장판하뢰 WT `+1.1일 → +1.5일`, 식소사번 `2일마다 → 1.1일마다`,
  수성지주 `1일마다 → 0.9일마다` 회복.
- 수성지주의 "1일마다"가 알고 보니 화계(火計) 지형과 공유하는 전역 상수
  (`FORMULA.terrainPeriod`)라는 걸 발견하고, "화계도 같이 0.9로 바꿀지 /
  수성지주만 분리할지"를 물어 **화계도 같이 90으로 조정**하기로 확인받았다.
- `docs/*.xlsx`가 문구(text)의 유일한 출처라(`extract_data.py`가 `time N` →
  "N/100일" 자동 변환) 효과 DSL만 고치면 화면 문구가 낡은 채로 남는다는 걸
  먼저 짚고, 엑셀 셀도 함께 고칠지 사용자 확인 후 진행했다.
- 관련 회귀 테스트(`skills.test.ts`·`skills-s.test.ts`·`battle.test.ts`)의
  기대값을 새 수치로 갱신.

### 7. 데이터 파이프라인 신설 — 고유기술 열전(`origin`)

번역이 끝난 뒤 "지금은 검토 생략, 바로 실제 데이터에 반영"하기로 하고 다음을
연결했다:

- `assets/Languages/sam_skills.csv` 신설 — `sam_people.csv`(장수열전)와
  완전히 같은 규약: `id`(로마자 슬러그) 열로 스킬을 식별하고, 언어별
  `origin_{lang}` 열에 "[출처 태그] 서술문"을 담는다.
- `tools/extract_data.py`에 `extract_skill_lore()`/`attach_skill_lore()`
  추가 — `extract_bios()`/`attach_bios()`를 그대로 본떴다.
- **`UniqueSkillData.origin`이 원래 있었다** — `string` 타입의 미사용
  플레이스홀더로, `SkillModal.tsx`에 "기술 유래 : {skill.origin}" 자리까지
  이미 만들어져 있었는데 아무도 안 채워서 늘 그 줄이 사라져 있었다. 타입을
  `Partial<Record<StoryLang, string>>`로 승격하고 `pickStory()`(장수열전이
  쓰던 것과 동일 함수)로 현재 UI 언어에 맞는 유래문을 고르도록 `SkillModal.tsx`를
  고쳤다.
- `tools/smoke_meta.ts`의 "기술 유래가 비었는데 줄이 남아 있으면 실패"라는
  단정이 이제 데이터가 실제로 채워졌으니 항상 실패하게 될 상황이라, 그
  단정을 걷어내고 있는/없는 상태를 로그로만 남기게 고쳤다(S·E급 31종은
  있고, A·B급 9종은 정형 효과뿐이라 원래 없다).

## 이번 범위 밖 (다시 볼 자리)

- **고유기술 소개 전용 화면은 아직 없다** — 이번엔 기존 `SkillModal`의
  "기술 유래" 자리(장수 카드 팝업)에만 연결했다. 사용자가 원래 말한 "장수
  정보 카드에서 장수열전을 띄워주듯" 별도 열전 화면을 만드는 건 다음 작업.
- **`skill.name`/`skill.hanja`/`skill.text`(효과 설명)는 여전히 한국어
  전용이다.** 이번엔 `origin`(유래) 필드만 다국어화했다 — 스킬 이름 자체나
  효과 설명 문구를 10개 언어로 넓히는 건 별개 작업이다(번역 에이전트들이
  스킬 제목도 각 언어로 옮겨 두긴 했지만 — `en.md`의 "The Lone Oar's Crossing"
  류 — 현재 데이터 스키마에는 연결하지 않았다. 필요해지면
  `sam_skills.csv`를 만들 때 쓴 스크래치패드 원본에서 다시 뽑을 수 있다).
- **A·B급 9종(공용 고유기술)은 고사 조사 대상이 아니었다** — 정형 효과라
  특정 고사가 없다는 전제였고, `origin` 필드 자체가 없다.
- **`assets/` 아래 변경(CSV·이미지 리네임·신규 이미지)은 `.gitignore`
  대상이라 이번 커밋에 안 잡혔다** — `assets/Languages/sam_skills.csv`
  신설과 `assets/SpecialSkills/허저 단기도강.png` 교체는 저장소를 새로
  클론한 환경에는 없다는 뜻이다. 자산을 옮길 때 이 문서를 참고해 함께
  맞춰야 한다(2026-08-31 세션이 남긴 것과 같은 종류의 주의사항).
