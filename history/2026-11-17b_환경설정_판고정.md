# 2026-11-17b 환경설정 판 — 언어를 바꿔도 크기 · 줄이 그대로

기획자 요청: 환경설정 판을 넓히고(화면의 90%), 언어 칩 열 개를 한 크기로, 줄 이름 · 가로/세로 칸을 열 언어 중 가장 큰 것에 맞춰
**언어를 바꿀 때마다 판이 들쭉날쭉하지 않게.** 가로/세로는 부대 배치의 남군 · 북군 토글 꼴로.

## 잰 것 (뷰포트 760×1200 → 판 600px)

| | 전 | 후 |
|---|---|---|
| 판 폭 | 438.5px = 화면의 **73.1%** (`.modal` max-width 19rem) | 540px = **90%** (열 언어 같음) |
| 판 높이 | 817.3 ~ 831.5 (언어마다 다름) | 821.8 (열 언어 같음) |
| 언어 칩 | 57.7 ~ 68.4 × 50.9 (칩마다 다름 · 글자는 언어를 안 탄다, MN이 가장 넓음) | 69.0 × 51.0 전부 |
| 가로/세로 | 77.1 ~ 103.7 (언어마다 다름) | 112.4 × 36.8 (열 언어 × 두 낱말 중 가장 긴 「Orizzontale」 기준) |
| 줄 이름 | ID · Language · 화면 모드는 5.2rem 고정 → 「Modo de pantalla」 · 「Modalità schermo」 · 「Дэлгэцийн горим」이 **두 줄** | 줄마다 열 언어 중 가장 긴 것의 한 줄 폭 |

판 높이가 출렁인 원인은 둘이었다 — ① 긴 「화면 모드」 이름이 두 줄로 접힘, ② 명패 제목이 긴 언어(이탈리아어 · 포르투갈어 브라질)에서
`useFitText`로 글자가 줄며 **줄 높이까지 줄어** 명패가 1~4px 낮아짐. ②는 명패 줄 높이를 `1.25rem`으로 박아 풀었다.
390×844(폰)에서도 열 언어 판 351×534.2로 같다.

## 어떻게

- `SettingsModal.tsx`의 `useSteadyBoxes` — `data-steady="<묶음>"` 요소를 묶음마다 모아, 복제본을 **같은 부모 안에 숨겨** 한 줄로 그려 재고
  가장 큰 폭 · 높이를 묶음 전원에 `em`으로 입힌다. `data-steady-keys`가 있으면 그 문구를 열 언어로(`inLang`) 끼워 잰다.
  `em`이라 창 크기가 바뀌어도 다시 잴 필요가 없고, 메타 화면 글꼴이 언어를 안 타서(몽골어 `--serif`는 여기 안 닿는다) 열 때 한 번 + `fonts.ready` 뒤 한 번.
  옛 `useTwoChipSize`(지금 언어만 재서 맞추던 것)를 갈았다. 묶음: 줄 이름 여섯(각자) · 언어 칩 열 · 가로/세로 둘.
- `VolumeRange`에 `steadyKey` — 배경 음악 · 효과음 이름 칸도 같은 훅이 잰다.
- 가로/세로 — `.set-sides`(명령 단추 한 장 `btn-battle-command.png`를 반반, 가운데 금) · 고른 쪽(세로)은 밝은 금빛 글자 + 투구 메달
  (`icons/tutorial/next.png`), 안 고른 쪽은 잿빛. 둘 다 잠겨 있지만(세로 고정) 흐리게 빼지 않는다.
- CSS는 전부 `.set-modal` 아래 — 언어 팝업(`LanguageModal`)도 `.opt-row` · `.langs`를 쓰므로 안 건드린다.

## 검사

`tools/settings_ux.ts`에 「언어를 바꿔도 판이 안 움직인다」 — 열 언어를 돌며 판 폭 = 화면의 90% · 이름 한 줄 · 칩 · 가로/세로 크기가 하나 ·
판 · 칩 · 가로/세로 · 이름 칸 크기가 첫 언어와 같은지. 옛 판이면 첫 언어에서 73%로 떨어진다. `npm run typecheck` 통과.

## 이어서 — 화면 모드는 화살표 목판 둘 (기획자)

판 한 장 반반 + 투구 메달을 걷고, 쪽 넘김 단추와 같은 화살표 목판 둘(`assets/icons/ui/to_end` · `to_next` → `ui/pager-end` · `pager-next`)을
**대칭으로** — 왼쪽 [가로]는 꼭짓점이 왼쪽, 오른쪽 [세로]는 오른쪽, 고리 둘이 가운데에서 만난다. 고른 쪽은 초록 판(`to_end`) + 빛나는 글자,
안 고른 쪽은 갈색 판(`to_next`) + 빛 없는 글자. 판만 `::before`에서 뒤집는다(단추째 뒤집으면 글자가 거울이 된다). 칸이 그림(1.8:1)보다 길어
통째로 늘이면 꼭짓점이 퍼지므로 고리 15% · 꼭짓점 22%만 잘라 가운데 나뭇결만 늘인다. 열 언어 가로/세로 칸 119.1 × 48.5 하나(`settings_ux` 통과).
