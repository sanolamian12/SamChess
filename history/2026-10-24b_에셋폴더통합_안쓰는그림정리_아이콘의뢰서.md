## 고친 버그

- **`build_ui.py`에 `knock_out_black` · `BLACK_BG_LEVEL`이 두 번 정의돼 있었다** (2026-10-21 우편함 · 사용안내 아이콘). 뒤의 것(아이콘용, 인자 하나 ·
  문턱 10)이 앞의 것(판때기용, `hollow` · 문턱 28)을 덮어, **`npm run ui -- --force`가 액자 단계에서 죽었다.** `--force` 없이는 바뀐 원본만
  굽기 때문에 아무도 몰랐다. 아이콘 쪽을 `knock_out_black_icon` · `ICON_BLACK_LEVEL`로 갈랐다.

## 확인한 방법

- **쓰는지는 「실제로 연 파일」로 가렸다** — 도구 9개를 `--force`로 돌리며 `open()`을 가로채 기록했다. 기록에 안 잡히는 둘을 손으로 더했다:
  `shutil.copy2`(Windows는 `open`을 안 거친다 — 대장간 고정 그림) · ffmpeg 인자(`dice.mp4`).
- **화면이 쓰는지는 정적 검색만으로 못 가린다** — `emblem-${id}` · `collection-${side}` · `steward-${tier}`처럼 이름을 조립한다.
  후보마다 조립하는 자리를 찾아 하나씩 확인했다(`collection-south`는 쓰는 것이었다).
- **옮긴 뒤 같은 395장을 읽는 것을 기록끼리 대조했다.** `public/`의 굽힌 그림은 `.gitignore` 대상이라 **`git status`로는 결과물이 바뀌었는지
  알 수 없다** — 처음에 그것으로 「한 바이트도 안 바뀌었다」고 잘못 보고했다가 고쳤다.
- `npm run typecheck` · `npm test`(1095 통과) · 바뀐 도구 넷과 `extract` 재실행(경고는 원래 있던 「못 찾은 원본」 없음 · `levelup_frame` · 장터 `frame-*`가 빠져 줄었다).
