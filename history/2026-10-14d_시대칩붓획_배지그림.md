# 시대 칩 붓 획 · 배지 그림 붙이기 (2026-10-14 d)

기획자가 컬렉션 목록의 시대 칩(둥근 상자)을 **굵은 붓 「一」 위의 글자**로 바꾸자고 했고(의뢰서 ⑥), 그림을 받아 붙였다.
같은 때 전투 배지 그림 둘도 받았다. `era-strokes` 브랜치 → main `--ff-only`.

## 1. 확정한 것 (기획자)

| | 결정 |
|---|---|
| 시대 칩 | 붓 획(시대마다 「이야기의 색」, 한 단계 진하게) 위에 미색 글자. 열전(금)만 짙은 갈색 글자 |
| A · B | **B(색마다 따로 받은 여덟 장)를 먼저** — 획이 조금씩 달라 심심함을 던다. A(검은 획 한 장을 물들임)는 `?stroke=a`로 견준다 |
| 옥색 마름모 | 컬렉션 「기술 변형」이 아니라 **태학 개량 책략** 표지로. 컬렉션은 붉은 인장 하나가 다 맡는다 |

## 2. 만든 것

- `tools/build_ui.py` — `전투-컬렉션` → `badge-active.png` · `전투-책략 개량` → `badge-upgrade.png`(검은 바탕 걷기, 폭 96),
  붓 획 `era-stroke-b-{n}`(`unmix_on_black` — 획 색의 중앙값에 대어 알파를 푼다, 밝기로 걷으면 쪽빛 · 자주의 속까지 비친다) ·
  `era-stroke-a-{n}`(`tint_on_white` — 먹의 진하기 = 알파, 진할수록 조금 어둡게). 원본 이름의 색 낱말 → 시대 번호는 `ERA_STROKE_COLORS`.
- `style.css` `.clx-era` — 9분할(`border-image-slice: 0 34% 0 12% fill`, 테 두께 0 · 그림 폭만 여백 위에) — 머리 · 꼬리는 그대로, 가운데만 글자 길이만큼.
  **그림이 없으면** 미색 글자가 종이 위에서 사라지므로 글자 칸(`content-box`)에만 같은 색 바탕을 깐다.
- `CollectionScreen.tsx` `ERA_STROKE` — `?stroke=a`. `tools/collection_ux.ts`에 `STROKE=a`.
- `ui/collectionBadge.ts` — 인장 하나(`data-bonus="collection"`)가 고유기술 SP까지. SP 칸은 줄만 긋는다.
- `ui/upgradeMark.ts`(새 파일) — `def.base`가 있으면 옥색 마름모. 전투의 책략 목록(칸 왼쪽 여백 — 이름 앞에 끼우면 두 열 칸에서 「공…」으로 잘렸고,
  테 밖에 걸치면 목록 상자가 반을 잘랐다) · 적 책략 팝업의 칩.
- 데모 `?collections=1` — 남군 책략을 **하나 걸러** 개량형으로(개량형에만 서는지 · 원본에는 안 서는지를 한 목록에서). `smoke:ui`에 그 단계.
