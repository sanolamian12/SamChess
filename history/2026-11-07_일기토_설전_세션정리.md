## 7. 고친 버그

- **끝 말풍선이 두세 번 떠오르던 것**: 끝 장면 도중 말풍선이 걷히고 대결 단계가 닫히며 층이 다시 지어질 때마다(실측 0 · +1.39 · +1.49초) 떠오름 애니메이션이 처음부터 돌았다. 처음 그린 때(`endShown`)부터 음수 지연으로 이어 돌게 했다. 「패배」 도장도 같다.
- **미리 낸 패를 그대로 누르면 「골랐다」로 안 바뀌던 것**: 판의 패가 같아 다시 짓기 열쇠가 그대로였다. `smoke:duel`이 미리 낸 패가 둘째 단추일 때(⅓)만 떨어져 **흔들림으로 보고 한 번 넘겼던** 실패다. 누르면 다시 짓기를 청한다.
- **끝 말풍선의 작은 글이 폭에 걸려 아무 데서나 두 줄이 되던 것**: 이제 정보 하나에 한 줄이다(어떻게 끝났나 / 이긴 쪽 / 진 쪽, 보상 문구의 「·」에서 끊는다). 글 묶음을 위로 올려 세 줄이어도 아래 가시 안에 든다.

## 8. 교훈

- **같은 자리에서만 떨어지는 스모크는 흔들림이 아니다.** 같은 검사가 두 번 떨어지면 「언제 떨어지나」의 조건부터 본다. 이번 것은 ⅓ 확률의 실제 버그였다.
- **다시 짓는 층의 CSS 애니메이션은 시작 시각을 들어야 한다.** 합 번호 반짝임 · 장면 스밈 · 말풍선 · 끝 말풍선이 모두 같은 틀(음수 지연)이다. 새 애니메이션을 더하면 이 틀을 따른다.
- **같은 세기의 CSS 규칙은 파일에서 아래 것이 이긴다.** 끝 말풍선 여백을 위쪽 규칙에서 고쳤는데 안 먹었다. 실제로 이긴 규칙은 `background-image`가 있는 아래 줄이었다. 사진으로 봐야 안다.
- **실시간 연출 길이는 서버와 함께 쓰는 값이다.** 「더 오래 보여 달라」는 요청은 `timing.ts`의 불변식(`TIMING_INVARIANTS`)부터 본다. 공개는 못 늘렸고 끝 장면은 늘릴 수 있었다.
